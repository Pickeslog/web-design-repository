## 🛠️ 파일별 상세 수정 내역

### 1. `index.html` (대표 커버 구조 및 모달 추가)
- **메타 박스 개편 (`.cover-meta-grid`)**:
  - 최근 근황 업데이트 박스를 제거하고 참여 멤버 단독 카드로 구성.
  - `.member-highlight-card` 클래스를 적용하고, 좌측에 4명의 아바타(`나`, `솔`, `민`, `준`)가 원형으로 겹쳐진 오버랩 그래픽 배치.
  - 우측 끝에 직관적인 Call-to-Action 버튼인 `멤버 보기 ➔` 뱃지 추가.
  - 밝고 튀던 형광 초록 배경을 전체 테마와 어우러지는 반투명 글래스 톤(`rgba(248, 251, 249, 0.85)`) 및 은은한 테두리로 수정.
- **클릭 이벤트 제한 및 전파 방지**:
  - 대표 사진 카드(`.main-photo-card`) 전체에 걸려있던 모달 열기 이벤트를 제거.
  - 오직 **참여 멤버 박스(`.member-highlight-card`)**에만 `onclick="openMemberListModal(event)"` 및 `cursor: pointer` 부여.
  - 카메라 아이콘(`.photo-edit-overlay`)과 사진 제목(`#dt-photo-title`) 영역 클릭 시 `event.stopPropagation()`을 호출하여 모달이 뜨지 않고 본래 기능만 동작하도록 분리.
- **참여 멤버 리스트 모달 창 (`#member-list-overlay`) 신규 추가**:
  - Clov 초록 클로버 디자인 테마를 반영한 깔끔하고 세련된 멤버 리스트 팝업 모달 추가.
  - 나, 솔, 민, 준 4인의 프로필 및 상태 표시.

### 2. `css/desktop.css` (스타일 및 경계선 마스크 그라데이션)
- **그리드 레이아웃 확장 (`.cover-meta-grid`)**:
  - 기존 2열 분할(`repeat(2, minmax(0, 1fr))`)에서 1열(`1fr`) 구조로 변경.
- **참여 멤버 카드 인터랙션 (`.member-highlight-card:hover`)**:
  - 마우스 호버 시 위로 2px 떠오르며 진한 초록 그림자와 테두리가 감싸는 부드러운 전환 효과 추가.
- **사진과 텍스트 영역 자연스러운 경계선 블렌딩 (`.main-photo-wrapper`)**:
  - `-webkit-mask-image: linear-gradient(to right, rgba(0, 0, 0, 1) 50%, rgba(0, 0, 0, 0) 100%);` 적용.
  - 사진의 오른쪽 50% 구간이 서서히 투명해지며 텍스트 영역의 여백 및 배경색 안으로 부드럽게 스며드는 디졸브 효과 구현.
  - 라이트 모드와 다크 모드 모두에서 괴리감 없이 완벽하게 어우러짐.
  - 모바일 화면(`.mobile-window .main-photo-wrapper`)에서는 상하 레이아웃 구조에 맞춰 가로 마스크가 해제되도록 `mask-image: none;` 예외 처리.

### 3. `js/desktop.js` (모달 제어, 이미지 업로드 제한, D-day 1일차 보정)
- **멤버 리스트 모달 열기/닫기 함수 구현**:
  ```javascript
  // 참여 멤버 리스트 모달 제어 함수
  function openMemberListModal(event) {
      if (event && (event.target.closest('.photo-edit-overlay') || event.target.closest('#dt-photo-title') || event.target.closest('.editable-title'))) {
          return;
      }
      const overlay = document.getElementById('member-list-overlay');
      if (overlay) overlay.style.display = 'flex';
  }

  function closeMemberListModal() {
      const overlay = document.getElementById('member-list-overlay');
      if (overlay) overlay.style.display = 'none';
  }

  window.openMemberListModal = openMemberListModal;
  window.closeMemberListModal = closeMemberListModal;
  ```
- 이중 방어 로직을 적용하여 타겟 요소가 카메라나 제목 영역일 경우 모달이 뜨지 않도록 안전장치 마련.
- **이미지 업로드 유효성 검사 및 제한 강화**:
  - 대표 사진 모달(`handleFile`), 프로필 아바타(`handleProfileAvatarUpload`), 게시글 작성(`previewWriteImg`), 단계 인증(`uploadStagePhoto`) 전반에 이미지 파일 형식 검증 로직 추가.
  - 사용자가 드래그 앤 드롭이나 파일 창에서 비이미지 파일(PDF, ZIP 등)을 선택할 경우 즉시 경고창(`alert('⚠️ 이미지 파일(JPG, PNG, GIF, WEBP 등)만 업로드할 수 있습니다.');`)을 띄우고 입력을 초기화.
- **함께한지 D-day 배너 D+0 오류 수정 및 1일차 보정**:
  - `animateDdayElement`: 애니메이션이 0부터 카운트업하면서 `D+0 일째`를 출력하던 문제를 수정. 한국식 날짜 계산 규칙(만남 당일 = 1일차)에 따라 `safeTarget` 및 애니메이션 시작 카운트를 최소 1(`Math.max(1, targetNumber)`)로 설정.
  - V5 헤더 배너 ID 연동 (`dt-v5dday`, `mb-v5dday`): 기존 V5 배너 업그레이드 이후 애니메이션 대상에서 빠져 있던 요소들을 `animateDdayCount`에 추가하고, 숫자만 들어가는 V5 span 특성에 맞추어 `formatVal` 조건부 포맷팅 적용.
  - `v5updateHUD(p)`: 동기화 실패 시 기본값이 `0`이 되어 0일차로 렌더링되는 폴백(fallback) 오류를 최소 `1`로 안전하게 변경.
  - 친구 연동 (`connectFriend` / `connectDesktopFriend`): 연동 완료 시 `ddayCount = 1` 값을 즉시 `localStorage`에 저장하고 V5 헤더 UI(`v5render()`)를 즉각 갱신하도록 처리.

## ✅ 검증 및 결과
1. **클릭 타겟 정확도**: 참여 멤버 박스를 클릭했을 때만 모달이 정상적으로 팝업되며, 사진이나 배경, 제목, 카메라 아이콘 클릭 시 모달이 작동하지 않음을 확인.
2. **시각적 완성도**: 너무 밝고 튀던 색상이 차분하게 정돈되었으며, 경계선 그라데이션 처리로 인해 이미지와 텍스트 영역이 고품질 스트리밍 서비스 커버처럼 매끄럽게 연결됨.
3. **D-day 정확도 및 애니메이션 연동**: 초기 접속, 그룹 변경, 단짝친구 연동 시 D+0으로 깜빡이거나 0일차로 표기되는 문제 없이 1일차(D+1) 또는 실제 설정된 디데이 숫자로 부드럽고 정확하게 애니메이션 및 동기화됨을 확인.
