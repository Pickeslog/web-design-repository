## chacha1650a — invite 프론트 (clov-web #28)

너의 **letter 프론트(#25, `pages/letters/Letters`·`api/letter.js`)를 그대로 본떠라.** 백엔드는 이미 완성돼 있어 **프론트만** 붙이면 된다.

1. **`api/invite.js`** 생성 — `api/letter.js`처럼:
   - `createInvite(roomId, payload)`→`POST /rooms/{roomId}/invites`, `getInvites(roomId)`, `cancelInvite(inviteId)`→`DELETE /invites/{inviteId}`
   - `requestJoin({inviteCode})`→`POST /invites/accept`, `getJoinRequests(roomId)`, `acceptJoinRequest(id)`/`rejectJoinRequest(id)`/`undoJoinRequest(id)`→`POST /join-requests/{id}/{accept|reject|undo}`
2. **화면**: `pages/rooms/Invite`(코드 생성·목록·취소) + `pages/rooms/JoinRoom`(코드 입력→신청) + **대기 신청 목록**(신청자 `applicant.nickname`·수락/거절, 수락 후 `undoDeadlineAt`로 **5분 되돌리기** 카운트다운).
3. **router**: `/rooms/:roomId/invite`·`/rooms/:roomId/join`. Dashboard에 진입점.
4. **꼭 지킬 것**: `POST /invites/accept`는 **입장이 아니라 신청(PENDING) 생성**. 409 에러 3종(`JOIN_REQUEST_ALREADY_PROCESSED`·`ROOM_CAPACITY_EXCEEDED`·`JOIN_REQUEST_UNDO_EXPIRED`)은 사용자 안내 메시지로.
5. 완료: lint/build + 브라우저 렌더 확인, PR 본문 `Closes #28`.

## kimgyubi1234 — notification actor (clov-api #35, 백+프론트)

너의 **notification 슬라이스를 골든레퍼런스로**, 알림에 "누가"를 넣는다.

1. **백엔드**: `NotificationResponse`에 `actor`=`UserSummary` 추가(현재 `actorId` 문자열만). 매퍼에서 `users` JOIN(`actor_id` 기준)으로 닉네임·프로필 채우기. 계약 §13 = `actor`(중첩 객체). **`UserSummaryResponse`는 `global/dto` 재사용.**
2. **프론트**: 메시지를 `actor.nickname`으로 개인화 — 예: "OOO님이 가입을 신청했어요"(JOIN), "OOO님이 편지를 보냈어요"(FRIEND). 현재 type별 제네릭 문구를 actor+type 조합으로.
3. **주의**: 목록 봉투 정합(`{items}`)은 **별도 PR #36에서 이미 처리**됐으니 건드리지 마(actor만).
4. **통합테스트**: 알림 응답에 `actor.nickname` 존재 확인. CI `build` 초록.
5. 완료: 백 PR(`Closes #35`) → 프론트 PR.
