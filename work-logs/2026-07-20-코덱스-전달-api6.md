## 선행 — 공유 개발 DB에 동의 컬럼 추가

05-db에는 이미 반영됨. 실제 공유 DB에는 **ADD COLUMN만** 실행(⚠️ DROP/TRUNCATE 금지), 실행 후 **팀에 공지**(공유 DB라 한 번만).

```sql
ALTER TABLE users
  ADD COLUMN terms_agreed_at     DATETIME NULL AFTER birthdate,
  ADD COLUMN privacy_agreed_at   DATETIME NULL AFTER terms_agreed_at,
  ADD COLUMN marketing_agreed_at DATETIME NULL AFTER privacy_agreed_at;
```

## 재사용 — #4에서 이미 만든 것

- `JwtTokenProvider` (Access 30분/Refresh 14일 발급·검증)
- `RefreshToken`/`RefreshTokenMapper` (**해시 저장**, `revoked_at IS NULL`·미만료 조회, revoke)
- `PasswordEncoder`(BCrypt) 빈
- `ApiResponse` 봉투 + `ErrorCode`(인증 코드는 §14에 추가 완료)

[선행 — 공유 DB에 동의 컬럼 추가 (05-db에 이미 반영됨)]
users에 아래 3개가 필요하다. 공유 개발 DB에는 ADD COLUMN만 실행(DROP/TRUNCATE 금지),
실행 후 팀에 공지해:
ALTER TABLE users
  ADD COLUMN terms_agreed_at     DATETIME NULL AFTER birthdate,
  ADD COLUMN privacy_agreed_at   DATETIME NULL AFTER terms_agreed_at,
  ADD COLUMN marketing_agreed_at DATETIME NULL AFTER privacy_agreed_at;

[엔드포인트 — 계약 §4-1 스키마 그대로]
- POST /api/v1/auth/signup — 가입 즉시 로그인 (accessToken+refreshToken+user, 201)
  · 요청: email, password, nickname, birthdate?, agreements{service,privacy,marketing}
  · service/privacy 가 false면 400 TERMS_REQUIRED
  · 동의 시각을 terms_agreed_at/privacy_agreed_at/marketing_agreed_at 에 기록
  · 프로필 이미지는 받지 않음(기본값). personal_invite_code 서버 생성(CLV-+Base32 6자, UNIQUE 충돌 시 재생성)
  · 이메일 중복 409 EMAIL_DUPLICATED
- POST /api/v1/auth/login — 성공 시 위 인증 data(200). 실패는 동일 401 INVALID_CREDENTIALS
- POST /api/v1/auth/refresh — refreshToken은 요청 본문. 회전(기존 revoke + 신규 발급)
  · 위조/형식 401 INVALID_TOKEN, 만료/revoked 401 TOKEN_EXPIRED
- POST /api/v1/auth/logout — refreshToken 본문, 해당 revoked_at 기록, data: null

[재사용 — #4 산출물]
- JwtTokenProvider로 토큰 발급/검증
- RefreshToken/RefreshTokenMapper로 저장(원문 아닌 해시)·조회·revoke
- PasswordEncoder(BCrypt) 빈 재사용

[반드시 지킬 것]
- base path /api/v1
- 비밀번호 BCrypt 해시. 응답 DTO에 password 절대 미포함
- refresh 토큰은 원문 아닌 해시로 저장
- 비밀번호 정책 8~20자·영문/숫자/특수문자 2종 이상 @Valid
- role 개념 만들지 마 (users에 role 없음, 계약 §3)
- MyBatis만(JPA 금지), SQL은 #{} (${} 금지)
