**작업 일시**: 2026년 6월 29일
**대상 파일**: makerooms.html
**참고**: `Clov - 0629 모달 및 UI 텍스트 수정본.html`의 Desktop/Mobile 동시 미리보기 구조(`split-workspace`)와 색상 토큰(`--primary-green` 등), `signup_in/SignUp.html`의 입력값 검증 패턴을 그대로 가져와 일관성을 맞췄습니다.

## 화면 구성

데스크톱 브라우저 뷰와 모바일 앱 뷰를 한 페이지에 나란히 띄워, 같은 컴포넌트가 두 환경에서 동일하게 보이는지 바로 비교할 수 있게 했습니다.

1. **대표 사진/아이콘**: 점선 테두리의 정사각 영역을 클릭하면 사진 URL을 입력받아 미리보기에 반영(기존 `triggerPhotoUpload` 패턴 재사용). 비워두면 기본 카메라 아이콘 상태를 유지합니다.
2. **우정공간 이름** (필수): 한글/영문 2~20자 정규식 검증. `signup_in/SignUp.html`의 `validators` 패턴과 동일한 방식으로 입력 중 실시간 검증하고, 어긴 경우에만 경고 문구를 보여줍니다.
3. **소개글** (선택): 60자 이내 한 줄 소개. 비워도 생성에는 문제없습니다.
4. **우정공간 만들기 버튼**: 이름 검증을 통과하면 생성 완료 패널로 전환됩니다.

## 생성 완료 패널

- 방 이름을 포함한 완료 메시지와 함께, 새로 생성된 **방 전용 초대 코드**(`CLOV-XXXX` 형식)를 보여줍니다.
- 기존 "🤝 친구 초대코드" 모달의 `personal_invite_code`(개인 식별 코드)와는 다른, 이 우정공간에만 쓰이는 초대 코드입니다 — DB 설계상 `ROOM_INVITES.invite_code`에 해당합니다.
- 복사 버튼은 `navigator.clipboard`를 우선 사용하고, 지원하지 않는 환경에서는 입력값을 선택(select)하는 방식으로 대체합니다.
- "다른 우정공간 더 만들기"를 누르면 폼을 초기화하고 처음 화면으로 되돌립니다.

## 의도적으로 포함하지 않은 것

- **친구 코드 즉시 입력란**: 방 생성과 동시에 상대 코드를 받는 것보다, 방을 먼저 만들고 초대 코드를 공유하는 흐름이 더 단순하다고 판단해 제외했습니다. 친구 코드를 직접 입력해 연동하는 흐름은 기존 "🤝 친구 초대코드" 모달에서 이미 처리합니다.
- **그래프/진행 바/클로버 채움 같은 성장 표현**: 방을 처음 만드는 화면에는 아직 쌓인 기록이 없으므로 불필요합니다. 레벨·성장 표현은 방이 만들어진 이후 대시보드 화면의 몫입니다.
- **약속/일정 동시 등록**: 방 만들기와 약속 만들기를 한 화면에 묶지 않고, 방을 먼저 만든 뒤 일정계획 탭에서 약속을 등록하는 기존 흐름을 그대로 따릅니다.
