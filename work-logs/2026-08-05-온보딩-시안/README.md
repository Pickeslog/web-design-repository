## 구현할 때 여기서 가져갈 코드

`guide-v5.html` 안에 다 있다.

```
medianCut() / nearest()     팔레트 자동 추출(스프라이트마다)
pixelize(img, 64, 12)       ★ 평균으로 줄이고 → 색을 줄인다. 순서를 바꾸면 얼룩진다
F{} / pxText() / pxGrid()   5×7 비트맵 → SVG rect ("START", 로고, 클로버)
KEY_NEVER / KEY_SESSION     다시 뜰지 말지 세 갈래
```

## 왜 이렇게 정했는지

`../2026-08-05-핸드오프.md` §12에 근거가 있다. 요약하면:

- **한글 픽셀 폰트가 없다** → 픽셀은 테두리·버튼·캐릭터가 만들고 한글은 일반 폰트 (스파이디 트래커도 같은 방식)
- **마스코트는 자동 변환(A안)** → 7종 + 계속 느는 스킨을 손으로 못 따라간다. 사용자가 고른 마스코트가 그대로 나와야 한다
- **64px · 12색** → 1픽셀이 화면 2px 아래로 내려가면 픽셀 아트로 안 읽힌다
- **평균 다운샘플** → 니어리스트로 줄이면 원본 잡티를 집어와 얼룩진다
