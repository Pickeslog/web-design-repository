# 코덱스 전달 — room 백엔드 (M2 R1 · 이슈 #19 · 최우선)

> 사용법: 아래 프롬프트를 clov-api에서 코덱스에 그대로 붙여넣는다. room은 모든 도메인의 `roomId` 부모라 R1에서 먼저 뚫는다.

---

작업 전 `clov-api/AGENTS.md`, `web-design-repository/docs/AI-TEAM-HARNESS.md`·`DOMAIN-NAMING-REGISTRY.md`·`CODE-CONVENTION.md`, 그리고 계약 `docs/API-CONTRACT.md` §6·§12를 읽어.

## 목표
clov-api에 **room 도메인 백엔드 슬라이스**를 구현한다. GitHub 이슈 **#19**. 모든 도메인의 `roomId` 부모라 **최우선**.

## 방식
이미 머지된 **auth 슬라이스(`domain/auth`)를 구조 그대로 복사**하고 이름만 레지스트리 §2 `room`·`exp/mascot` 행의 확정값으로 치환한다. 공통(`ApiResponse`·`ErrorCode`·`GlobalExceptionHandler`·`client`)은 **재사용**, 재생성 금지.

## 이름 (레지스트리 §2 — 확정값만, 표에 없으면 이슈로 제안)
- `domain/room` · `RoomController`·`RoomService`·`RoomMapper`·`RoomMemberMapper` (+ `RoomLevelController`·`MascotController`·`MascotService`)
- Entity: `Room`(friendship_rooms)·`RoomMember`(room_members)·`FriendshipExpLog`(friendship_exp_logs, 서버계산)
- `resources/mapper/room/RoomMapper.xml` (namespace=인터페이스 FQN, SQL id=메서드명, `#{}`만)

## 엔드포인트 (계약 §6·§12 — 경로/요청/응답/에러코드 그대로)
**§6 Rooms**
- `POST /api/v1/rooms` 생성(생성자=첫 멤버, 일반 멤버와 동일) → RoomDetail(201)
- `GET /api/v1/rooms/{roomId}` 상세(RoomDetail) · `PATCH /api/v1/rooms/{roomId}` 수정(`name`·`description`≤60·`themeColor`·`transportType`·`coverPhotoUrl`·`coverTitle`) → 전 멤버 알림 팬아웃
- `GET /api/v1/rooms/{roomId}/members` 목록(ACTIVE/LEFT)
- `DELETE /api/v1/rooms/{roomId}/members/me` 나가기(**row 삭제 아님, `status=LEFT`**)
- `PATCH /api/v1/rooms/{roomId}/members/me/status-message` · `PATCH /api/v1/rooms/{roomId}/favorite` 즐겨찾기 토글
- `POST /api/v1/rooms/{roomId}/revive` 되살리기
- 전원 LEFT → 서버가 `status=INACTIVE`+`scheduled_delete_at`(+30일) 자동. **별도 방 삭제 API 없음.**

**§12 Exp/Level/Mascot** (room-scoped, 분리 안 함)
- `GET /api/v1/rooms/{roomId}/exp-logs` · `GET /api/v1/rooms/{roomId}/level`(서버 계산: `friendshipLevel`·`expPoint`·`expForNextLevel`·`remainingToNextLevel`)
- `POST /api/v1/rooms/{roomId}/mascot/interact`(+2, 하루 3회 초과 → `429 MASCOT_INTERACTION_LIMIT_REACHED`)
- exp는 직접 API 없이 서버 내부 부수효과로 적립.

## 규칙
- **최대 8명 단일 구조. `role`/방장/관리자/대표자 개념 만들지 마. 모든 멤버 동등.**
