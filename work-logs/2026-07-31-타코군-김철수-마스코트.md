# 타코군·김철수 마스코트 작업 기록 — 2026-07-31

## 1. 작업 목적

기존 간판 사진에서 아이디어를 얻은 문어와 코끼리를 Clov에서 선택할 수 있는 독립 마스코트로 정리했다.

- 문어 캐릭터 이름: **타코군**
- 코끼리 캐릭터 이름: **김철수**
- 김철수의 직업: **목수**
- 최종 반영 위치: `clov-web/src/assets/mascot/`

간판 캐릭터의 인상을 그대로 복제하지 않고, 사용자가 좋아한 감정과 분위기는 남기면서 색상·실루엣·의상·소품을 새 캐릭터에 맞게 다시 설계했다.

## 2. 타코군 디자인 결정

### 유지한 감정

사용자가 가장 강하게 반응한 부분은 원본의 표정이었다.

- 서로 가까이 붙은 작은 눈
- 눈 위로 들린 짧은 눈썹 두 개
- 한쪽으로 기울어진 커다란 입
- 신나고 약간 사고를 칠 것 같은 표정

이 네 요소를 타코군의 고정 얼굴 규칙으로 삼았다. 이후 몸이나 의상이 바뀌더라도 얼굴의 감정 구조는 유지한다.

### 새롭게 정한 조형

- 몸 색상을 보라색에서 **선홍색**으로 변경
- 머리 위 촉수를 물음표처럼 말린 나선형으로 구성
- 입 테두리는 원본의 코랄색 대신 **겨자색** 사용
- 크림색 앞치마와 겨자색 주머니 적용
- 진한 남색 외곽선과 크림색 스티커 테두리 사용

초기 재설계안은 삼각형 몸·짝눈·민트색 소품을 사용했으나 너무 일반적인 귀여운 캐릭터가 되어 폐기했다. 최종안은 원본의 투박하고 들뜬 감정을 살리되 색상과 몸 구조를 달리하는 방향으로 정리했다.

## 3. 김철수 디자인 결정

### 기본 캐릭터

- 몸 색상을 보라색에서 **연한 하늘색**으로 변경
- 큰 귀, 긴 코, 좁은 세로 눈, 검은 미소와 머리 위 작은 털 유지
- 원본의 단순한 종이 스티커 형태와 크림색 외곽선 유지

### 목수 설정

건설 현장 인부보다 동네 목수로 읽히도록 다음 요소를 사용했다.

- 황토색 캔버스 작업 앞치마
- 짙은 갈색 공구 벨트
- 노란 줄자
- 주머니 속 접이식 자
- 귀에 꽂은 빨간 목수 연필
- 작은 장도리

안전모와 전동공구는 사용하지 않았다.

### 코·손·귀 가독성 조정

처음에는 하늘색 몸이 한 덩어리로 합쳐져 코·손·귀가 잘 보이지 않았다. 반대로 안쪽 귀 면과 굵은 외곽선을 모두 넣은 버전은 설명 그림처럼 과도하게 뚜렷했다.

최종안은 다음 절충안을 사용한다.

- 귀는 별도 색 면 없이 짧고 얇은 접힘선만 표시
- 코는 전체를 굵게 두르지 않고 연한 파란 선과 작은 주름만 표시
- 망치를 잡는 손과 반대 손은 작은 둥근 형태로만 분리
- 원본처럼 큰 색 덩어리가 이어지는 느낌을 우선

## 4. 앱용 에셋 처리

초기 자동 배경 제거는 크림색 눈·앞치마·스티커 외곽선을 배경으로 오인했다. 이를 그대로 사용하지 않고 두 캐릭터를 균일한 녹색 크로마키 배경으로 다시 만든 뒤, 녹색만 제거했다.

| 캐릭터 | 앱 에셋 | 규격 | 용량 |
|---|---|---:|---:|
| 타코군 | `clov-web/src/assets/mascot/tako-gun.png` | 640×640 투명 PNG | 약 253 KB |
| 김철수 | `clov-web/src/assets/mascot/kim-cheolsu.png` | 640×640 투명 PNG | 약 254 KB |

두 에셋 모두 눈·앞치마·도구·크림색 외곽선이 보존됐는지 투명 배경 상태로 다시 확인했다.
