### 상세 수정 사항
1. **타입 불일치(Number vs String) 문제 해결 (`js/schedule.js`)**:
   - HTML 인라인 이벤트나 모달 입력창에서 전달된 일정 ID가 문자열(`String`)인 경우, 기존의 엄격한 비교 연산자(`===`, `!==`)로 인해 숫자(`Number`) 형태인 배열의 ID와 일치하지 않아 삭제 및 수정 필터링이 작동하지 않는 버그를 발견하였습니다.
   - 이를 유연한 비교 연산자(`==`, `!=`)로 수정하고, ID를 명확하게 변환하도록 하여 문자열과 숫자에 관계없이 정확히 대상을 찾아 삭제하도록 수정하였습니다.
2. **모달 내 삭제 기능 연동 (`js/schedule.js`, `index.html`)**:
   - `openScheduleModal` 실행 시 기존 일정을 수정하는 경우에만 모달 내 삭제 버튼(`dt-schedule-modal-delete-btn`)이 노출되도록(`display: inline-block`) 상태 연동을 추가하였습니다.
   - 모달에서 삭제 버튼 클릭 시 실행되는 `deleteScheduleFromModal` 함수를 신규 구현하고, 삭제 완료 후 모달 창(`dt-schedule-modal`, `mb-schedule-modal`)이 즉시 닫히도록 개선하였습니다.
3. **4컷 약속 카드 상단 즉시 삭제 버튼 부착 (`js/schedule.js`)**:
   - 각 약속 카드 헤더 우측(D-day 뱃지 옆)에 마우스로 즉시 삭제할 수 있는 휴지통 버튼(`.strip-card-delete-btn`) HTML을 정상적으로 포함시키고, `event.stopPropagation()`을 적용하여 카드 클릭 이벤트와 충돌하지 않도록 구현하였습니다.
4. **전역 스코프 명시적 노출 (`js/schedule.js`)**:
   - `window.deleteSchedule`, `window.deleteScheduleFromModal` 등 주요 함수들을 `window` 객체에 명시적으로 노출하여 브라우저에서 인라인 이벤트 호출 시 스코프 참조 오류가 발생하지 않도록 100% 보장하였습니다.

## 작업 내용 (오후 추가 작업 9: 잔여 호버 스케일(Scale) 확대 효과 전역 제거 및 부채꼴 회전 30도 조정)
- **요구사항**: 카드나 썸네일 이동 및 호버링 중간 중간에 남아있던 불필요한 크기 확대(`scale`) 효과를 완벽히 제거하고, 부채꼴 카드 호버 시 회전 각도를 `30deg` 수준으로 상향 조정.

### 상세 수정 사항
1. **부채꼴 슬롯 카드 호버 각도 30도 조정 (`styles/space.css`, `css/desktop.css`)**:
   - 좌/우 부채꼴 카드 호버(`.polaroid-fan-slot.fan-left:hover`, `.fan-right:hover`) 시 회전 각도를 기존 `±25deg`에서 `±30deg`(`rotate(-30deg)`, `rotate(30deg)`)로 더욱 시원하고 명확하게 펼쳐지도록 상향 조정하였습니다.
2. **잔여 호버 크기 확대(Scale) 속성 전면 제거**:
   - **피드 그리드 (`css/desktop.css`)**: 짝수 번째 피드 카드 호버 시 남아있던 `scale(1.015)`를 제거하여 순수 회전(`rotate`)만 남겼습니다.
   - **Stack 및 Coverflow 뷰어 (`styles/space.css`, `css/desktop.css`)**: 사진 뷰어에서 주변 카드(`.cline-slot--past`, `.cline-slot--newer`, `.cline-slot--far-*` 등)에 마우스를 올릴 때 크기가 팽창하던 호버 스케일(`scale(0.93)`, `scale(0.90)` 등) 효과를 제거하여, 마우스 탐색 시 카드가 울렁거리거나 커지지 않고 깔끔한 원근감 유지 상태로 부드럽게 상하 이동(`translateY`)만 하도록 최적화했습니다. 또한 활성 중앙 카드(`.is-active`)의 `scale(1.04)`도 `scale(1)`로 정규화했습니다.
   - **하단 필름 스트립 썸네일 (`styles/space.css`, `css/desktop.css`)**: 썸네일 프레임(`.cline-film-frame:hover:not(.is-current)`)에 마우스를 올릴 때 세로로 늘어나던 `scaleY(1.05)` 효과를 깔끔하게 제거했습니다.
   - **인생네컷 약속 카드 (`styles/schedule.css`, `css/desktop.css`)**: 약속 목록 카드(`.fourcut-row-card:hover`) 호버 시 적용되던 `scale(1.06)` 확대 효과를 제거하고 부드러운 상하 떠오름(`translateY(-4px)`)만 유지했습니다.
3. **캐시 버스팅 갱신 (`index.html`)**:
   - `styles/space.css?v=8`, `styles/schedule.css?v=2`로 로드 버전을 갱신하여 변경 사항이 즉각 표시되도록 조치하였습니다.
