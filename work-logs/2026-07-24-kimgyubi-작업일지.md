## 1. clov-web #78 — 날짜·시각 공통 유틸 신설

**배경**: 알림 화면이 날짜 파싱 함수에 없는 필드를 넘겨 페이지 전체가 죽고 초대 수락이 막혔던 사고(PR #72)를 계기로, 화면마다 중복되던 날짜 처리 함수를 한 곳으로 모으는 팀 전체 작업의 1번 담당(다른 팀원 작업의 선행 조건).

**브랜치**: `feat/78-datetime-util`

**추가한 파일**: `src/lib/datetime.js` (신규)
- `parseUtc(value)` — 오프셋 없는 UTC 문자열에 `Z`를 붙여 `Date`로 변환, 값 없으면 `null`
- `formatDate(value)` — `2026. 07. 24` 형식
- `formatTime(value)` — `09:13` 형식
- `ddayDiff(dateStr)` — 오늘과의 날짜 차이(숫자만, 라벨 문자열은 안 만듦)
- 원칙: 값이 없거나 잘못돼도 절대 예외를 던지지 않음(전부 `null`/`''` 반환)

**검증**: `npm run lint`/`npm run build` 통과, 콘솔에서 `parseUtc(undefined)→null`, `formatDate('2026-07-24T00:13:04')→"2026. 07. 24"` 등 직접 확인.

**커밋/PR**: `d1196b5` → PR [#83](https://github.com/Pickeslog/clov-web/pull/83)(`Closes #78`) → 머지(`80618f9`).

이후 이 유틸을 팀원들이 각자 화면에 적용(#79 Feed.jsx, #80 Schedule.jsx, #81 Dashboard/RoomList/RoomPreviewModal/Notifications — 전부 다른 팀원·리더 작업, 아래 8절 참고).
