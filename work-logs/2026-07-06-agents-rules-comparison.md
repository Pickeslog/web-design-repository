# 2026-07-06 작업 로그: AGENTS.md 맞춤형 지침과 기본 설정의 차이점

## 개요
이 문서는 AI 어시스턴트에게 제안된 맞춤형 `AGENTS.md` 지침이 범용적인 기본 설정과 비교하여 어떤 차이점과 장점이 있는지 분석하여 기록한 내용입니다.

## 주요 차이점 및 장점

### 1. 사고(버그) 방지 강제성
- **기본 설정**: AI가 문맥을 유추해 자의적으로 기존 코드를 리팩토링하거나 불필요해 보이는 코드를 삭제할 위험이 있습니다.
- **맞춤형 지침**: "최소 침습"과 "가정 금지"를 명문화하여, AI가 사용자에게 묻지 않고 기존 코드를 삭제하거나 덮어쓰는 사고를 원천적으로 차단합니다.

### 2. 사용자 프로젝트 맞춤형 컨벤션 고정
- **기본 설정**: 일반적인 최신 프레임워크나 보편적인 스타일을 무작위로 제안할 수 있습니다.
- **맞춤형 지침**: "클래스 토글 방식 사용", "바닐라 웹 기술 우선" 등 사용자 고유의 규칙을 고정하여, AI가 다른 스타일로 코드를 오염시키는 것을 막아줍니다.

### 3. 작업 보폭의 물리적 제한
- **기본 설정**: 한 번의 프롬프트로 너무 넓은 범위의 수정을 시도하여, 구조적 결함이나 컨텍스트 유실이 발생하기 쉽습니다.
- **맞춤형 지침**: "한 번에 작게 쪼개서", "분석 먼저" 하도록 규칙을 강제하여, 복잡한 작업에서 AI가 길을 잃고 엉뚱한 결과물을 내는 것을 방지합니다.

## 결론
맞춤형 지침을 적용하면 AI는 단순히 "코드를 잘 짜는 조수"에서 나아가, **"사용자의 코드 스타일을 절대 어기지 않고 돌다리도 두들겨가며 일하는 안전한 조수"**로 완벽하게 통제됩니다.
