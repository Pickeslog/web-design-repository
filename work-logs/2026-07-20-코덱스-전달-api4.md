# 2026-07-20 — 코덱스 전달: API #4 (Security + JWT 기반)

> #3(응답 봉투/에러코드) 머지 후 다음 슬라이스. JWT 발급·검증 기반 + 인가 규칙.
> **사전 지뢰**: STATELESS 필터 단계의 401/403은 `@RestControllerAdvice`가 못 잡는다 → 시큐리티 핸들러가 #3 봉투를 직접 써야 한다.

## 사전 점검 메모 (리뷰 기준)

1. **필터 단계 예외 ↔ 봉투 일치** — #3 `GlobalExceptionHandler`는 컨트롤러 예외만 잡는다. 인증 필터에서 나는 401(토큰 없음/무효)·403은 Spring Security의 `AuthenticationEntryPoint`/`AccessDeniedHandler`가 처리하므로, 이들이 `{success:false, error:{code:"UNAUTHORIZED"/"FORBIDDEN", ...}}`를 **직접 써야** 봉투가 깨지지 않는다. (#3 `ApiResponse`/`ErrorCode` 재사용)
2. **jjwt 누락** — 현재 `build.gradle`에 jjwt 없음(계약 §1은 `0.12.x` 요구). 3줄 추가 필요.
3. **JWT secret** — `application-secret.example.yaml`은 현재 DB만 있다. JWT secret placeholder 추가 필요(값은 커밋 금지).
4. **role 금지** — `users`에 `role` 없음(계약 §3). JWT claim에 role 넣지 말 것. 최대 지뢰.
