**사용자 지시**: "#179 이어서 하자" 완료 후 "#155 이어서 작업할 거야. 새 브런치를 만들고 시작하자" + 리더의 착수 승인/리뷰 코멘트 전달.

**브랜치**: `feat/155-mascot-rob-interactions`

**착수 전 확인**: 계약 §12(`POST /rooms/{roomId}/mascot/interact`, 하루 3회 제한, `429 MASCOT_INTERACTION_LIMIT_REACHED`)를 재대조. 리더가 착수 승인 코멘트에서 지적한 핵심 문제 확인 — 마스코트가 `<button>`이라 클릭 한 번이 곧 API 호출 한 번인데, 이스터에그(드래그·3연타·롱홀드)를 그대로 이식하면 하루 교감 한도가 이스터에그 한 번에 소진됨.

**수정 파일**: `Mascot.jsx`(상태머신 신규), `Mascot.css`(상태별 애니메이션), `SuccessOverlay.jsx`(이스터에그 힌트 재활성화), 신규 에셋 4종(`rob-{pulled,scared,angry,dizzy}.png`, 목업 원본에서 그대로 복사 — `idle.png`가 기존 production `rob.png`와 바이트까지 동일함을 확인하고 진행)

**리더 리뷰 반영 — 교감(API 호출)과 이스터에그(로컬 연출) 분리**
- 드래그·롱홀드는 API를 아예 호출하지 않는다(포인터가 임계값 이상 움직이면 뒤이어 발화하는 click을 무시).
- 3연타는 콤보의 첫 클릭만 교감으로 보내고 2·3번째는 dizzy 판정에만 쓴다(API 호출 없음).
- `disabled` 속성 제거 — 버튼을 잠그면 연타 판정(900ms) 중간에 버튼이 죽어 dizzy 자체가 안 뜨는 문제가 있어, 버튼은 항상 눌리게 두고 뮤테이션 쪽(`interactMutation.isPending`)에서만 중복 호출을 막음.

**검증(정밀 계측)**: `fetch`/`XHR`를 몽키패치해 실제 API 호출 횟수를 직접 카운트 — 3연타 버스트에 정확히 1회, 드래그+릴리즈에 정확히 0회 확인. React 렌더 로그로 상태머신 전체 사이클도 확인(`default→scared→angry→default` 3초 뒤 자동 전환·자동 복귀, `default→dizzy→default` 1.2초 뒤 자동 복귀). 크로비는 매 클릭이 독립적으로 API를 호출해 회귀 없음 확인. `npm run lint`/`npm run build` 통과, 콘솔 에러 없음.

**PR 리뷰 템플릿 자체검토에서 발견한 것**
