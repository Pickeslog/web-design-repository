## P1 — 우정공간 메인 (프로토타입 `02-main/index.html` ↔ `Dashboard.jsx`)

프로토타입 = "살아있는 대시보드", 현재 React = "링크 허브". 갭 최대.

| 프로토타입 요소 | React 현황 | 백엔드 | 조치 |
|---|---|---|---|
| **D+day** "함께한 지 D+1일째" | ❌ | room.createdAt로 계산 | 프론트(createdAt 반환 확인) |
| 시즌/트랙 "여름 추억 재생 중·N번째 트랙" | ❌ | 없음(장식) | 프론트(월→계절, 랜덤 트랙) |

| **상태 메시지** 편집(32/40, 한20/영40) | ❌ | ✅ `PATCH /members/me/status-message` | 프론트(표시+편집) |

## 횡단 관심사 — 배너 테마 시스템 (프로토타입 feed 하단 "배너 테마 테스트")

프로토타입엔 **계절(봄/여름/가을/겨울)·시간대(아침/낮/저녁/밤)·이벤트(생일 등)·우정레벨**에 따라 배너/테마가 바뀌는 시스템이 있다. 실제 앱엔 없음.
- 계절·시간대 = 프론트에서 현재 날짜/시각으로 계산(장식). 이벤트(생일) = user birthdate. 레벨 = `/level`.
- → 디자인 토큰 + 테마 훅으로 도입 가능(P2~P3 횡단).

## 착수 전 확인할 백엔드 응답 (프론트 착수 시 1차 점검)

1. `GET /rooms/{id}` 에 **createdAt** 있나 (D+day용).
2. `GET /rooms/{id}/level` 에 **티어명**(예: 씨앗의 우정) 필드 있나, 아니면 프론트 매핑.
3. `GET /rooms/{id}/members` 에 **statusMessage** 포함되나.
4. `GET /rooms` 요약에 **다음 약속** 포함 여부(없으면 백 추가 or 프론트 조회).
5. **내 가입신청(outgoing) 목록** 엔드포인트 부재 — 요청한 방 UI엔 백 추가 필요.
