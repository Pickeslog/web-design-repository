## 0. 공통 규칙 — 모든 이슈 본문·프롬프트 맨 위에 붙인다

```
- 이름은 web-design-repository/docs/DOMAIN-NAMING-REGISTRY.md §2 표의 확정값만 쓴다.
  표에 없는 이름은 지어내지 말고 이슈에 제안한다(문서 갱신 후 진행).
- auth 슬라이스를 구조 그대로 복사하고 이름만 표대로 치환한다.
  · 백: clov-api/.../domain/auth/{controller,service,mapper,dto,entity} + resources/mapper/auth/UserMapper.xml
  · 프론트: clov-web/src/pages/auth/Login/{Login.jsx, Login.style.js} + src/api/auth.js + src/stores/authStore.js
- 공통(ApiResponse·ErrorCode·GlobalExceptionHandler·axios client.js·authStore)은 재사용한다. 2번째 버전을 만들지 않는다.
- API 경로·요청/응답·에러코드는 계약(docs/API-CONTRACT.md)의 해당 §번호를 그대로 따른다. ID는 JSON 문자열.
- 한 슬라이스 = 한 도메인만. 배정된 범위 밖은 건드리지 않는다.
- PR 본문에 `Closes #N`을 반드시 넣는다(누락 시 이슈가 자동으로 안 닫혀 수동 처리해야 함).
- main 머지에는 CI `build`가 초록이어야 한다. 로컬에서 빌드·실행 확인 후 PR을 올린다.
```
