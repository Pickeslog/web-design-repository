## 🛠️ 주요 수정 사항

### 1. 팝오버(달력 모달) 출력 오류 수정
- **문제점**: 피드 상단의 '📅 달력' 버튼 클릭 시 화면에 달력 창이 보이지 않던 현상.
- **조치 내용**: HTML 내부에 중복으로 들어가 있던 (특히 모바일 뷰어의 숨겨진 영역 내부에 존재하던) month-picker-popover HTML 코드를 삭제하여, 최상위(body) 레벨에서 모달이 정상적으로 팝업될 수 있도록 구조적 오류를 해결했습니다.

### 2. 다크모드 버튼 색상 동기화 및 명도 개선
- **문제점**: 다크모드 시 '행운 편지 작성' 버튼과 '즐겨찾기' 필터 버튼의 색상이 제각각이거나 다소 어두웠음.
- **조치 내용**: 
  - '행운 편지 작성' 버튼의 배경색을 비활성화된 '즐겨찾기' 버튼과 동일한 CSS 변수(ar(--btn-primary-bg))로 통일했습니다.
  - 해당 버튼들에 쓰이는 다크모드용 기본 배경색을 기존 딥 그린(#008535)에서 훨씬 더 화사하고 산뜻한 **에메랄드/민트 그린(#1da858)**으로 한 단계 더 밝게 상향 조정했습니다.

### 3. 라이트모드 배경 텍스트 가독성 대폭 향상
- **문제점**: 라이트모드의 밝은 배경(그라데이션) 위에 '흰색' 글자가 직접 배치되어 글씨를 읽기 매우 힘들었음.
- **조치 내용**: 
  - 모바일 뷰어 상단의 **표지 요약 텍스트**, **제목**, **D-Day 등 세부 메타 정보**의 흰색 텍스트를 모두 어두운 텍스트 색상(ar(--text-color), ar(--primary-green) 등)으로 변경했습니다.
  - 피드의 각 **섹션 제목**(예: '참여자별 추억 증거 카드', '월별 추억 아카이브' 등)과 **Clover Growth Path**(주간 약속이 자라는 길) 텍스트 역시 라이트모드에 맞게 진한 녹색 톤으로 수정했습니다.
  - 글자 주변에 남아있어 텍스트를 지저분하게 만들던 검은색 그림자(	ext-shadow)를 제거하여 글씨를 깔끔하게 다듬었습니다.
  - **다크모드 유지**: 다크모드에서는 위 텍스트들이 기존과 동일하게 밝은 흰색으로 잘 보이도록 ody.dark-mode 예외 처리 CSS 코드를 꼼꼼히 추가했습니다.

### 4. 추억피드 글쓰기 모달 UI 간소화
- **문제점**: 글쓰기 모달 내부에 사용하지 않는 고정된 템플릿 태그 버튼(#어느날, #우리들 등)들이 공간을 차지하고 있었음.
- **조치 내용**: 데스크톱과 모바일 양쪽의 글쓰기 모달 HTML 구문에서 해당 태그 선택기(	ag-picker 영역)를 완전히 삭제했습니다. 이제 사용자가 텍스트 창에 직접 커스텀 해시태그를 적는 입력란만 단독으로 표시됩니다.
