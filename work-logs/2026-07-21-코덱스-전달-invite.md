## 목표
clov-api에 **invite / join-requests 백엔드 슬라이스**를 구현한다. 이슈 **#23**. **핵심 흐름**: 코드 입력 = **입장 신청**(즉시 입장 아님) → 멤버 1명 **수락** → `room_members` 생성 → **5분 되돌리기**.

## 방식
auth 슬라이스(`domain/auth`)를 구조 그대로 복사하고 이름만 레지스트리 §2 `invite` 행의 확정값으로 치환한다. 공통(`ApiResponse`·`ErrorCode`·`GlobalExceptionHandler`)은 재사용, 재생성 금지.

## 이름 (레지스트리 §2 — 확정값만)
- `domain/invite` · `InviteController`·`JoinRequestController`·`InviteService`·`InviteMapper`·`JoinRequestMapper` (+ XML)
- Entity: `RoomInvite`(room_invites)·`RoomJoinRequest`(room_join_requests)
- XML namespace = 인터페이스 FQN, SQL id = 메서드명, `#{}`만.

## 엔드포인트 (계약 §7 — 경로/요청/응답/에러코드 그대로)
- `POST /api/v1/rooms/{roomId}/invites` 코드 생성 · `GET .../invites` 목록 · `DELETE /api/v1/invites/{inviteId}` 취소(CANCELED)
- `POST /api/v1/invites/accept` — 코드로 **입장 신청** → `room_join_requests`(PENDING) 생성, 코드 `USED`. **입장 확정 아님**.
- `GET /api/v1/rooms/{roomId}/join-requests` 대기 목록
- `POST /api/v1/join-requests/{id}/accept` — 수락 → `room_members`(ACTIVE) 생성, `accepted_by`·`undo_deadline_at`(+5분), 전 멤버 알림
- `POST /api/v1/join-requests/{id}/reject`(REJECTED)
- `POST /api/v1/join-requests/{id}/undo` — 5분 되돌리기(`undo_deadline_at` 이전만): 멤버 제거·신청 PENDING 복원. 수락한 본인만.

## 동시성 (반드시 — 이 도메인의 핵심)
- `accept`/`reject`/`undo`는 `room_join_requests.version` **낙관적 락**. 이미 처리 → `409 JOIN_REQUEST_ALREADY_PROCESSED`. 되돌리기 만료 → `409 JOIN_REQUEST_UNDO_EXPIRED`.
- **정원**: `accept` 트랜잭션에서 ACTIVE 멤버 수 `FOR UPDATE` 카운트 **≤ 8** 확인. 초과 → `409 ROOM_CAPACITY_EXCEEDED`(신청 PENDING 유지).

## 규칙
- 최대 8명 단일 구조. `role`/방장/관리자 개념 만들지 마. MyBatis `#{}`만, JPA 금지. ID는 JSON 문자열. 계약·DB DDL·시크릿 건드리지 마.
