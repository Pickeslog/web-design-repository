# 블랙스타 공방 오닉스 선택 기록 — 2026-08-03

> 오늘은 디자인 선택과 인수인계 자료 저장까지만 완료했다. 9동작 제작과 상점 등록은 다음 세션에서 이어간다.

## 1. 최종 결정

| 항목 | 확정값 |
|---|---|
| 캐릭터 | 오닉스 (`onyx`) |
| 스킨명 | 블랙스타 공방 오닉스 |
| 영문 작업명 | Blackstar Atelier Onyx |
| 등급 | 고급 (`UNCOMMON`) |
| 선택 방향 | 검은 별 망치와 가장 단순하고 선명한 실루엣 |
| 제안 skinId | `blackstar-atelier-uncommon` |
| 상태 | 디자인 확정, 구현 전 |

확정 시안은 clov-web 저장소에 보존했다.

- [시안 이미지](../../clov-web/docs/mascot-skins/onyx/blackstar-atelier-uncommon/concept.png)
- [디자인 결정 메모](../../clov-web/docs/mascot-skins/onyx/blackstar-atelier-uncommon/README.md)

## 2. 반드시 유지할 시각 요소

- 기존 오닉스의 흰 깃털, 분홍 눈, 여성스러운 인상, 장밋빛 금속 고글
- 짙은 보라색 세공사 앞치마와 청록색 한 줄 장식
- 어깨에 걸친 장밋빛 금속 망치와 망치 머리의 검은 별 보석
- 반대쪽 날개에 든 검은 오닉스 원석
- 보라색 별 충격파와 소수의 청록색 보석 파편
- 기존 마스코트와 같은 단순한 페이퍼 컷아웃 실루엣
- 고급 등급에 맞는 제한된 장식 밀도. 영웅·전설급으로 복잡하게 만들지 않는다.

## 3. 다음 세션 작업 순서

1. 보존된 `concept.png`와 `src/assets/mascot/onyx/`의 상태별 원본을 함께 참조한다.
2. `default`, `angry`, `dizzy`, `find`, `pencil`, `pulled`, `scared`, `sleepy`, `smile` 9종을 각각 생성한다.
3. 단색 크로마키 배경을 제거하고 모든 결과를 640×640 RGBA PNG로 정규화한다.
4. 아래 경로에 9종과 `metadata.json`을 저장한다.

   ```text
   clov-web/public/shop/skins/onyx/blackstar-atelier-uncommon/
   ```

5. 메타데이터는 `rarity: UNCOMMON`, `shopCategory: COSTUME`으로 작성한다.
6. `Mascot.jsx`의 `EQUIPPED_SKIN_STATE_SPRITES`에 아래 루트를 추가한다.

   ```text
   /shop/skins/onyx/blackstar-atelier-uncommon
   ```

7. 투명 가장자리와 9동작 일관성을 접촉 시트로 확인한 후 `npm run lint`, `npm run build`를 실행한다.

## 4. 아직 하지 않은 것

- 9동작 이미지 생성
- 실제 스킨 폴더와 런타임 상태 전환 연결
- 상점 가격 결정
- `shop_items` DB 행 작성·등록
- 커밋·PR·배포

가격이 정해지기 전에는 DB 상품을 임의로 만들지 않는다. DB 등록 시 `category`는 반드시 `COSTUME`, `image_url`은 `/shop/skins/onyx/blackstar-atelier-uncommon/default.png`로 맞춘다.

## 5. 작업 시 주의

- clov-web 작업 트리의 `src/pages/rooms/Dashboard/dashboard.proto.css` 변경은 다른 작업이므로 건드리거나 포함하지 않는다.
- 현재 시안 저장용 clov-web 브랜치는 `chore/save-onyx-blackstar-atelier-concept`이다.
- 생성 도중 망치, 검은 별 보석, 고글이 상태별로 사라지거나 형태가 크게 바뀌면 해당 상태만 다시 생성한다.
