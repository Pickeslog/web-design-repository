# HTML 프로토타입 검수 체크리스트

## 문서 목적

이 문서는 팀원들이 AI 에이전트로 HTML을 수정한 뒤 기능 누락이나 구조 깨짐을 빠르게 확인하기 위한 체크리스트다.

## 1. 기준본 확인

- [ ] 기준본이 `Clov - 추억피드.html`인지 확인했다.
- [ ] 참고본 기능을 가져오더라도 기준본 기능을 삭제하지 않았다.
- [ ] 새 통합 파일을 만들 때 원본을 덮어쓰지 않았다.

## 2. Clov. 구조 원칙 확인

- [ ] 우정공간을 1:1 전용/1:N 전용으로 나누지 않았다.
- [ ] 방장, 대표자, 관리자 권한 개념을 추가하지 않았다.
- [ ] 초대한 사람에게 특별 권한을 주지 않았다.
- [ ] 모든 멤버가 동등하다는 구조를 유지했다.
- [ ] 약속 완료 후 추억 작성 후보 흐름을 약화시키지 않았다.
- [ ] 친구별 관점 기록 구조를 유지했다.

## 3. HTML 구조 확인

- [ ] `<div>` 열림/닫힘 개수가 맞다.
- [ ] 중복 ID가 없다.
- [ ] 데스크톱/모바일에 필요한 영역이 모두 있다.
- [ ] 모달 ID와 `openModal()` 호출 ID가 일치한다.
- [ ] 삭제된 탭이나 누락된 탭이 없다.

## 4. CSS 확인

- [ ] 기존 CSS 변수를 최대한 사용했다.
- [ ] 라이트 모드에서 텍스트 대비가 충분하다.
- [ ] 다크 모드에서 텍스트가 형광색처럼 튀지 않는다.
- [ ] 버튼 텍스트가 배경과 충분히 구분된다.
- [ ] 모바일에서 텍스트가 버튼 밖으로 넘치지 않는다.
- [ ] 카드 높이가 과도하게 흔들리지 않는다.

## 5. JavaScript 확인

- [ ] 같은 함수명이 중복 선언되지 않았다.
- [ ] `window.onclick`을 새로 덮어쓰며 기존 닫기 로직을 삭제하지 않았다.
- [ ] `keydown` 이벤트에서 기존 `Esc` 닫기 기능이 유지된다.
- [ ] 탭 전환 함수가 정상 호출된다.
- [ ] 모달 열기/닫기 함수가 정상 호출된다.
- [ ] 월 선택 팝오버 함수가 삭제되지 않았다.
- [ ] 행운편지 즐겨찾기 토글이 상세 모달 클릭과 충돌하지 않는다.

## 6. 대시보드 클릭 테스트

- [ ] 데스크톱 우정공간 탭 진입
- [ ] 모바일 우정공간 탭 진입
- [ ] 대표 사진 수정 오버레이 클릭
- [ ] 사진 제목 편집
- [ ] 다가오는 약속 배너 클릭 시 일정계획 이동
- [ ] 전체 피드 보기 클릭 시 추억피드 이동

## 7. 추억피드 클릭 테스트

- [ ] 데스크톱 추억피드 탭 진입
- [ ] 모바일 추억피드 탭 진입
- [ ] 전체/내 기록/친구 기록 필터 전환
- [ ] 월별 레일 버튼 클릭
- [ ] 월 선택 팝오버 열기
- [ ] 이전/다음 연도 이동
- [ ] 특정 월 선택
- [ ] 팝오버 외부 클릭 닫기
- [ ] `Esc`로 팝오버 닫기
- [ ] 글쓰기 모달 열기
- [ ] 추억 등록
- [ ] 긴 기록 더보기 열기
- [ ] 바텀시트 닫기

## 8. 행운편지 클릭 테스트

현재 기준본:

- [ ] 전체 편지 필터 클릭
- [ ] 즐겨찾기 필터 클릭
- [ ] 별 버튼으로 즐겨찾기 토글
- [ ] 즐겨찾기 편지가 없을 때 안내 문구 표시

병합 후:

- [ ] 편지 작성 버튼 클릭
- [ ] 작성 모달 열림
- [ ] 받는 사람 입력
- [ ] 모두에게 보내기 선택
- [ ] 보낸 사람 입력
- [ ] 이모지 선택
- [ ] 내용 입력 시 미리보기 표시
- [ ] 편지 보내기
- [ ] 목록에 새 편지 표시
- [ ] 편지 카드 클릭 시 상세 모달 열림
- [ ] 별 버튼 클릭 시 상세 모달이 열리지 않음
- [ ] 상세 모달 닫기

## 9. 일정계획 클릭 테스트

- [ ] 일정계획 탭 진입
- [ ] 새 D-day 만들기 모달 열기
- [ ] 일정 제목 입력
- [ ] 날짜 입력
- [ ] 빠른 날짜 선택 칩 클릭
- [ ] 일정 저장
- [ ] 일정 카드 선택
- [ ] 표시 밀도 전환
- [ ] 일정 수정
- [ ] 일정 삭제
- [ ] 대시보드 배너와 동기화 확인

## 10. 다크모드 테스트

- [ ] 데스크톱 다크모드 토글
- [ ] 모바일 다크모드 토글
- [ ] 대시보드 배경이 밤 모드로 바뀜
- [ ] 추억 카드 텍스트 가독성 유지
- [ ] 행운편지 텍스트 가독성 유지
- [ ] 일정 카드 텍스트 가독성 유지
- [ ] 버튼 텍스트 대비 유지

## 11. 반응형 테스트

- [ ] 데스크톱 프레임에서 레이아웃이 깨지지 않음
- [ ] 모바일 프레임에서 가로 스크롤이 과도하지 않음
- [ ] 모바일 카드가 너무 작아지지 않음
- [ ] 터치 버튼 간격이 충분함
- [ ] 모달이 화면 밖으로 넘치지 않음
- [ ] 바텀시트가 모바일에서 자연스럽게 보임

```md
- 

확인 필요:
- 

다음 작업:
- 
```
