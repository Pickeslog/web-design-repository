# Claude 디자인 프레임워크 입력 프롬프트 템플릿

## 문서 목적

이 문서는 `screen-spec-source` 문서를 Claude 디자인 프레임워크에 넣을 때 사용할 프롬프트 템플릿이다.

HTML 전체를 붙여넣는 대신, 필요한 문서 조합과 요청 형식을 정리한다.

## 기본 원칙

- HTML 전체를 먼저 넣지 않는다.
- 서비스 요약과 디자인 시스템을 먼저 넣는다.
- 한 번에 한 화면만 명세화한다.
- 필요할 때만 HTML 일부를 추가한다.
- 산출물 형식을 명확히 요청한다.

## 공통 시작 프롬프트

```text
너는 Clov. 서비스의 화면명세서를 작성하는 UX 기획자야.

Clov.는 "약속이 추억으로 자라는 친구 전용 기록공간"이라는 컨셉의 서비스야.
아래 문서들을 기준으로 화면명세서를 작성해줘.

중요 원칙:
- 우정공간은 인원 제한 없는 단일 구조야.
- 1:1 전용/1:N 전용으로 나누지 않아.
- 방장/대표자/초대한 사람 권한 개념은 없어.
- 모든 멤버는 동등해.
- 핵심 차별점은 약속 완료 후 추억 작성 후보로 전환되는 흐름이야.
- 같은 약속에 대해 친구별로 다른 관점의 기록을 남길 수 있어.

HTML 코드 설명이 아니라 실제 개발과 디자인에 넘길 수 있는 화면명세서 형태로 작성해줘.
```

## HTML 일부를 추가해야 하는 경우

HTML 일부를 추가할 때는 전체 파일을 넣지 말고 아래 단위로만 넣는다.

- 해당 화면의 HTML 영역
- 해당 화면의 CSS 영역
- 해당 화면의 JS 함수 몇 개

예시:

```text
아래는 기준 HTML 중 추억피드 월 선택 팝오버 부분만 발췌한 코드야.
이 코드를 참고해서 명세서의 UI 동작 설명을 더 정확히 보강해줘.
```
