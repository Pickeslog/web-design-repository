# HTML 기준본 병합 계획

## 문서 목적

이 문서는 현재 분리되어 있는 HTML 프로토타입을 하나의 기준본으로 정리하기 위한 병합 계획이다.

## 현재 파일 상태

### 기준본

파일:

```text
C:\gov\project\clov-계획서\화면구상html\Clov - 추억피드.html
```

기준본으로 삼는 이유:

- 추억피드 월별 아카이브가 포함되어 있다.
- iOS 스타일 월 선택 팝오버가 포함되어 있다.
- 긴 기록 더보기 바텀시트가 포함되어 있다.
- 일정계획의 `Clover Growth Path`가 포함되어 있다.
- Clov.의 핵심 차별점인 약속-추억 흐름을 가장 잘 설명한다.

### 참고 분기

파일:

```text
C:\gov\project\clov-계획서\화면구상html\Clov - 행운 편지.html
```

참고하는 이유:

- 행운편지 작성 모달이 포함되어 있다.
- 행운편지 상세 모달이 포함되어 있다.
- To/From, 이모지 선택, 미리보기가 포함되어 있다.
- 편지 즐겨찾기 빈 화면과 버튼 색상 보정이 반영되어 있다.

## 병합 원칙

- 기준본은 `Clov - 추억피드.html`로 유지한다.
- 참고 분기에서 행운편지 관련 기능만 가져온다.
- 추억피드 월 선택 팝오버와 행운편지 모달 닫기 로직이 충돌하지 않게 합친다.
- 병합 후 새 파일명은 `Clov - 통합기준본.html`을 권장한다.
- 기존 원본 파일은 덮어쓰지 않는다.

## 병합 대상 목록

### 1. CSS 변수

참고 분기에서 가져올 항목:

- `--btn-primary-bg`

라이트 모드:

- 중간 톤 초록색

다크 모드:

- 선명하지만 눈부시지 않은 초록색

적용 대상:

- 주요 버튼
- 행운편지 필터 버튼

### 2. 행운편지 전용 CSS

가져올 항목:

- `.letter-emoji-picker`
- `.letter-emoji-chip`
- `.letter-preview`
- `.letter-preview-label`
- `.letter-preview-content`
- `.letter-send-success`

### 3. 행운편지 탭 UI

데스크톱:

- 편지 작성 버튼 추가
- 안내 문구 변경
- 편지 목록 1열 구조 검토

모바일:

- 편지 작성 버튼 추가
- 안내 문구 변경
- 편지 목록 세로 배치

### 4. 데스크톱 행운편지 모달

가져올 모달:

- `dt-letter-modal`
- `dt-letter-detail-modal`

### 5. 모바일 행운편지 모달

가져올 모달:

- `mb-letter-modal`
- `mb-letter-detail-modal`

### 6. 행운편지 JS 함수

가져올 함수:

- `openLetterModal`
- `toggleLetterToAllBtn`
- `selectLetterEmoji`
- `updateLetterPreview`
- `submitLetter`
- `openLetterDetailModal`

기존 함수 수정:

- `renderLetters`

수정 방향:

- 편지 카드 클릭 시 상세 모달 열기
- 별 버튼 클릭은 상세 모달이 열리지 않게 이벤트 전파 중단
- To 필드가 없는 기존 샘플 데이터도 `모두`로 표시

### 7. window.onclick 병합

기준본의 동작:

- 프로필 드롭다운 닫기
- 월 선택 팝오버 외부 클릭 닫기

참고 분기의 동작:

- 프로필 드롭다운 닫기
- 모달 오버레이 클릭 닫기

병합 후 동작:

- 프로필 드롭다운 닫기
- 월 선택 팝오버 외부 클릭 닫기
- 모달 오버레이 클릭 닫기

### 8. keydown 병합

기준본의 동작:

- `Esc`로 추억 상세 바텀시트 닫기
- `Esc`로 월 선택 팝오버 닫기

병합 후 유지:

- 위 동작 유지
- 필요 시 열린 모달 닫기 정책 추가

## 병합 후 검증 체크리스트

### 구조 검증

- `<div>` 열림/닫힘 개수 일치
- 모달 ID 중복 없음
- 데스크톱/모바일 모달 모두 존재
- 함수 이름 중복 충돌 없음

### 기능 검증

- 대시보드 탭 전환
- 추억피드 탭 전환
- 행운편지 탭 전환
- 일정계획 탭 전환
- 월 레일 필터
- 월 선택 팝오버
- 추억 더보기 바텀시트
- 행운편지 작성
- 행운편지 상세 보기
- 즐겨찾기 토글
- 다크모드 전환

### 브라우저 클릭 검증

- 데스크톱 편지 작성
- 모바일 편지 작성
- 데스크톱 월 선택 팝오버
- 모바일 월 선택 팝오버
- 모달 바깥 클릭 닫기
- `Esc` 닫기

## 병합 산출물 추천

```text
Clov - 통합기준본.html
Clov - 통합기준본_검증메모.md
```

## 팀 공유 문장

```text
HTML 기준본은 `Clov - 추억피드.html`로 잡고, `Clov - 행운 편지.html`에서는 행운편지 작성/상세 모달과 버튼 색상 개선만 병합한다.
추억피드와 일정계획은 서비스 핵심 흐름이므로 기준본에서 유지하고, 행운편지는 기능 누락분만 보강한다.
```
