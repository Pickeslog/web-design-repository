# 우정공간 대시보드 화면 명세 소스

## 화면 목적

우정공간 대시보드는 사용자가 특정 우정공간에 들어왔을 때 가장 먼저 보는 홈 화면이다.

친구들과 함께한 시간, 우정 레벨, 대표 사진, 최근 기록, 다가오는 약속을 한눈에 보여준다.

## 핵심 메시지

- 이 공간은 친구들과의 관계가 쌓이는 장소다.
- 약속과 추억이 연결되어 우정 레벨로 표현된다.
- 대표 사진과 최근 기록으로 우정공간의 현재 상태를 빠르게 파악한다.

## 주요 영역

### 1. 우정 성장 대시보드

함께한 날수와 우정 레벨 진행 상황을 보여주는 상단 배너다.

HUD 요소:

- 함께한 날수 `D+N일째`
- 레벨 진행 바 `.lv-pill`

역할:

- 친구들과 함께한 시간과 관계 성장을 시각적으로 보여준다.

상태:

- 레벨 변화: 배지명, 진행률 변경

### 2. 대표 사진 카드

구성:

- 대표 사진
- 사진 수정 오버레이
- 우정공간 대표 커버 라벨
- 편집 가능한 사진 제목
- 참여 멤버 아바타 스택
- 요약 메타 정보

요약 메타 예시:

- 최근 근황
- 참여 기록
- 다가오는 약속

역할:

- 우정공간을 대표하는 감정적 커버 역할을 한다.
- 사진이 단순 이미지가 아니라 공간의 현재 분위기를 보여주는 요소가 된다.

사용자 액션:

- 대표 사진 클릭 또는 오버레이 클릭: 사진 업로드 트리거
- 제목 편집 후 포커스 해제: 제목 저장

### 3. 다가오는 약속 배너

구성:

- 일정 아이콘
- 일정 제목
- 일정 날짜
- D-day 배지

역할:

- 가장 가까운 약속을 홈 화면에서 바로 보여준다.
- 클릭하면 일정계획 화면으로 이동한다.

예외 상태:

- 등록된 일정이 없으면 "등록된 일정이 없습니다" 성격의 안내를 보여준다.

### 4. 참여자별 추억 증거 카드 — 겹침 카드 / 빨랫줄 / 일기장 + 카메라 필름 스트립

> **최신 구현**: 증거 카드 표현은 **테마 3종**으로 확장되었고 기본값은 **겹침 카드(coverflow)** 다(사용자설정에서 빨랫줄/일기장으로 변경 가능). 아래 빨랫줄 서술은 3종 중 하나(wire)의 상세다. 화면별 상세 → [index.md](../test-web-design/02-main/index.md) · 테마 선택 → [사용자설정](../test-web-design/08-profile/profile_edit.md)

기준본 초안 단계의 단순 그리드 미리보기 대신, 빨랫줄(clothesline)에 폴라로이드를 집게로 걸어둔 형태(wire 테마)로 구체화되었다. (팬(fan) 형태로 부채꼴로 펼치는 시안이 중간에 시도되었으나, 전환이 직관적이지 않아 빨랫줄 방식으로 되돌아갔다.)

구성:

- 섹션 타이틀
- 전체 피드 보기 버튼
- 빨랫줄(와이어) + 빈티지 필름 집게 SVG
- 폴라로이드 카드 슬롯: 데스크톱 5장(far-past ~ far-newer), 모바일 3장(past ~ newer)
  - 현재(current) 카드: 정면, 확대, 완전 불투명
  - 인접(past/newer) 카드: 좌우로 회전, 채도/밝기 낮춤
  - 양 끝(far-past/far-newer) 카드: 더 작고 흐리게
  - 카드 내부: 참여자 아바타(최대 4명, 초과 시 `+N`), 날짜, 사진(4:5 비율), 제목, 위치, 해시태그
- ◁ ▷ 이동 버튼으로 카드 전환
- 하단 카메라 필름 스트립: 과거 → 현재 순서로 전체 게시글 썸네일 나열, 클릭 시 해당 게시글로 즉시 이동, 현재 프레임은 초록 테두리+glow로 강조
- 컨테이너 배경은 투명(글래스모피즘/블러/큰 border-radius/외곽 그림자 없음) — 와이어·집게·폴라로이드·필름 스트립 자체 디자인만으로 구성

역할:

- 우정공간 홈에서 최근 추억 기록을 시간순으로 탐색하며 미리 보여준다.
- 전체 기록은 추억피드 탭에서 확인하도록 유도한다.

### 5. 마스코트 · 경험치(현재 구현 추가)

- **마스코트**: 크로비(따뜻함) / 롭(디스토피아 AI). 사용자설정에서 선택.
  - **기본 교감**: 클릭 시 좌우로 흔들리는 애니메이션 + 캐릭터별 고유 대사, 경험치(+2, 하루 3회).
  - **연타(어지러움)**: 0.9초 내 3회 연속 클릭 시 빙글빙글 도는 모습으로 전환(로봇은 주변에 글리치 파편 효과), 1.2초 후 원상 복구.
  - **방치(졸음)**: 20초간 입력이 없으면 눈을 감고 잠든 모습("Zzz…")으로 전환, 입력 감지 시 즉시 깨어남. 방치 중 8~15초 사이 랜덤 시점에 혼잣말이 잠시 나타났다 사라짐.
  - **드래그(롭 전용)**: 머리를 클릭한 채 드래그하면 늘어나는 모습으로 반응, 150px 이상 들어올리면 무서워하다가 3초 이상 지속 시 화내며 사용자 손을 뿌리치고 떨어짐.
  - **생일 당일**: 클릭했을 때만 축하 말풍선으로 전환(본인/친구 생일 구분).
- **우정 레벨/경험치 바**: 마스코트 교감(+2, 하루 3회) · 약속 등록(+3) · 약속 완료(+15) · 추억 게시글 작성(기본 +25, 사진 첨부 1장당 +1·최대 +10, 본문 50자↑ +5/100자↑ +10 중 도달한 최고 구간 1개만)으로 XP 적립. 우정공간 내 누적 게시글 수에 따라 이 모든 획득 XP 자체가 가속되는 스노우볼 구조다: 30개 돌파 x1.2 / 50개 돌파 x1.5 / 70개 돌파 x2.0 / 100개 돌파 x3.0. 매일 최초 접속 시에는 `(누적 게시물 수 × 0.5) + (다가올 일정 수 × 1)` 공식으로 계산된 패시브 경험치가 자동 지급된다("기억의 샘" — "어제 남겨둔 추억들 덕분에 클로브가 이만큼 자랐어요!" 팝업). 100% 초과 시 연속 레벨업(초과분 이월), 레벨에 따라 `--level-accent` 색 진화.
  - **레벨업 연출**: 기본 레벨업은 파동(`.levelup-pulse`)·뱃지 반짝임 + "(가속 x1.5)" 등 성장 말풍선. 111/222 등 111단위 마일스톤은 소규모 폭죽 펄스(3~4회 연속) + 테마 컬러 진화 컷씬 + 기념 뱃지. 777 만렙은 화면 6곳(정중앙·네 모서리·마스코트 중심)에서 대규모 폭죽 펄스와 함께 전용 축하 대사("대단합니다! 클로버가 엄청난 진화를 거쳐 만렙(Lv.777)에 도달했습니다!" 등).
  - **만렙(777) 이후**: 더 이상 XP는 오르지 않고, 마스코트 클릭 시 빨간 하트 파티클 7개가 위로 퍼지는 전용 반응(예: "사랑이 넘치는 우리 우정! 하트를 받았어 ❤️"), 게시글/일정/4컷완성 시 노란 별 파티클 12개가 3초간 화면 밖으로 퍼지는 전용 반응(예: "우리의 추억이 반짝거려! ✨")으로 대체된다.
- **생일 이벤트**: 본인 또는 방 멤버의 생일 당일에만 배너 영역에 파티클 효과가 나타난다(본인 생일은 풍선까지 함께 올라감, 친구 생일은 파티클만). 축하 대사는 배너가 아니라 마스코트를 클릭했을 때만 출력되며, 경험치 상승분이 있으면 대사에 함께 조합되어 노출된다.
- 화면별 상세 → [index.md](../test-web-design/02-main/index.md)

### 6. 참여 멤버(현재 구현 추가)

- 대표 커버의 **겹침 아바타 + "N명 함께하는 중"** → 클릭 시 **참여 멤버 리스트 모달**(상태메시지·초대 코드 복사). 가입 수락 시 멤버 수·아바타 동적 반영. → [알림](../test-web-design/07-notification/notification.md)

## 사용자 액션

- `Clov.` 로고 클릭: 우정공간 탭으로 이동
- 대시보드 레벨 배지 클릭: 프로토타입에서는 우정 레벨 변경
- 대표 사진 변경
- 대표 사진 제목 편집
- 다가오는 약속 배너 클릭: 일정계획 탭 이동
- 전체 피드 보기 클릭: 추억피드 탭 이동
- ◁ ▷ 이동 버튼 클릭: 빨랫줄 폴라로이드 카드 전환
- 필름 스트립 썸네일 클릭: 해당 게시글로 바로 이동
- 프로필 드롭다운에서 그룹 변경 또는 초대코드 확인

## 데이터 항목

우정공간:

- 이름
- 아이콘
- 함께한 날짜 수
- 우정 레벨
- 레벨 이름
- 진행률
- 대표 사진 URL
- 대표 사진 제목
- 일정 목록
- 추억 게시글 목록
- 행운편지 목록

## 데스크톱/모바일 차이

데스크톱:

- 대표 사진과 요약 정보가 넓은 카드 안에서 안정적으로 배치된다.
- 추억 미리보기는 그리드 형태로 보인다.

모바일:

- 세로 스크롤 중심이다.
- 대표 사진과 요약 정보가 더 압축된 형태로 보인다.
- 터치 영역과 카드 간격을 우선한다.

## 명세 작성 시 강조할 점

- 대시보드는 단순 프로필 홈이 아니라 "관계가 자라는 상태판"이다.
- 우정공간은 모든 멤버가 동등한 구조이므로 방장/관리자 UI를 넣지 않는다.
- 약속과 추억이 같은 흐름 안에 있다는 점을 배너와 미리보기로 보여준다.
- 참여자별 추억 증거 카드의 "빨랫줄 폴라로이드 + 필름 스트립" 콘셉트는 일정계획 화면의 "포토부스 인생4컷 카드"([05-schedule-screen.md](05-schedule-screen.md))와 서로 다른 영역이므로 혼동하지 않는다. 우정공간은 "추억 탐색/보관" UI, 일정계획은 "약속 인증 과정" UI다.
