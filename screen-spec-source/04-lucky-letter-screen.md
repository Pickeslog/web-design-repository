# 행운편지 화면 명세 소스

## 화면 목적

행운편지는 우정공간 멤버들이 서로에게 짧은 응원과 마음을 남기는 보관함 화면이다.

기준본인 `Clov - 추억피드.html`에서는 즐겨찾기와 필터 중심의 기본 보관함 형태가 반영되어 있다.

## 현재 기준본 상태

포함됨:

- 행운편지 탭
- 전체 편지 필터
- 즐겨찾기 필터
- 편지 목록 렌더링
- 별 버튼으로 즐겨찾기 토글
- 즐겨찾기 없음 안내 문구

기준본에는 아직 없음:

- 편지 작성 모달
- 편지 상세 모달
- To/From 입력
- 이모지 선택
- 실시간 편지 미리보기

위 항목은 `Clov - 행운 편지.html` 분기에서 추후 병합할 대상이다.

## 핵심 메시지

- 행운편지는 친구에게 가볍게 마음을 전하는 공간이다.
- 중요한 편지는 즐겨찾기로 따로 모아볼 수 있다.
- 추억피드가 사건과 기록 중심이라면, 행운편지는 감정과 응원 중심이다.

## 주요 영역

### 1. 행운편지 헤더

구성:

- 화면 타이틀
- 설명 문구

기준본 문구 방향:

```text
하루에 한 번 서로에게 랜덤 응원 문구를 보낼 수 있습니다.
```

병합 후 권장 문구:

```text
마음을 담은 행운 편지를 직접 작성해 보내보세요.
```

### 2. 필터 버튼

구성:

- 전체 편지
- 즐겨찾기

역할:

- 전체 편지 목록과 즐겨찾기 목록을 전환한다.

상태:

- 활성 필터
- 비활성 필터

### 3. 편지 목록

기준본 카드 구성:

- 즐겨찾기 별 버튼
- 보낸 사람
- 편지 본문

병합 후 권장 카드 구성:

- 즐겨찾기 별 버튼
- 받는 사람
- 보낸 사람
- 편지 본문 미리보기
- 카드 클릭 시 상세 모달

### 4. 즐겨찾기 빈 화면

현재 기준본:

- 작은 muted 텍스트로 안내

병합 후 권장:

- 글자 크기를 키운다.
- 가독성을 높인다.
- 라이트/다크 모드에서 잘 보이도록 색상 대비를 보정한다.

문구:

```text
즐겨찾기한 편지가 없습니다. 편지 우상단의 별을 눌러 즐겨찾기해 보세요!
```

## 병합 예정: 편지 작성 모달

구성:

- 받는 사람 입력
- 모두에게 보내기 버튼
- 보낸 사람 입력
- 편지 내용 입력
- 편지 장식 이모지 선택
- 실시간 미리보기
- 취소 버튼
- 편지 보내기 버튼

상태:

- 빈 입력
- 모두에게 보내기 활성
- 이모지 선택
- 내용 입력 시 미리보기 표시
- 제출 성공
- 내용 미입력 에러

## 병합 예정: 편지 상세 모달

구성:

- 모달 타이틀
- To
- From
- 편지 전체 내용
- 닫기 버튼

역할:

- 목록에서는 짧게 보고, 상세 모달에서 편지를 온전히 읽는다.

## 사용자 액션

현재 기준본:

- 전체 편지 클릭: 전체 목록 표시
- 즐겨찾기 클릭: 즐겨찾기 편지만 표시
- 별 클릭: 즐겨찾기 토글

병합 후:

- 편지 작성 클릭: 작성 모달 열기
- 편지 보내기 클릭: 편지 목록에 추가
- 편지 카드 클릭: 상세 모달 열기
- 모달 바깥 클릭: 닫기

## 데이터 항목

편지:

- 받는 사람
- 보낸 사람
- 본문
- 장식 이모지
- 즐겨찾기 여부

## 데스크톱/모바일 차이

데스크톱:

- 편지 목록은 넓은 영역에 카드 형태로 배치한다.
- 작성/상세 모달은 중앙 박스로 띄운다.

모바일:

- 편지 목록은 세로 리스트로 배치한다.
- 모달은 화면 폭에 맞게 압축한다.
- 입력 필드와 버튼은 터치하기 쉬운 크기를 유지한다.

## 명세 작성 시 강조할 점

- 행운편지는 핵심 기록 흐름의 보조 감성 기능이다.
- 추억피드보다 가볍고 따뜻한 톤을 유지한다.
- 권한 구조를 만들지 않는다. 모든 멤버가 편지를 쓰고 읽을 수 있는 동등한 관계다.
