# 행운편지 화면 명세 소스

## 화면 목적

행운편지는 우정공간 멤버들이 서로에게 짧은 응원과 마음을 남기는 보관함 화면이다.

> 기존 명세는 기준본(`Clov - 추억피드.html`)의 즐겨찾기/필터 중심 초기 상태를 기준으로, 작성 모달·상세 모달·To/From·이모지·미리보기를 "병합 예정" 항목으로 분리해 두었다. 실제 구현(`test-web-design/02-main/index.html`)에서는 이 기능들이 이미 반영되어 있으며, 아래는 그 최신 구조다. 화면별 상세 → [letter_detail.md](../test-web-design/05-letter/letter_detail.md)

## 현재 구현 상태

포함됨:

- 행운편지 탭
- 전체 편지 / 즐겨찾기 / 편지 쓰기, 3개 필터(토글) 버튼
- 편지 목록 렌더링
- 별 버튼으로 즐겨찾기 토글
- 즐겨찾기 없음 안내 문구
- 편지 작성(인라인 토글 폼): 받는 사람, 모두에게 보내기, 보낸 사람, 편지 내용, 장식 이모지, 실시간 미리보기, 편지 보내기
- 편지 상세는 별도 페이지(`05-letter/letter_detail.html`)로 이동해 확인

## 핵심 메시지

- 행운편지는 친구에게 가볍게 마음을 전하는 공간이다.
- 중요한 편지는 즐겨찾기로 따로 모아볼 수 있다.
- 추억피드가 사건과 기록 중심이라면, 행운편지는 감정과 응원 중심이다.

## 주요 영역

### 1. 행운편지 헤더

구성:

- 화면 타이틀
- 설명 문구

문구 방향:

```text
마음을 담은 행운 편지를 직접 작성해 보내보세요.
```

### 2. 필터 버튼 (전체 / 즐겨찾기 / 편지 쓰기)

구성:

- 전체 편지
- 즐겨찾기
- 편지 쓰기

역할:

- 전체 편지 목록, 즐겨찾기 목록, 편지 작성 화면을 전환한다.
- `편지 쓰기`를 선택하면 편지 목록 영역이 숨겨지고 같은 자리에 작성 폼이 표시된다 (별도 팝업 모달이 아니라 인라인 전환).

상태:

- 활성 필터
- 비활성 필터

### 3. 편지 목록

카드 구성:

- 즐겨찾기 별 버튼
- 받는 사람 (`To.`, 미지정 시 `전체`)
- 보낸 사람 (`From.`)
- 편지 본문

역할:

- 카드를 클릭하면 `letter_detail.html`로 이동해 편지 전체 내용을 확인한다.

### 4. 즐겨찾기 빈 화면

문구:

```text
즐겨찾기한 편지가 없습니다. 편지 우상단의 별을 눌러 즐겨찾기해 보세요!
```

- 글자 크기와 가독성을 확보하고, 라이트/다크 모드 모두에서 색상 대비를 보정한다.

### 5. 편지 작성 (인라인 폼)

`편지 쓰기` 필터를 선택했을 때 표시되는 인라인 폼이다. 별도 오버레이 모달이 아니라 편지 탭 안에서 목록 대신 나타난다.

구성:

- 받는 사람 입력
- 모두에게 보내기 토글 버튼 (누르면 받는 사람 입력이 비활성화되고 전체 수신으로 전환)
- 보낸 사람 입력
- 편지 내용 입력
- 편지 장식 이모지 선택 칩
- 실시간 미리보기 (받는 사람/보낸 사람/내용/이모지가 입력될 때마다 갱신)
- 편지 보내기 버튼

상태:

- 빈 입력
- 모두에게 보내기 활성
- 이모지 선택
- 내용 입력 시 미리보기 표시
- 제출 성공 (편지 목록 맨 앞에 추가되고 필터가 `전체`로 돌아감)
- 내용 미입력 에러 (`편지 내용을 작성해주세요! ✍️`)

### 6. 편지 상세 페이지 (`letter_detail.html`)

목록 카드를 클릭하면 모달이 아니라 별도 페이지로 이동한다. URL 파라미터로 데이터를 전달한다.

| 파라미터 | 내용 |
|---|---|
| `groupId` | 현재 그룹 ID (뒤로가기 시 복원용) |
| `index` | 편지 인덱스 |
| `theme` | 다크모드 동기화 (`dark` / `light`) |

구성:

- 발신자 레이블: `내 기록` 또는 친구 이름
- 편지 본문 전체 (줄바꿈 보존)
- ⭐ 즐겨찾기 토글
- 🗑 편지 삭제 (삭제 후 목록으로 자동 복귀)
- ✕ 닫기 (목록으로 복귀)

닫기/삭제 시 이동 대상:

```text
../02-main/index.html?selectedGroup={groupId}&theme={theme}
```

## 사용자 액션

- 전체 편지 클릭: 전체 목록 표시
- 즐겨찾기 클릭: 즐겨찾기 편지만 표시
- 편지 쓰기 클릭: 작성 폼으로 전환
- 별 클릭: 즐겨찾기 토글
- 모두에게 보내기 클릭: 받는 사람 입력 비활성화
- 이모지 칩 클릭: 편지 장식 이모지 선택, 미리보기 갱신
- 편지 보내기 클릭: 편지 목록에 추가 후 전체 목록으로 전환
- 편지 카드 클릭: 상세 페이지(`letter_detail.html`)로 이동
- 상세 페이지에서 닫기/삭제: 메인 화면으로 복귀

## 데이터 항목

편지:

- 받는 사람
- 보낸 사람
- 본문
- 장식 이모지
- 즐겨찾기 여부

## 데스크톱/모바일 차이

데스크톱:

- 편지 목록은 넓은 영역에 카드 형태로 배치한다.
- 작성 폼은 목록과 같은 폭의 인라인 영역에 표시한다.

모바일:

- 편지 목록은 세로 리스트로 배치한다.
- 작성 폼은 화면 폭에 맞게 압축한다.
- 입력 필드와 버튼은 터치하기 쉬운 크기를 유지한다.

## 명세 작성 시 강조할 점

- 행운편지는 핵심 기록 흐름의 보조 감성 기능이다.
- 추억피드보다 가볍고 따뜻한 톤을 유지한다.
- 권한 구조를 만들지 않는다. 모든 멤버가 편지를 쓰고 읽을 수 있는 동등한 관계다.
- 편지 작성은 팝업 모달이 아니라 탭 내 인라인 전환, 편지 상세는 모달이 아니라 별도 페이지 이동이라는 점을 다른 화면(추억피드 등)의 모달 패턴과 혼동하지 않는다.
