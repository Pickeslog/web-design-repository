# 공통 모달 및 인터랙션 명세 소스

## 문서 목적

이 문서는 `Clov - 추억피드.html` 기준본에서 여러 화면이 공유하는 모달, 팝오버, 바텀시트, 탭 전환, 다크모드 인터랙션을 정리한다.

## 공통 탭 전환

데스크톱 탭:

- 우정공간
- 추억피드
- 행운편지
- 일정계획

모바일 탭:

- 우정공간
- 추억피드
- 행운편지
- 일정계획

동작:

- 탭 클릭 시 해당 화면만 활성화한다.
- 활성 탭 버튼에 강조 스타일을 적용한다.
- 데스크톱과 모바일은 같은 데이터를 공유한다.

## 프로필 드롭다운

구성:

- 프로필 버튼
- 그룹 변경
- 친구 초대코드

동작:

- 프로필 버튼 클릭 시 드롭다운 토글
- 화면 바깥 클릭 시 닫힘

## 그룹 변경 모달

목적:

- 현재 보고 있는 우정공간을 전환한다.

구성:

- 우정공간 목록 버튼
- 닫기 버튼

동작:

- 그룹 선택 시 activeGroup 변경
- 대시보드, 추억피드, 행운편지, 일정계획 데이터가 모두 갱신된다.
- 모달 닫힘

주의:

- 그룹 변경은 프로토타입 검토용이다.
- 실제 서비스에서는 우정공간 리스트/초대/참여 흐름으로 재설계될 수 있다.

## 초대코드 모달

목적:

- 친구를 우정공간에 초대하는 흐름을 표현한다.

구성:

- 초대코드 입력 또는 표시 영역
- 닫기 버튼
- 연동하기 버튼

주의:

- 초대한 사람이 방장 권한을 갖는 구조로 해석하지 않는다.
- 초대는 참여 수단일 뿐 권한 차이를 만들지 않는다.

## 추억 글쓰기 모달

목적:

- 새 추억 게시글을 작성한다.

구성:

- 제목 입력
- 내용 입력
- 해시태그 선택
- 커스텀 해시태그 입력
- 취소 버튼
- 등록 버튼

동작:

- 제목과 내용 입력
- 태그 선택
- 등록 시 추억 목록에 추가
- 피드 재렌더링
- 모달 닫힘

예외:

- 제목 또는 내용이 비어 있으면 등록하지 않는다.

## 일정 모달

목적:

- 새 D-day를 만들거나 기존 D-day를 수정한다.

구성:

- 일정 제목 입력
- 날짜 입력
- 빠른 날짜 선택 칩
- 취소 버튼
- 저장 버튼

동작:

- 새 일정 등록
- 기존 일정 수정
- 저장 후 대시보드 일정 배너와 일정계획 화면 동기화

예외:

- 제목 또는 날짜 미입력 시 안내

## 추억 상세 바텀시트

목적:

- 카드에 다 담기 어려운 긴 기록을 안정적으로 읽는다.

구성:

- 배경 오버레이
- 하단 시트
- 핸들
- 제목
- 날짜
- 본문
- 태그
- 닫기 버튼

열림:

- 추억 카드의 더보기 버튼 클릭

닫힘:

- 닫기 버튼
- 배경 클릭
- `Esc`

## 월 선택 팝오버

목적:

- 추억피드에서 원하는 월로 빠르게 이동한다.

구성:

- 달력 아이콘 트리거
- 팝오버
- 이전 연도 버튼
- 현재 연도
- 다음 연도 버튼
- 1월~12월 버튼
- 월별 기록 개수

열림:

- 월 선택 아이콘 클릭

닫힘:

- 외부 클릭
- 월 선택
- `Esc`

동작:

- 월 버튼 클릭 시 `activeFeedMonth` 변경
- 추억피드 재렌더링
- 월 요약 배지 업데이트

## 다크모드

목적:

- 라이트/다크 모드 전환으로 다른 분위기에서도 화면을 확인한다.

동작:

- 다크모드 버튼 클릭
- `body.dark-mode` 클래스 토글
- 버튼 아이콘 애니메이션
- 카드, 텍스트, 배경 색상 전환

주의:

- 다크모드에서는 카드 내부 텍스트 가독성을 우선한다.
- 형광 초록처럼 눈에 피로한 색은 피한다.

## 닫기/외부 클릭 정책

기준본에서 확인된 닫기 방식:

- 프로필 드롭다운: 외부 클릭 시 닫힘
- 월 선택 팝오버: 외부 클릭 또는 `Esc`로 닫힘
- 추억 상세 바텀시트: 배경 클릭 또는 `Esc`로 닫힘
- 일반 모달: 닫기/취소 버튼 중심

병합 예정:

- 행운편지 작성/상세 모달은 모달 바깥 클릭 시 닫히는 로직을 함께 합칠 필요가 있다.

## Claude 명세 작성 시 요청 문장 예시

```text
아래 문서를 기준으로 Clov.의 추억피드 화면명세서를 작성해줘.
화면 목적, 주요 UI 영역, 컴포넌트, 사용자 액션, 상태, 예외 케이스,
데스크톱/모바일 차이, API 설계에 참고할 데이터 항목을 표로 정리해줘.
HTML 코드 설명이 아니라 실제 서비스 화면 명세서 형태로 작성해줘.
```
