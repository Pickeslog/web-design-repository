# Clov. 사용자 흐름 명세 소스

## 문서 목적

이 문서는 Clov.의 주요 사용자 흐름을 화면명세서와 개발 설계에 연결하기 위한 소스다.

화면별 UI만 보면 서비스의 핵심 흐름인 `약속 -> 만남 -> 추억`이 끊겨 보일 수 있으므로, 화면을 가로지르는 사용자 여정을 별도로 정리한다.

## 핵심 서비스 여정

```text
우정공간 진입
-> 약속 등록
-> D-day 확인
-> 실제 만남
-> 추억 작성 후보 생성
-> 친구별 기록 작성
-> 추억피드 저장
-> 우정 레벨/클로버 성장 반영
```

## 1. 우정공간 진입 흐름

### 목적

사용자가 친구들과 공유하는 우정공간에 들어와 현재 관계 상태를 확인한다.

### 진입 후 확인 정보

- 함께한 날짜
- 우정 레벨
- 대표 사진
- 최근 기록
- 다가오는 약속
- 참여자별 추억 미리보기

### 다음 행동

- 추억피드 보기
- 새 약속 만들기
- 행운편지 보기
- 대표 사진 수정
- 우정공간 전환

## 2. 약속 등록 흐름

### 목적

친구들과의 앞으로의 만남을 D-day로 등록한다.

### 흐름

1. 일정계획 탭 진입
2. 새 D-day 만들기 클릭
3. 일정 제목 입력
4. 날짜 입력 또는 빠른 날짜 칩 선택
5. 저장
6. 일정계획 목록과 대시보드 배너 동기화

### 필요한 상태

- 일정 제목
- 일정 날짜
- 일정 상세 메모
- D-day 계산값
- 선택된 일정

### 예외

- 제목 미입력
- 날짜 미입력
- 지난 날짜 등록 여부 정책 필요

## 3. D-day 확인 흐름

### 목적

등록된 약속까지 남은 시간을 확인하고 기대감을 유지한다.

### 노출 위치

- 우정공간 대시보드의 다가오는 약속 배너
- 일정계획의 성장 카드
- 일정계획의 선택 일정 상세

### 상태

- D-n
- D-day
- D+n

### 화면 표현

- 다가오는 약속은 기대감 중심
- 오늘 약속은 강한 강조
- 지난 약속은 추억 전환 흐름으로 연결

## 4. 약속 완료 후 추억 전환 흐름

### 목적

Clov.의 핵심 차별점인 약속 완료 후 추억 작성 후보 전환을 설명한다.

### 이상적인 흐름

1. 약속 날짜가 지남
2. 일정 상태가 완료 또는 지난 약속으로 바뀜
3. 해당 약속이 추억 작성 후보로 표시됨
4. 사용자가 추억 작성 진입
5. 제목, 내용, 사진, 해시태그, 친구별 기록 작성
6. 추억피드에 저장

### 현재 HTML 기준

현재 기준본은 `약속이 지나면 추억 피드에 기록 후보로 이어지는 흐름`을 문구와 일정계획 UI에서 암시한다.

실제 후보 리스트나 자동 전환 화면은 아직 상세 구현되지 않았다.

### 명세서에서 보강할 항목

- 완료된 약속 목록
- 추억 작성 후보 카드
- 이미 추억으로 전환된 약속 표시
- 친구별 작성 상태
- 작성 리마인드

## 5. 추억 작성 흐름

### 목적

같은 약속 또는 같은 순간에 대해 친구별로 다른 기록을 남긴다.

### 흐름

1. 추억피드에서 글쓰기 클릭
2. 제목 입력
3. 내용 입력
4. 해시태그 선택
5. 커스텀 해시태그 입력
6. 등록
7. 추억피드에 카드 추가

### 향후 보강 흐름

- 약속 후보에서 작성 시작
- 사진 추가
- 친구별 관점 기록 추가
- 공개 범위 또는 우정공간 내 공유 여부 확인

주의:

- 권한 차등은 만들지 않는다.
- 모든 멤버는 동등하게 기록할 수 있다.

## 6. 추억 탐색 흐름

### 목적

쌓인 추억을 월별, 작성자별, 감정 태그별로 다시 찾는다.

### 흐름

1. 추억피드 진입
2. 월별 레일 또는 월 선택 팝오버 사용
3. 전체/내 기록/친구 기록 필터 선택
4. 추억 카드 확인
5. 긴 기록은 더보기 바텀시트에서 확인

### 탐색 기준

- 월
- 작성 주체
- 해시태그
- 사진 유무
- 참여자 기록

## 7. 행운편지 흐름

### 목적

친구에게 가벼운 응원과 감정을 남긴다.

### 현재 기준본 흐름

1. 행운편지 탭 진입
2. 전체 편지 또는 즐겨찾기 필터 선택
3. 별 버튼으로 즐겨찾기 토글

### 병합 후 흐름

1. 편지 작성 클릭
2. 받는 사람 입력 또는 모두에게 보내기 선택
3. 보낸 사람 입력
4. 편지 내용 입력
5. 이모지 선택
6. 미리보기 확인
7. 편지 보내기
8. 편지 목록에 추가
9. 카드 클릭 시 상세 모달 확인

## 8. 우정 성장 흐름

### 목적

기록과 약속이 쌓일수록 우정공간이 성장하는 느낌을 제공한다.

### 반영 요소

- 함께한 날짜
- 추억 개수
- 일정 완료
- 참여자별 기록 수
- 행운편지 수

### 화면 표현

- 우정 레벨
- 진행률
- 클로버가 자라는 지면
- 성장 배지

## Claude 명세 작성 시 요청 문장

```text
아래 사용자 흐름을 기준으로 Clov.의 화면명세서에서 화면 간 연결 흐름을 보강해줘.
특히 약속 등록, D-day, 약속 완료, 추억 작성 후보, 추억피드 저장 흐름이 끊기지 않게 작성해줘.
```
