# Clov. 사용자 흐름 명세 소스

## 문서 목적

이 문서는 Clov.의 주요 사용자 흐름을 화면명세서와 개발 설계에 연결하기 위한 소스다.

화면별 UI만 보면 서비스의 핵심 흐름인 `약속 -> 만남 -> 추억`이 끊겨 보일 수 있으므로, 화면을 가로지르는 사용자 여정을 별도로 정리한다.

각 흐름의 화면 단위 상세는 `test-web-design/`의 화면별 명세서를 우선한다(이 문서는 화면을 가로지르는 여정·연결에 집중).

## 핵심 서비스 여정

```text
[인증] 로그인/회원가입
-> [방 선택] 우정공간 목록에서 입장 (또는 코드로 가입 신청 -> 알림에서 수락)
-> 우정공간 진입(대시보드)
-> 약속 등록
-> D-day 확인
-> 실제 만남
-> 추억 작성 후보 생성
-> 친구별 기록 작성
-> 추억피드 저장
-> 우정 레벨/클로버 성장 반영
```

## 0. 서비스 진입 흐름 (인증 → 방 선택 → 입장)

초기 명세에는 없던 진입 앞단이 실제로 구현되었다.

### 0-1. 로그인 / 회원가입

- 앱 최초 화면은 로그인. **자동 로그인 토큰(`accessToken`)이 있으면 로그인 화면을 건너뛰고 바로 방 선택으로** 이동한다.
- 회원가입은 5단계 위저드(계정 → 약관 → 확인 → 프로필 → 완료).
- → [../test-web-design/01-auth/login.md](../test-web-design/01-auth/login.md) · [signup.md](../test-web-design/01-auth/signup.md)

### 0-2. 방 선택 / 새 공간 / 코드 입장

- 로그인 성공 → **우정공간 목록**(보딩패스 카드). 카드 클릭 시 **입장 스탬프 연출** 후 대시보드(`02-main`) 진입.
- 새 공간 만들기, 초대 코드로 입장(가입 신청) 분기.
- → [../test-web-design/03-rooms/makerooms.md](../test-web-design/03-rooms/makerooms.md)

### 0-3. 코드 입장 → 가입 신청 → 수락 (방장 없는 입장 승인)

핵심 원칙(방장 없음, 모든 멤버 동등)이 입장 승인 흐름에 그대로 반영되었다.

1. 친구에게 받은 **방 코드**로 가입 신청(`clov_joinRequests`에 `pending` 추가).
2. 신청자는 "메인(알림)으로 이동" → 수락 대기.
3. 공간의 **참여 멤버 누구나 1명**이 알림의 "가입 신청" 탭에서 **수락**하면 입장 확정(참여 멤버 수·아바타 즉시 반영). 단 **정원 8명**이 차 있으면 수락 차단.
4. 수락 후 **5분 되돌리기** 가능(강퇴 개념 대신 되돌리기로만 취소).
- → [초대](../test-web-design/03-rooms/invite.md) · [입장](../test-web-design/03-rooms/join_room.md) · [알림 수락](../test-web-design/07-notification/notification.md)

## 1. 우정공간 진입 흐름

### 목적

사용자가 친구들과 공유하는 우정공간에 들어와 현재 관계 상태를 확인한다.

### 진입 후 확인 정보

- 함께한 날짜
- 우정 레벨
- 대표 사진
- 최근 기록
- 다가오는 약속
- 참여자별 추억 미리보기

### 다음 행동

- 추억피드 보기
- 새 약속 만들기
- 행운편지 보기
- 대표 사진 수정
- 우정공간 전환

## 2. 약속 등록 흐름

### 목적

친구들과의 앞으로의 만남을 D-day로 등록한다.

### 흐름

1. 일정계획 탭 진입
2. 새 D-day 만들기 클릭
3. 일정 제목 입력
4. 날짜 입력 또는 빠른 날짜 칩 선택
5. 저장
6. 일정계획 목록과 대시보드 배너 동기화

### 필요한 상태

- 일정 제목
- 일정 날짜
- 일정 상세 메모
- D-day 계산값
- 선택된 일정

### 예외

- 제목 미입력
- 날짜 미입력
- 지난 날짜 등록 여부 정책 필요

## 3. D-day 확인 흐름

### 목적

등록된 약속까지 남은 시간을 확인하고 기대감을 유지한다.

### 노출 위치

- 우정공간 대시보드의 다가오는 약속 배너
- 일정계획의 성장 카드
- 일정계획의 선택 일정 상세

### 상태

- D-n
- D-day
- D+n

### 화면 표현

- 다가오는 약속은 기대감 중심
- 오늘 약속은 강한 강조
- 지난 약속은 추억 전환 흐름으로 연결

## 4. 약속 완료 후 추억 전환 흐름

### 목적

Clov.의 핵심 차별점인 약속 완료 후 추억 작성 후보 전환을 설명한다.

### 이상적인 흐름

1. 약속 날짜가 지남
2. 일정 상태가 완료 또는 지난 약속으로 바뀜
3. 해당 약속이 추억 작성 후보로 표시됨
4. 사용자가 추억 작성 진입
5. 제목, 내용, 사진, 해시태그, 친구별 기록 작성
6. 추억피드에 저장

### 현재 구현 기준

일정계획(인생4컷)에서 **약속 당일 이후**가 되면 성장 카드의 "만남" 단계에서 인증 사진 업로드가 열리고, 필터의 **"인증 가능"/"완료된 약속"** 으로 완료 약속을 모아 본다. 약속 완료는 경험치(+15)로도 연동된다.

추억 작성 시 **약속(영수증)과 연결**할 수 있고, 추억 상세(MEMORY PASSPORT)에서 그 약속의 **영수증·도장 4상태**를 함께 보여 약속 → 추억 전환을 시각화한다.

- → [일정계획(인생4컷)·약속 영수증](../test-web-design/02-main/index.md) · [추억 여권 상세](../test-web-design/04-feed/memory_detail.md)

### 여전히 명세서에서 보강할 항목

- 완료된 약속 → 추억 작성 후보를 **자동 리마인드**하는 화면
- 이미 추억으로 전환된 약속 vs 미작성 약속 구분 표시
- 친구별 작성 상태(누가 아직 안 썼는지)

## 5. 추억 작성 흐름

### 목적

같은 약속 또는 같은 순간에 대해 친구별로 다른 기록을 남긴다.

### 흐름

1. 추억피드에서 글쓰기 클릭
2. 제목 입력
3. 내용 입력
4. 해시태그 선택
5. 커스텀 해시태그 입력
6. 등록
7. 추억피드에 카드 추가

### 향후 보강 흐름

- 약속 후보에서 작성 시작
- 사진 추가
- 친구별 관점 기록 추가
- 공개 범위 또는 우정공간 내 공유 여부 확인

주의:

- 권한 차등은 만들지 않는다.
- 모든 멤버는 동등하게 기록할 수 있다.

## 6. 추억 탐색 흐름

### 목적

쌓인 추억을 월별, 작성자별, 감정 태그별로 다시 찾는다.

### 흐름

1. 추억피드 진입
2. 월별 레일 또는 월 선택 팝오버 사용
3. 전체/내 기록/친구 기록 필터 선택
4. 추억 카드 확인
5. 긴 기록은 더보기 바텀시트에서 확인

### 탐색 기준

- 월
- 작성 주체
- 해시태그
- 사진 유무
- 참여자 기록

## 7. 행운편지 흐름

### 목적

친구에게 가벼운 응원과 감정을 남긴다.

### 현재 구현 흐름

1. 행운편지 탭 진입
2. 전체 편지 또는 즐겨찾기 필터 선택 / 별 버튼으로 즐겨찾기 토글
3. **"편지 쓰기"** 필터 선택 → 목록 자리에 **인라인 작성 폼** 전환(팝업 모달 아님)
4. 받는 사람 입력 또는 "모두에게 보내기" → 보낸 사람 → 내용 → 이모지 선택 → 미리보기 → 보내기 → 목록에 추가
5. 카드 클릭 → **별도 상세 페이지**(`letter_detail.html`, URL 파라미터로 데이터 전달)에서 전체 내용·즐겨찾기·삭제

- → [../test-web-design/05-letter/letter_detail.md](../test-web-design/05-letter/letter_detail.md)

## 8. 우정 성장 흐름

### 목적

기록과 약속이 쌓일수록 우정공간이 성장하는 느낌을 제공한다.

### 반영 요소

- 함께한 날짜
- 추억 개수
- 일정 완료
- 참여자별 기록 수
- 행운편지 수

### 화면 표현

- 우정 레벨 / 진행률(레벨에 따라 색 진화, 지면 클로버 성장)
- 성장 배지
- **경험치(XP) 적립**: 약속 추가(+3)·완료(+15)·게시글 작성(기본25+사진+정성)·마스코트 교감(+2, 하루 3회). 100% 초과 시 연속 레벨업(초과분 이월).
- **마스코트 교감**: 크로비(따뜻함)/롭(디스토피아 AI) 클릭 → 말풍선 + XP. 만렙(777) 연출.
- → [../test-web-design/02-main/index.md](../test-web-design/02-main/index.md)

```text
특히 약속 등록, D-day, 약속 완료, 추억 작성 후보, 추억피드 저장 흐름이 끊기지 않게 작성해줘.
```
