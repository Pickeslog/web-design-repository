# Clov. 디자인 시스템 요약

## 기준

이 문서는 `Clov - 추억피드.html`의 CSS와 UI 패턴을 화면명세서 작성용으로 요약한 것이다.

## 디자인 키워드

- 클로버
- 우정
- 기록
- 약속
- 성장
- 부드러운 초록 계열
- 낮/밤 전환
- 카드형 정보 구조
- 모바일 앱 같은 하단 시트와 모달 경험

## 색상 토큰

라이트 모드:

- `--primary-green`: 딥 포레스트 그린
- `--accent-green`: 민트 그린
- `--dashboard-end-green`: 대시보드 성장 배경 끝색
- `--body-bg`: 세이지 그레이 배경
- `--card-bg`: 흰색 카드 배경
- `--bg-light`: 밝은 회록색 보조 배경
- `--text-color`: 짙은 녹회색 본문
- `--text-muted`: 흐린 회록색 보조 텍스트
- `--border-color`: 연한 경계선
- `--header-bg`: 흰색 헤더
- `--letter-bg`: 편지 카드 배경
- `--letter-border`: 편지 강조 경계선

다크 모드:

- 전체 배경은 짙은 밤하늘 녹색 계열
- 카드 배경은 어두운 녹색/먹색 계열
- 주요 텍스트는 밝은 백록색
- 보조 텍스트는 연록색
- 주요 액션과 활성 상태는 선명한 초록색
- 카드 내부 텍스트는 과한 형광 느낌을 줄이고 읽기 쉬운 대비를 우선한다.

## 화면 배경

- 전체 페이지는 부드러운 초록/세이지 계열 배경을 사용한다.
- 미리보기 화면은 데스크톱 브라우저 프레임과 모바일 프레임을 나란히 배치한다.
- 실제 React 이식 시에는 미리보기 프레임을 제거하고 앱 화면 자체를 기준으로 재구성한다.

## 타이포그래피

- 시스템 산세리프 계열을 사용한다.
- 화면 타이틀은 진한 초록 계열을 사용한다.
- 보조 설명은 작은 크기와 muted 색상을 사용한다.
- 카드 내부에서는 제목, 날짜, 설명의 위계를 명확히 둔다.

## 공통 레이아웃

- 데스크톱은 상단 헤더 + 탭 네비게이션 + 본문 카드/그리드 구조다.
- 모바일은 앱 프레임 안에서 하단 탭 네비게이션을 사용한다.
- 주요 콘텐츠는 카드 단위로 묶는다.
- 반복 정보는 그리드 또는 세로 리스트로 배치한다.

## 공통 컴포넌트

### 헤더

- 로고: `Clov.`
- 주요 탭: 우정공간, 추억피드, 행운편지, 일정계획
- 다크모드 토글
- 프로필 버튼
- 프로필 드롭다운

### 탭 버튼

- 활성 탭은 초록 계열 강조 배경을 사용한다.
- 비활성 탭은 muted 텍스트와 투명/약한 배경을 사용한다.
- 데스크톱과 모바일이 같은 정보 구조를 공유한다.

### 카드

- 흰색 또는 다크 카드 배경
- 둥근 모서리
- 은은한 그림자
- 제목, 날짜, 상태, 본문을 위계적으로 배치

### 주요 버튼

- 기본 버튼은 초록 계열 배경과 흰색 텍스트를 사용한다.
- 보조 버튼은 밝은 배경, 경계선, muted 텍스트를 사용한다.
- 위험 액션은 삭제 버튼에서만 제한적으로 사용한다.

### 모달

- 전체 화면 오버레이
- 중앙 박스
- 부드러운 등장 애니메이션
- 취소/저장 버튼 하단 배치

### 바텀시트

- 긴 추억 기록을 전체 확인할 때 사용한다.
- 모바일 앱에서 익숙한 아래에서 올라오는 패턴을 따른다.
- 배경 클릭과 `Esc`로 닫을 수 있다.

## 다크모드 패턴

- `body.dark-mode` 클래스로 전역 테마를 전환한다.
- 다크모드 토글 아이콘은 애니메이션과 함께 변경된다.
- 카드 안쪽 텍스트의 가독성을 우선한다.
- 날짜/상태/제목이 형광색처럼 튀지 않게 톤을 낮춘다.

## 반응형 기준

데스크톱:

- 브라우저형 프레임
- 넓은 그리드
- 추억피드 카드 다열 배치
- 상단 탭 네비게이션

모바일:

- 스마트폰형 프레임
- 좁은 세로 스크롤
- 카드 단일 열 중심
- 하단 탭 네비게이션
- 터치 가능한 버튼 크기 확보

## 현재 구현 반영 (토큰·패턴 확장)

초기 요약(위) 이후 실제 구현(`test-web-design/`)에서 추가·확정된 디자인 토큰/패턴. 공통 테마는 `02-main/css/global-theme.css` 기반이며 인증·방·상세 페이지도 이를 공유한다.

- **버튼 색 토큰**: 솔리드 초록 CTA는 `--btn-primary-bg`로 통일(주버튼). 크림 종이 버튼(영수증 위 작성 등)은 **의도적으로 다크에 미적응**(디자인 결정, 건드리지 않음).
- **레벨 색 진화**: 우정 레벨에 따라 `--level-accent`가 바뀌어 레벨 바·지면 클로버 톤이 성장한다.
- **커스텀 배경(물감)**: `clov_appBgCustomColor` 단색 배경. **배경 밝기에 따라 글자를 자동 라이트/다크**로 전환(가독성). 커스텀 적용 시 배경 이미지를 `none`으로 지워 단색이 실제로 보이게 처리.
- **"다크에서도 라이트 유지" 예외**: 약속 여정 영수증(크림 종이)·행운편지 편지함은 다크 모드에서도 라이트 지면/배경을 유지하고 대비만 보정한다(감성·가독성 우선). → [일정계획](../test-web-design/02-main/index.md) · [행운편지](../test-web-design/05-letter/letter_detail.md)
- **테마 커스터마이즈 UI**: 색 스와치·**물감 커스텀 색상 피커(SV박스+Hue)**·**바탕화면 아이콘 스와치(이모지 폴백)**. → [사용자설정](../test-web-design/08-profile/profile_edit.md)
- **성공/입장 연출**: 로그인 성공 오버레이, 방 입장 스탬프 애니메이션 등 진입 연출 패턴 추가.

## Claude 명세 작성 시 주의점

- HTML 코드를 그대로 설명하지 말고 사용자 화면 기준으로 설명한다.
- 데스크톱/모바일 프레임은 프로토타입 검토용 장치이며, 실제 서비스 화면의 본질은 탭별 화면 구조다.
- 색상은 exact CSS 값보다 역할 중심으로 설명한다.
- Clov.는 친구 전용 우정 기록 서비스이므로 관리자/방장/권한 차등 표현을 넣지 않는다.
