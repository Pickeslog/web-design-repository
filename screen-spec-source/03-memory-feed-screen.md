# 추억피드 화면 명세 소스

## 화면 목적

추억피드는 약속 이후 남긴 기록을 월별로 탐색하고, 내 기록과 친구 기록을 구분해 확인하는 화면이다.

Clov.의 핵심 차별점인 `약속이 추억으로 전환되는 흐름`과 `친구별 관점 기록`을 가장 직접적으로 보여준다.

> **현재 구현 확장**(아래 원문 유지, 최신 요소 요약): ① 헤더에 **검색·정렬 필터** 추가, ② **사진 모아보기 갤러리**(사진만 모아 보기), ③ 상세는 바텀시트에서 **추억 여권(MEMORY PASSPORT) 상세**로 확장 — 연결된 약속의 **영수증·도장 4상태**·갤러리 포함, ④ 저장 시 사진 **재압축·롤백**으로 용량 초과 대응. 화면별 상세 → [feed.md](../test-web-design/04-feed/feed.md) · [memory_detail.md](../test-web-design/04-feed/memory_detail.md)

## 핵심 메시지

- 추억은 단순 시간순 피드가 아니라 월별로 보관되는 아카이브다.
- 같은 약속도 친구마다 다르게 기억할 수 있다.
- 사진이 없어도 기록 자체가 소중하게 보관된다.
- 긴 기록은 카드 밖의 상세 영역에서 안정적으로 읽는다.

## 주요 영역

### 1. 월별 추억 아카이브 헤더

구성:

- 화면 타이틀: 월별 추억 아카이브
- 설명 문구
- 현재 선택 월 요약 배지
- 글쓰기 버튼

역할:

- 추억피드가 월 단위 탐색 화면임을 명확히 보여준다.
- 글쓰기 모달로 새 추억을 등록할 수 있다.

### 2. 월 선택 레일

구성:

- 전체 월 버튼
- 추억이 있는 월 버튼 목록
- 선택 월의 추억 개수
- 활성 월 표시

역할:

- 사용자가 원하는 시기의 추억만 빠르게 필터링한다.

상태:

- 전체 추억
- 특정 월 선택
- 선택 월에 추억 없음

### 3. iOS 스타일 월 선택 팝오버

구성:

- 달력 아이콘 버튼
- 팝오버
- 이전/다음 연도 버튼
- 현재 연도 표시
- 1월~12월 3x4 월 버튼
- 월별 기록 개수 표시

역할:

- 월이 많아졌을 때 가로 스크롤 없이 원하는 월로 빠르게 이동한다.
- 빈 월을 선택해도 해당 월 상태가 유지되어 월별 페이지처럼 사용할 수 있다.

닫기 조건:

- 외부 클릭
- `Esc`
- 월 선택 완료

### 4. 피드 필터 탭

구성:

- 전체
- 내 기록
- 친구 기록

역할:

- 같은 우정공간 안의 기록을 작성 주체 기준으로 분류한다.

주의:

- `친구 기록`은 특정 소유자 권한을 의미하지 않는다.
- 모든 멤버는 동등하며, 필터는 표시 방식만 바꾼다.

### 5. 추억 카드 그리드

카드 구성:

- 이미지 영역
- 작성자 배지
- 날짜
- 제목
- 장소/부제
- 본문 미리보기
- 참여자별 기록 타일
- 해시태그
- 내 기록 박스
- 더보기 버튼

역할:

- 하나의 추억을 카드 단위로 보여준다.
- 참여자별 시점 차이를 한 카드 안에서 보여준다.

카드 타입:

- 내 기록 카드
- 친구 기록 카드
- 그룹/다수 참여 카드

### 6. 사진 없는 추억 플레이스홀더

구성:

- 초록 계열 배경
- 클로버 아이콘
- 안내 문구

문구 방향:

```text
사진이 없는 추억은 클로버로 보관됩니다
```

역할:

- 사진이 없는 추억도 미완성처럼 보이지 않게 한다.
- 기록 자체가 소중하다는 Clov.의 감성을 유지한다.

### 7. 해시태그

기본 태그 예시:

- `#소중한순간`
- `#우리만의장소`
- `#웃긴날`
- `#다시보고싶은날`

역할:

- 추억을 감정, 장소, 분위기 단위로 분류한다.
- 향후 검색, 추천, 회고 기능으로 확장 가능하다.

### 8. 긴 기록 더보기 (→ 추억 여권 상세)

> 현재 구현에서는 단순 바텀시트를 넘어 **추억 여권(MEMORY PASSPORT) 상세**로 확장되었다(연결 약속의 영수증·도장 4상태·사진 갤러리). 아래는 기본 바텀시트 서술이며, 상세는 [memory_detail.md](../test-web-design/04-feed/memory_detail.md) 참고.

구성:

- 배경 오버레이
- 하단 시트
- 핸들
- 제목
- 날짜
- 전체 기록 본문
- 태그
- 닫기 버튼

역할:

- 카드 본문은 짧게 유지하고, 긴 기록은 별도 영역에서 읽게 한다.
- 모바일 피드의 카드 높이 흔들림을 방지한다.

닫기 조건:

- 닫기 버튼
- 배경 클릭
- `Esc`

## 사용자 액션

- 글쓰기 버튼 클릭: 새 추억 작성 모달 열기
- 월 레일 버튼 클릭: 해당 월 필터 적용
- 달력 아이콘 클릭: 월 선택 팝오버 열기
- 팝오버 월 클릭: 해당 월 필터 적용
- 전체/내 기록/친구 기록 탭 클릭: 피드 필터 변경
- 더보기 클릭: 기록 상세 바텀시트 열기
- 바텀시트 닫기

## 예외 상태

- 선택한 월에 추억 없음
- 필터 결과 없음
- 사진 없는 추억
- 참여자 기록 없음
- 긴 기록

## 데이터 항목

추억 게시글:

- 날짜
- 제목
- 부제 또는 장소
- 본문
- 이미지 URL
- 작성자/카드 타입
- 참여자별 기록
- 태그

## 데스크톱/모바일 차이

데스크톱:

- 카드 그리드가 넓게 배치된다.
- 월 레일과 필터 탭이 한 줄에서 함께 보인다.
- 월 선택 팝오버는 버튼 근처에 뜬다.

모바일:

- 카드가 한 열 중심으로 배치된다.
- 월 레일은 가로 스크롤 중심이다.
- 팝오버와 바텀시트는 터치 조작을 우선한다.
- 현재/과거 비교 카드가 너무 작아지지 않도록 카드 영역을 넓게 확보한다.

## 명세 작성 시 강조할 점

- 추억피드는 Clov.의 핵심 화면이다.
- 월별 아카이브는 단순 장식이 아니라 오래된 약속을 다시 찾기 위한 핵심 탐색 구조다.
- 같은 약속에 대해 친구별 기록이 다르게 남는 구조를 반드시 설명한다.
- 사진 없는 카드도 감성적으로 완성된 상태로 보여야 한다.
