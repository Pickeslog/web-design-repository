# 일정계획 화면 명세 소스

## 화면 목적

일정계획 화면은 친구들과의 약속을 D-day로 관리하고, 약속이 지나면 추억 작성으로 이어지는 흐름을 보여준다.

기준본은 일반 캘린더가 아니라 `Clover Growth Path`라는 성장 경로형 UI를 사용한다.

## 핵심 메시지

- 약속은 단순 일정이 아니라 추억으로 자라나는 씨앗이다.
- D-day 전후의 흐름을 단계적으로 보여준다.
- 약속이 끝나면 추억 피드 기록 후보로 연결된다.

## 주요 영역

### 1. 일정계획 헤더

구성:

- 화면 타이틀: 약속 여정
- 새 D-day 만들기 버튼

역할:

- 사용자가 우정공간의 약속 목록을 관리한다.
- 새 약속을 등록할 수 있다.

### 2. Clover Growth Path 히어로

구성:

- 키커: `CLOVER GROWTH PATH`
- 타이틀
- 설명 문구
- 표시 밀도 버튼

설명 방향:

```text
약속 씨앗이 D-day 새싹을 지나 만남 클로버가 되고, 다음 날 추억 꽃으로 피어납니다.
```

역할:

- 일정이 추억으로 이어지는 Clov.만의 차별성을 전달한다.

### 3. 표시 밀도 컨트롤

구성:

- 3 핵심
- 6 주간
- 전체

역할:

- 일정이 많을 때 화면 밀도를 조절한다.

상태:

- compact
- standard
- detailed

### 4. 성장 카드 리스트

카드 구성:

- 일정 제목
- 일정 날짜
- D-day 배지
- 성장 단계 트랙
- 진행 바
- 현재 단계 설명

성장 단계:

- 약속 씨앗
- D-day 새싹
- 만남 클로버
- 추억 꽃

카드 상태:

- 선택됨
- 완료됨
- 잠김
- 미래 일정
- 오늘 일정
- 지난 일정

### 5. 선택 일정 상세

구성:

- 수정 버튼
- 삭제 버튼
- D-day 문구
- 큰 D-day 값
- 일정 제목
- 친화적인 날짜 표시
- 일정 메모 영역
- 추억 전환 안내 문구

역할:

- 선택한 약속의 상세 내용을 확인하고 수정한다.
- 약속 이후 추억 피드 작성으로 이어지는 흐름을 암시한다.

### 6. 새 D-day 만들기 모달

구성:

- 일정 제목 입력
- 날짜 입력
- 빠른 날짜 선택 칩
- 취소 버튼
- 저장 버튼

빠른 선택 예시:

- 1주 뒤
- 2주 뒤
- 1개월 뒤

역할:

- 캘린더를 길게 조작하지 않고도 미래 약속을 빠르게 등록한다.

## 사용자 액션

- 새 D-day 만들기 클릭: 일정 모달 열기
- 일정 카드 클릭: 선택 일정 변경
- 표시 밀도 버튼 클릭: 카드 표시 개수 변경
- 수정 클릭: 기존 일정 수정 모달 열기
- 삭제 클릭: 일정 삭제
- 일정 메모 입력: 상세 내용 저장
- 빠른 날짜 칩 클릭: 날짜 자동 입력
- 저장 클릭: 새 일정 추가 또는 기존 일정 수정

## 예외 상태

- 등록된 일정 없음
- 미래 일정 없음
- 지난 일정만 있음
- 선택된 일정이 삭제됨
- 일정 제목 또는 날짜 미입력

## 데이터 항목

일정:

- ID
- 제목
- 날짜
- 상세 메모

계산값:

- D-day 값
- 현재 성장 단계
- 진행률
- 일정 타입
- 완료 여부

## 데스크톱/모바일 차이

데스크톱:

- 성장 카드 리스트와 상세 영역을 넓게 보여준다.
- 일정 밀도 전환이 한눈에 보인다.

모바일:

- 성장 카드와 상세 영역을 세로로 쌓는다.
- 카드 크기와 터치 영역을 충분히 확보한다.
- D-day 숫자와 주요 액션이 작아지지 않게 한다.

## 명세 작성 시 강조할 점

- 일정계획은 일반 캘린더 화면이 아니다.
- 약속이 추억으로 자라나는 경로를 보여주는 화면이다.
- 약속 완료 후 추억 작성 후보가 생긴다는 서비스 핵심 차별점을 반드시 연결해서 설명한다.
