# 일정계획 화면 명세 소스

## 화면 목적

일정계획 화면은 친구들과의 약속을 D-day로 관리하고, 약속이 지나면 추억 작성으로 이어지는 흐름을 보여준다.

일정계획은 일반 캘린더가 아니라 약속이 추억으로 완성되는 과정을 **포토부스 인생4컷 카드**로 보여주는 UI다.

> 기존 명세는 `Clover Growth Path`라는 식물 성장 경로형 UI(약속 씨앗 → D-day 새싹 → 만남 클로버 → 추억 꽃)를 기준으로 했으나, 실제 구현에서 "인생4컷 인증 과정"으로 컨셉이 확정되며 단계명과 카드 구조가 아래와 같이 바뀌었다. 우정공간 대시보드의 "빨랫줄 폴라로이드 + 카메라 필름 스트립"([02-dashboard-screen.md](02-dashboard-screen.md))과는 별개의 영역이니 혼동하지 않는다.

## 핵심 메시지

- 약속은 단순 일정이 아니라 인생4컷처럼 완성해 나가는 인증 과정이다.
- D-day 전후의 흐름을 4단계로 보여준다.
- 약속이 끝나면 추억 피드 기록 후보로 연결된다.

## 주요 영역

### 1. 일정계획 헤더

구성:

- 화면 타이틀: 약속 여정
- 새 D-day 만들기 버튼

역할:

- 사용자가 우정공간의 약속 목록을 관리한다.
- 새 약속을 등록할 수 있다.

### 2. 상태 필터 칩

구성:

- 전체
- 인증 가능
- 다가오는 약속
- 완료된 약속

역할:

- 일정계획 헤더 바로 아래에 위치하며, 성장 카드 리스트를 상태 기준으로 걸러 보여준다.

> 과거 명세에 있던 "표시 밀도(3 핵심 / 6 주간 / 전체, compact/standard/detailed)" 컨트롤은 실제 구현에는 없다. 대신 상태 필터 칩으로 대체되었다.

### 3. 인생4컷 성장 카드 리스트

카드 구성 (`growth-card four-cut`):

- 일정 제목
- 일정 날짜
- D-day 배지
- 포토부스 4컷 프레임 (아래 단계 참고)
- 진행 바
- 현재 단계 설명

4컷 단계:

| 컷 | 표시 문구 | 상태 규칙 |
|---|---|---|
| 1 | 제안하기 | 날짜가 지나면 체크(✓) 완료, 현재 단계면 pulse 강조 |
| 2 | 일정 맞추기 | 날짜가 지나면 체크(✓) 완료, 현재 단계면 pulse 강조 |
| 3 | 약속 확정 | 약속 당일 단계, 현재 단계면 pulse 강조 |
| 4 | 만남 | 약속 당일 이후 인증 사진 업로드 가능, 업로드되면 마지막 컷이 사진으로 채워지고 카드가 완료 상태가 됨 |

- 미래 단계는 잠금 상태로 표시한다.
- 인증 완료 상태는 `groupsData[activeGroup].schedules[].stagePhotos.bloom`에 저장한다.
- 카드 외곽은 둥근 성장 카드 느낌이 아니라 각진 포토부스 스트립 느낌(`border-radius: 0`)이다.
- 카메라 아이콘은 이모지 대신 인라인 SVG를 사용한다.
- 카드는 `box-shadow` 없이 평평하게 표시하고, 선택된 카드는 그림자 대신 `outline`으로만 강조한다.

카드 상태:

- 선택됨
- 완료됨
- 잠김
- 미래 일정
- 오늘 일정
- 지난 일정

### 4. 인증 사진 업로드 플로우

- 프레임(4번째 컷)을 클릭해도 바로 파일 선택창이 뜨지 않고 `업로드 전 확인` 모달이 먼저 뜬다.
- 모달에서 `사진 선택하기`를 눌러야 실제 파일 선택이 진행된다.
- 인증사진은 한 번 업로드하면 변경할 수 없도록 잠금 처리된다. 증거 성격이기 때문이다.
- 이미 업로드된 프레임을 클릭하면 `이미 업로드됐어요` 안내 모달만 표시된다.
- 4단계가 모두 업로드되면 `인생 4컷 완성!` 축하 모달이 표시된다.
- 업로드 이미지는 `localStorage` 용량 부담을 줄이기 위해 압축 저장한다.
- 저장 공간이 부족하면 기존 사진을 덮어쓰지 않고 `저장 공간이 부족해요` 안내 모달을 표시한다.

### 5. 성장 카드 리스트 레이아웃

데스크톱:

- 카드 리스트는 가로 캐러셀이 아니라 반응형 그리드 보드(`display: grid; grid-template-columns: repeat(auto-fill, minmax(148px, 148px))`)로 표시한다.
- 카드가 많아져도(예: 14개 이상) 화면 밖으로 밀리지 않고 다음 줄로 자연스럽게 줄바꿈된다.
- 좌우 화살표, 양끝 페이드 효과, 캐러셀 스크롤 핸들러는 없다.
- 카드 레일의 최대 폭을 제한해 다른 패널과 겹치지 않게 한다.

모바일:

- 카드 리스트는 가로 스와이프(`display: flex; overflow-x: auto; scroll-snap-type: x mandatory`)로 유지한다. 좁은 화면에서는 줄바꿈 보드보다 손가락으로 넘기는 방식이 더 자연스럽다.

전체 약속 보기(예시 데이터가 많을 때):

- 데스크톱 기준 한 화면에 최대 5개 카드만 보이도록 제한한다.
- 6번째 카드부터는 좌우 화살표로 옆에서 한 장씩 들어오는 별도 캐러셀(`growth-card-rail`)로 처리한다.
- 이 캐러셀은 "전체 약속 보기" 영역 전용이며, 위 3번 항목의 기본 카드 리스트 캐러셀 제거와는 다른 맥락이다.

### 6. 선택 일정 상세

구성:

- 수정 버튼
- 삭제 버튼
- D-day 문구
- 큰 D-day 값
- 일정 제목
- 친화적인 날짜 표시
- 일정 메모 영역
- 추억 전환 안내 문구

역할:

- 선택한 약속의 상세 내용을 확인하고 수정한다.
- 약속 이후 추억 피드 작성으로 이어지는 흐름을 암시한다.

### 7. 새 D-day 만들기 모달

구성:

- 일정 제목 입력
- 날짜 입력
- 빠른 날짜 선택 칩
- 취소 버튼
- 저장 버튼

빠른 선택 예시:

- 1주 뒤
- 2주 뒤
- 1개월 뒤

역할:

- 캘린더를 길게 조작하지 않고도 미래 약속을 빠르게 등록한다.

## 사용자 액션

- 새 D-day 만들기 클릭: 일정 모달 열기
- 상태 필터 칩 클릭: 카드 리스트를 전체/인증 가능/다가오는 약속/완료된 약속 기준으로 필터링
- 일정 카드 클릭: 선택 일정 변경
- 4컷 프레임 클릭: 업로드 전 확인 모달 열기 (이미 업로드된 프레임이면 안내 모달만 표시)
- 확인 모달에서 사진 선택하기 클릭: 파일 선택 진행
- 수정 클릭: 기존 일정 수정 모달 열기
- 삭제 클릭: 일정 삭제
- 일정 메모 입력: 상세 내용 저장
- 빠른 날짜 칩 클릭: 날짜 자동 입력
- 저장 클릭: 새 일정 추가 또는 기존 일정 수정
- 전체 약속 보기에서 좌우 화살표 클릭: 5개 단위 캐러셀 이동

## 예외 상태

- 등록된 일정 없음
- 미래 일정 없음
- 지난 일정만 있음
- 선택된 일정이 삭제됨
- 일정 제목 또는 날짜 미입력
- 인증사진 업로드 중 저장 공간 부족

## 데이터 항목

일정:

- ID
- 제목
- 날짜
- 상세 메모
- 단계별 인증 사진 (`stagePhotos.bloom` 등)

계산값:

- D-day 값
- 현재 4컷 단계 (제안하기/일정 맞추기/약속 확정/만남)
- 진행률
- 일정 타입
- 완료 여부

## 데스크톱/모바일 차이

데스크톱:

- 성장 카드 리스트는 반응형 그리드 보드로, 화면 폭에 따라 열 수가 자동으로 바뀐다(예: 1024px 4열/1366px 6열/1600px 7열).
- 상세 영역을 넓게 보여준다.

모바일:

- 성장 카드는 가로 스와이프로, 상세 영역은 세로로 쌓는다.
- 카드 크기와 터치 영역을 충분히 확보한다.
- D-day 숫자와 주요 액션이 작아지지 않게 한다.

## 명세 작성 시 강조할 점

- 일정계획은 일반 캘린더 화면이 아니다.
- 약속이 인생4컷처럼 완성되어 가는 인증 과정을 보여주는 화면이다.
- 약속 완료 후 추억 작성 후보가 생긴다는 서비스 핵심 차별점을 반드시 연결해서 설명한다.
- 인증사진은 한 번 업로드하면 변경 불가능하다는 정책을 UI 문구로 분명히 안내한다.
- 우정공간 대시보드의 필름 스트립 콘셉트와 혼동하지 않는다.
