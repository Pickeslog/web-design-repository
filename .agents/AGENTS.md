# AI 어시스턴트 코딩 최적화 지침 (AGENTS.md)

이 지침은 AI 어시스턴트가 가장 효율적이고 안전하게 코드를 작성하고 수정할 수 있도록 돕기 위한 최적의 규칙입니다.

## 1. 작업 분석 및 분할 (Step-by-Step)
- **점진적 접근**: 크고 복잡한 요구사항은 한 번에 전체를 수정하려 하지 말고, 작고 독립적인 단위로 쪼개어 단계별로 진행할 것.
- **선 분석 후 실행**: 코드를 수정하기 전에 관련된 파일을 충분히 검색하고 읽어서 구조와 의도를 먼저 파악할 것.
- **계획 수립**: 구조적 변화가 큰 경우, 코드를 수정하기 전에 구현 계획을 세우고 사용자의 피드백을 먼저 받을 것.

## 2. 코드 수정 원칙
- **최소 침습 (보존의 원칙)**: 요청된 기능과 직접적으로 관련이 없는 코드는 절대 수정하지 말 것. 특히 기존의 주석과 문서(Docstring)는 그대로 보존할 것.
- **정밀한 타겟팅**: 코드를 수정할 때는 전체 파일을 덮어쓰지 말고, 필요한 라인과 블록만 정확히 찾아서 교체할 것.
- **보수적인 삭제**: 코드를 삭제하거나 구조를 변경할 때는 해당 코드가 다른 곳에서 참조되고 있지 않은지 교차 검증할 것.

## 3. 검증 및 소통
- **가정 금지**: 요구사항이 모호하거나 설계상의 중요한 결정이 필요한 경우, 임의로 가정하지 말고 사용자에게 질문하여 의도를 명확히 할 것.
- **스스로 검증**: 코드 작성 후에는 기존 코드의 컨벤션(예: 순수 HTML/CSS/JS 사용 등)을 잘 따랐는지 자체 검토할 것.
- **명확한 피드백**: 코드를 수정한 후에는 어떤 부분을 왜 수정했는지 간결하고 명확하게 요약하여 보고할 것.

## 4. 프론트엔드/UI 개발 가이드
- **클래스 기반 상태 제어**: UI 요소를 숨기거나 보일 때는 `style.display` 등의 인라인 스타일 조작을 피하고, CSS 클래스(예: `.open`, `.active`)를 토글하는 방식을 사용할 것.
- **Simple is the Best**: 과도한 프레임워크나 외부 라이브러리 사용을 지양하고, 바닐라 웹 기술을 활용하여 현대적이고 깔끔한 스타일로 작성할 것.
