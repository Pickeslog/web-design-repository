# signup.html — 회원가입

**최종 수정**: 2026-07-07  
**담당 파트**: `01-auth/`

---

## 화면 개요

Clov 회원가입 화면. 미니멀 SaaS 스타일(플랫 카드 + 단일 그린 액센트) 위에 은은한 Glassmorphism을 결합한 카드 UI, Outfit 폰트 기반 4단계 스텝 구조.

---

## 화면 구조

- 배경: `linear-gradient` + 3개 `orb` (blur 80px, 드리프트 애니메이션 12초 주기)
- 중앙 카드: `max-width: 440px`, `border-radius: 26px`, glassmorphism (`background: rgba(255,255,255,.7)`, `backdrop-filter: blur(16px) saturate(150%)`)
- 버튼: 풀필(pill, `border-radius: 999px`) 형태, 높이 50px 고정
- 입력창: 높이 48px 고정, 반투명 배경(`rgba(255,255,255,.5)`) + `blur(10px)`, 포커스 시 더 또렷해짐
- 진입 애니메이션: `slideUp` (`translateY 14px → 0, 500ms`)

---

## 4단계 회원가입 플로우

| 단계 | 내용 |
|---|---|
| Step 1 (step-0) | 기본 정보 — 이메일, 비밀번호 |
| Step 2 (step-1) | 약관 동의 — 전체 / 필수 2개 / 선택 1개 |
| Step 3 (step-2) | 프로필 설정 — 이미지, 닉네임, 생년월일 |
| Step 4 (step-3) | 가입 완료 — 환영 메시지 + 로그인하러 가기 버튼 |

`goStep(n)` 함수로 단계 전환. 각 단계에서 유효성 검사(`validateStep0/1/2`) 통과 시에만 다음 단계 이동.

**프로필 저장 (0703 수정)**: `goStep(3)` 진입 시 닉네임/이메일/생년월일을 `localStorage.clov_profile`에 저장하도록 추가. 기존엔 완료 화면에 이름을 표시만 하고 저장하지 않아, 가입 직후 편지함 요약 등 다른 화면에서 항상 "사용자님"으로만 표시되던 문제가 있었음.

## 입력 검증

| 항목 | 검증 |
|---|---|
| 이메일 | 이메일 형식 정규식 (`/\S+@\S+\.\S+/`) |
| 비밀번호 | 8~20자, 영문/숫자/특수문자 중 2가지 이상 조합 |
| 닉네임 | 한글·영문·숫자 1~12자 (`/^[가-힣A-Za-z0-9]{1,12}$/`) |
| 생년월일 | `YYYY-MM-DD` 형식, 1900~현재 연도 (선택 항목 — 형식만 검증, 미입력 시 진행 허용) |

---

## 비밀번호 기능

- 눈 아이콘 토글: 보기/숨기기
- 강도 표시 바: 4개 segment (8자 이상 / 영문·숫자·특수문자 중 2가지 이상 조합 / 12자 이상 / 특수문자 포함+조합 충족)

---

## 약관 동의 (Step 2)

- 전체 동의 체크박스
- 필수: 서비스 이용약관 / 개인정보 처리방침
- 선택: 마케팅 정보 수신
- 필수 항목 미체크 → 약관 박스 흔들림 애니메이션

---

## 프로필 설정 (Step 3)

- 원형 이미지 미리보기 (파일 선택 → 즉시 반영)
- 닉네임 입력 → 🎂 버튼 클릭 → 카드 180° 회전으로 생년월일 입력 전환
- 생년월일: 클릭 → 년/월/일 선택 모달 → `YYYY-MM-DD` 형식 반영

---

## 이스터에그

- 클로버 로고 클릭 → 랜덤 메시지 캡슐 팝업 (4종)
- 10% 확률 희귀 이벤트: 카드가 반으로 갈라지는 `cracking` 애니메이션
