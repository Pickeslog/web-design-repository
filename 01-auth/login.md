# login.html — 로그인

**최종 수정**: 2026-07-07  
**담당 파트**: `01-auth/`

---

## 화면 개요

이메일/비밀번호 기반 로그인 화면. Clov 서비스의 진입점이다.

---

## 화면 구성 (2열 그리드)

`grid-template-columns: minmax(310px, .92fr) / minmax(360px, 1fr)`

### 왼쪽 패널 (memory-panel)

- 배경: 진한 초록색 (`--primary-green`)
- `🍀 Clov.` 브랜드 로고
- `오늘도 추억 보관 중` 배지
- 서비스 소개 문구
- 더미 추억 카드 2개 (그리드 패턴 마스크 효과)

### 오른쪽 패널 (form-panel)

- 이메일 입력
- 비밀번호 입력 (보기/숨기기 토글)
- 로그인 유지 체크박스
- 비밀번호 찾기 버튼 (추후 API 연동 예정 메시지)
- 로그인 버튼
- 소셜 로그인 (카카오 · 네이버 · 구글) — 원형 아이콘 버튼

---

## 입력 검증

- 이메일 형식 오류 → 해당 input 흔들림 애니메이션
- 비밀번호 공란 → 해당 input 흔들림 애니메이션
- 정상 입력 → 성공 오버레이(`ClovSuccessOverlay`) 표시 후 `../02-main/index.html` 이동 (API 미연동, 폼 값 체크만)

---

## 비밀번호 보기/숨기기

- 눈 아이콘 클릭 시 `input[type]` 전환 (`password` ↔ `text`)
- 보임 상태: `조심하세요! 비밀번호가 보여요!` 표시

---

## 폰트 및 애니메이션

- 폰트: `Outfit` (Google Fonts, 300–900 웨이트)
- 진입 애니메이션: `rise` (`translateY + scale 0.98 → 1, 650ms`)
