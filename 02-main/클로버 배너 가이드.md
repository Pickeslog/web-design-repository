# 🍀 클로버 D+124 LP 배너 — 가이드

우정 추억 보관 서비스용 대시보드 배너입니다. 함께한 날(D-day)을 **LP 트랙**에 빗대어, 계절마다 배경·색감·인터랙션이 바뀝니다.

- **크기:** 970 × 215 px
- **감성:** 따뜻한 아날로그 / 레트로 LP

---

## 파일 구성

| 파일 | 역할 |
|---|---|
| `clover-banner.html` | 자립형 HTML — 네 계절 배너를 한 화면에서 보기 (오프라인 열람 가능, 더블클릭으로 열림) |
| `D+124 배너.dc.html` | 실제 배너 1개 (편집용) — Tweaks 패널에서 계절별로 조절 |
| `배너 미리보기.dc.html` | 봄·여름·가을·겨울을 위→아래로 나란히 보는 미리보기 |
| `assets/` | 계절별 턴테이블 배경 이미지 |

---

## 배너에 담긴 것

- **D+124 일째** — 함께한 날수 (`ddayCount`로 변경)
- **회전 클릭영역** — LP 라벨을 클릭하면 색종이가 터짐 (우정 레벨업)
- **추억 재생 중 · N번째 트랙** — 함께한 날을 트랙으로 표현한 배지
- **은은한 움직임** — LP 위로 음표 떠오름, 햇살이 나무결 위를 천천히 번짐, 클로버 잎 그림자 살랑임, 계절 파티클(꽃잎·반딧불·낙엽·눈)

---

## 계절별 설정

| 계절 | 배경 | 챕(배지) 색 | 클릭 색종이 |
|---|---|---|---|
| 🌸 봄 | 벚꽃 | 분홍 | 분홍 계열 |
| ☀️ 여름 | 클로버·여름볕 | 클로버 그린 | 하양·하늘색·말차 (크림소다) |
| 🍁 가을 | 단풍 | 주황/브라운 | 주황 계열 |
| ❄️ 겨울 | 눈·솔가지 | 아이시블루 | 아이시블루 계열 |

`season` 값을 `spring / summer / fall / winter` 로 바꾸면 위 요소가 한 번에 전환됩니다.

---

## Tweaks(조절) 방법

`D+124 배너.dc.html` 을 열고 Tweaks 패널에서:

1. **배너** 섹션 → `season`으로 조절할 계절 선택 + `가이드 표시` 켜기 (클릭영역이 주황 링으로 보임)
2. 해당 계절 섹션(**🌸 봄 / ☀️ 여름 / 🍁 가을 / ❄️ 겨울**)에서:
   - **회전 클릭영역** — X 위치 · Y 위치 · 크기
   - **클릭 이벤트(색종이)** — 색상 · 퍼짐 범위 · 개수
3. 다 맞추면 `가이드 표시` 끄기 → LP 클릭으로 확인

계절마다 값이 **독립적으로** 저장됩니다.

## 참고

- 우정 레벨(1~5)은 클릭 시 순환하며 브라우저에 저장됩니다.
- 움직임은 `prefers-reduced-motion`(모션 최소화) 설정 시 자동으로 멈춥니다.
- 봄 배경만 벚꽃이 상단에 몰려 있어 크롭 특성상 꽃이 왼쪽에 집중돼 있습니다 — 분홍 색감·꽃잎 파티클로 계절감을 보완했습니다.
