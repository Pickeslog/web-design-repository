# 🍀 Clov — 프로토타입 → React 이관 매핑 (분리 지도)

> 프로토타입(`test-web-design/`)의 각 조각이 React(`clov-web/src/`) **어디로 가는지** 1:1로 분리한 지도.
> ⚠️ **프로토타입 파일은 옮기거나 고치지 않는다** — 작동하는 참조 원본으로 보존. 이 문서는 "무엇을 → 어디로"만 정의한다.
> 방법론은 [`React-이관가이드.md`](React-이관가이드.md), 이벤트는 [`이벤트-기능정의서.md`](이벤트-기능정의서.md) 참고.
> 최종 갱신: 2026-07-14

---

## 1. React 타깃 구조 (`clov-web/src/`)

```
src/
├── pages/          라우트 단위 화면 (프로토타입 화면 = 여기)
├── components/     재사용 컴포넌트 (헤더·모달·마스코트 등)
├── api/            axios 인스턴스 + 도메인별 호출 함수 (data.js 대체)
├── stores/         Zustand 전역 UI 상태 (선택된 방·테마·모달)
├── hooks/          커스텀 훅
├── lib/            유틸·이미지 압축 (utils.js 이식)
├── styles/         디자인 토큰 + 화면별 CSS
└── assets/         이미지·아이콘
```

## 2. 화면(페이지) 매핑 — 프로토타입 → React 페이지

| 화면 | 프로토타입 소스 | → React 페이지 | 주 API 도메인 | CSS |
|---|---|---|---|---|
| 로그인 | `01-auth/login.html` + `js/auth.js` | `pages/auth/Login.jsx` | Auth | 인증 전용 팔레트 |
| 회원가입 | `01-auth/signup.html` | `pages/auth/Signup.jsx` (5스텝) | Auth | 인증 전용 |
| 방 목록 | `03-rooms/makerooms.html` | `pages/rooms/RoomList.jsx` | Rooms·Invites·JoinRequests | — |
| 초대/방 접속 | `03-rooms/invite.html`·`join_room.html` | `pages/rooms/Invite.jsx`·`JoinRoom.jsx` | Invites·JoinRequests | — |
| 대시보드 | `02-main/pages/space-page.js` + `js/space.js` | `pages/Dashboard.jsx` | Rooms·Exp | `styles/space.css` |
| 추억피드 | `02-main/pages/feed-page.js` + `js/feed.js` | `pages/Feed.jsx` | Memories·Comments·Images | `styles/feed.css` |
| 행운편지 | `02-main/pages/letter-page.js` + `js/letter.js` | `pages/Letters.jsx` | Letters | `styles/letter.css` |
| 일정계획·인생4컷 | `02-main/pages/schedule-page.js` + `js/schedule.js` + `js/fourcut.js` | `pages/Schedule.jsx` | Plans·StagePhotos·Checklists | `styles/schedule.css` |
| 알림 | `02-main/index.html`(noti) | `pages/Notifications.jsx` | Notifications·JoinRequests | — |

> `02-main/index.html`은 **앱 셸(헤더 + 4탭)** = React `App.jsx` + 라우터(react-router v7)로. 4탭이 위 페이지들.

## 4. 로직(JS) 분류 — 교체 / 이식 / 흡수 / 폐기

| 프로토타입 JS | 처리 | 어디로 |
|---|---|---|
| `js/data.js` (localStorage read/write) | 🔴 **교체** | `src/api/*` (도메인별 호출) + TanStack Query. **그대로 옮기지 않음** |
| `js/space·feed·letter·schedule.js` 의 데이터 접근부 | 🔴 교체 | 각 페이지의 `useQuery`/`useMutation` |
| `js/space·feed·letter·schedule.js` 의 연출·계산부 | 🟢 **이식** | 각 페이지/컴포넌트 로직 |
| `js/fourcut.js` (인생4컷 극장 연출) | 🟢 이식 | `pages/Schedule` + `components/FourCutTheater` |
| `js/v5-banner.js`·`croby-mascot.js`·`success-overlay.js` | 🟢 이식 | §3 컴포넌트 |
| `js/utils.js` | 🟡 **선별 이식** | `src/lib/utils.js` (사진 압축은 `src/lib/image.js`) |
| `js/nav.js` (탭 전환) | 🟠 **흡수** | react-router (라우팅이 대체) |
| `js/init.js` (부트스트랩·전역 onclick/keydown) | 🟠 흡수 | `App.jsx` + ESC 훅·포커스 시스템 |
| `js/desktop.js` + `css/`(레거시 모놀리식) | ⚫ **폐기** | `04-feed/feed.html`만 쓰던 보존용. 이관 안 함 |

## 5. 스타일·자산 매핑

| 프로토타입 | → React |
|---|---|
| `styles/base.css` (디자인 토큰 CSS 변수) | `src/styles/tokens.css` — **거의 그대로**(다크모드 포함) |
| `styles/space·feed·letter·schedule.css` | **각 컴포넌트 폴더의 `Xxx.style.js` (Emotion styled)** |

> **스타일 규약(2026-07-20 확정)**: 컴포넌트는 폴더로 분리해 `Xxx.jsx` + `Xxx.style.js`(Emotion `@emotion/styled`)로 나눈다. 전역 디자인 토큰만 `src/styles/tokens.css`. (당초 CSS Modules에서 변경 — 다크모드·hover·keyframes를 충실히 이관하기 위해. 컴포넌트 셀렉터 `${Comp}`는 babel 플러그인이 없으면 못 쓰니 `label` 등 요소·클래스 셀렉터를 쓴다.)
| `assets/croby`·`rob` | `src/assets/mascot/` |
| `assets/stamps` | `src/assets/stamps/` (도장·인증) |
| `assets/background-icons` | `src/assets/backgrounds/` (V5 벽지) |

## 7. 이관 순서 (권장)

1. **공통 먼저**: `tokens.css` · `Header`·`Modal`·`Toast` · `src/api` 인스턴스 → 나머지가 이걸 씀
2. **로그인 워킹 스켈레톤**(리더) → 정답 패턴
3. **화면별 팬아웃**: 위 담당 묶음대로, 각 화면 = [마크업→JSX / CSS 복사 / localStorage→Query / 연출 이식]
