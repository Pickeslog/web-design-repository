# 🍀 Clov — 이벤트 기능 정의서

> **화면(무엇을 보나) ↔ API(어떤 엔드포인트)** 사이를 잇는 다리.
> 각 사용자 이벤트마다: **트리거 → 사전조건·검증 → 호출 API → 성공 결과(상태변화) → 예외**.
> 근거: [`API-CONTRACT.md`](API-CONTRACT.md)(엔드포인트·에러) · 화면 명세(`../test-web-design/*/*.md`) · DB [`../api-spec/05-db-unified-final.md`](../api-spec/05-db-unified-final.md).
> 프론트는 "호출 API + 검증 + 예외 UI"를, 백은 "검증 + 상태변화"를 이 표대로 구현한다.
> 최종 갱신: 2026-07-14

**표기**: 클라=프론트 검증 · 서버=백엔드 검증(신뢰 기준) · (XP)=서버 부수효과 적립

## 9. 마스코트 · 레벨 · 생일

> **구현 단계 (리더 확정 2026-07-24)** — 프로덕션은 **MVP부터** 간다.
> **MVP = §9.1 획득표(편지 제외) + 연속 레벨업 판정 + 레벨당 100 XP.**
> **후속 = §9.2 가속도 · §9.3 기억의 샘 · §9.5 마일스톤 연출.**
> 레벨 규칙과 `action_type`·`reference_id` 정본은 [API-CONTRACT §12](API-CONTRACT.md#12-exp--level--mascot-서버-계산).

### 9.1 경험치(XP) 획득

| 행동 | 트리거 | 획득 XP | 비고 |
|---|---|---|---|
| 마스코트 교감 | `POST /rooms/{id}/mascot/interact` (클릭/쓰다듬기) | +2 | 하루 최대 **10회** 제한(일 최대 20XP, 방 단위). 골드도 같이 나간다 — **횟수는 계약 §15-4의 `EARN_MASCOT`과 같은 값이어야 한다** |
| 일정 등록 | 새 약속/D-day 등록 완료 | +3 | 약속 생성 기본 보상 |
| 일정 완료 | 약속 당일 인증(인생4컷 등) 체크 완료 | +15 | 달성 보상 |
| 추억 게시글 작성 | 추억피드 기본 게시글 작성 | +25 | 기본 XP 중 최고치 |
| 사진 첨부 보너스 | 게시글 작성 시 사진 첨부 | +1(장당), 최대 **+8** | **§10의 사진 개수 상한(8)과 같은 값이어야 한다** — 보너스 상한이 더 크면 9·10번째는 영원히 닿지 않는 죽은 규칙이 된다(2026-07-31 계약 §12에서 10 → 8로 정합, 이 문서는 2026-08-04에 반영) |
| 글자 수 보너스 | 게시글 본문 길이 | 50자↑: +5 / 100자↑: +10 | 두 구간 중 **도달한 최고 구간 1개만** 적용(중첩 아님 — 100자 이상이면 +10만, +5는 별도로 더 붙지 않음) |

10회 초과 시 마스코트 교감은 `429 MASCOT_INTERACTION_LIMIT_REACHED` → "오늘은 여기까지!" 말풍선으로 노출(XP·골드 모두 미지급).

**골드는 XP와 캡 스코프가 다르다.** 교감 캡(10회)은 **방 단위**, 골드 캡(§15-4 `EARN_MASCOT` 10회 + 총 상한 3,000)은 **유저 단위**다. 방 여러 개에 속한 사용자는 교감을 10회씩 더 할 수 있지만 **골드는 유저 기준으로 끊긴다** — 그때 `429`가 아니라 정상 응답에 `earnedGold: 0`이 온다. 화면은 이 값으로 골드 획득 연출 여부를 판단한다.

### 9.2 XP 가속도 (스노우볼링)

우정공간 내 **누적 게시글 수**에 비례해 위 9.1의 모든 최종 획득 XP가 증폭된다:

- 누적 게시글 **30개** 돌파: **x1.2배**
- 누적 게시글 **50개** 돌파: **x1.5배**
- 누적 게시글 **70개** 돌파: **x2.0배**
- 누적 게시글 **100개** 돌파: **x3.0배**

> 예시: 누적 게시글 50개인 방에서 100자 이상(+10) + 사진 5장(+5)을 포함해 글을 쓰면 (기본 25 + 10 + 5) × 1.5 = 최종 **60 XP** 획득.

### 9.3 기억의 샘 (패시브 XP)

매일 최초 접속 시(자동 감지) 접속하지 않은 동안 쌓인 공간 인프라 기준으로 자동 지급된다.

- **공식**: `(누적 게시물 수 × 0.5) + (다가올 일정 수 × 1)` — 9.2의 가속 배율도 함께 적용
- **피드백**: 접속 시 *"어제 남겨둔 추억들 덕분에 클로브가 이만큼 자랐어요!"* 팝업 노출과 함께 계산된 경험치 즉시 반영

### 9.4 마스코트 상태 이벤트

| 상태 | 트리거 | 동작 및 대사 |
|---|---|---|
| 기본 교감 | idle 상태에서 클릭 | 좌우로 흔들리는 애니메이션 + 캐릭터별 대사(크로비: "안녕!", "오늘도 낙서 중~" 등 / 로봇: 대사 + 일시적으로 돋보기·연필 스프라이트로 변신하는 특수 리액션) |
| 어지러움(dizzy) | 0.9초 내 3연속 클릭 | 빙글빙글 도는 이미지로 전환(크로비: "어지러워...!" / 로봇: "001011010101(어지러워..)" + 사방에 빨간 `0`/`1` 글리치 파편). 1.2초 후 기본 상태로 복구 |
| 졸음(sleepy) | 20초간 마우스 이동·스크롤 등 무입력 | 눈 감고 잠든 이미지로 전환 + 말풍선 "Zzz…". 입력 이벤트 감지 시 즉시 눈 뜨고 깨어남 |
| 혼잣말(mutter) | idle 중 8~15초 사이 랜덤 시점 | 상호작용 없이 혼잣말이 잠시 나타났다 사라짐(예: "흐음… 다음 컷은…", "구도가 어렵네…") |
| 드래그 들어올리기(로봇 전용) | 머리 부분 클릭 후 드래그 | 쭈욱 늘어나는 이미지(lifted)로 전환 + "오오 늘어난다.." 대사, 마우스를 따라 이동 |
| 공포·화남(로봇 전용) | 드래그 상태로 150px 이상 들어올림 | 바둥거리는 이미지(scared) + "너무 높아!!" 대사. 3초 이상 계속 들고 있으면 화난 이미지(angry) + "날 내려놔, [사용자 이름]!" 대사와 함께 마우스 커서 쪽 유리 파편 이펙트(Cursor Shatter) 후 마우스를 뿌리치고 바닥으로 추락(drop) |

| 777레벨(만렙) | 최고 레벨 777 도달 | 화면 6곳(정중앙·좌측상단·우측상단·좌측하단·우측하단·마스코트 중심부)에서 거대한 폭죽 펄스가 쏟아지듯 터짐. 크로비: "대단합니다! 클로버가 엄청난 진화를 거쳐 만렙(Lv.777)에 도달했습니다!" / 로봇: "동기화 완료. 우정 진행률 100% 달성. 만렙(Lv.777)." |

### 9.6 생일 이벤트

| 대상 | 감지 조건 | 배너 시각화 | 마스코트 교감 |
|---|---|---|---|
| 본인 생일 | 유저 본인 생일 당일 접속 | 배너 영역에 **풍선이 올라가고** 파티클이 흩날리며 내려오는 특수 효과 | 사용자가 마스코트를 클릭했을 때만 본인 생일 축하 말풍선 출력. 경험치 상승분이 있으면 대사와 문구가 조합되어 노출 |
| 친구 생일 | 방 멤버 중 당일 생일자 존재 | 배너 영역에 **풍선 없이 파티클 효과만** 흩날리며 내려옴 | 사용자가 마스코트를 클릭했을 때만 친구 생일을 알리고 축하하는 말풍선 출력. 경험치 상승 시 문구와 조합되어 노출 |

> 생일 축하 대사는 항상 "마스코트를 클릭했을 때"만 반응하는 상호작용이며, 배너의 시각적 요소(풍선 유무)로 본인 생일과 친구 생일의 연출을 구분한다.

## 공통 규칙 (모든 이벤트)

- **응답 봉투**: 성공 `{success,data}` / 실패 `{success,error{code,message}}`.
- **인가**: 조회·작성=공간 멤버(ACTIVE) · 수정·삭제=작성자 본인. 위반 시 `ROOM_MEMBER_NOT_FOUND`(403)/`NOT_WRITER`(403).
- **클라 신뢰 금지**: XP·5분 타이머·정원·도장 상태는 **서버가 최종 판정**. 프론트는 표시·연출만.
- **낙관적 UI**: mutation 성공 후 TanStack Query 캐시 무효화로 갱신. 실패 시 롤백 + 토스트.
- **모달/포커스**: 열림 시 포커스 트랩·`aria-hidden`, ESC는 최상위 레이어만 닫음(전파 차단).
