# 🍀 Clov — 이벤트 기능 정의서

> **화면(무엇을 보나) ↔ API(어떤 엔드포인트)** 사이를 잇는 다리.
> 각 사용자 이벤트마다: **트리거 → 사전조건·검증 → 호출 API → 성공 결과(상태변화) → 예외**.
> 근거: [`API-CONTRACT.md`](API-CONTRACT.md)(엔드포인트·에러) · 화면 명세(`../test-web-design/*/*.md`) · DB [`../api-spec/05-db-unified-final.md`](../api-spec/05-db-unified-final.md).
> 프론트는 "호출 API + 검증 + 예외 UI"를, 백은 "검증 + 상태변화"를 이 표대로 구현한다.
> 최종 갱신: 2026-07-14

**표기**: 클라=프론트 검증 · 서버=백엔드 검증(신뢰 기준) · (XP)=서버 부수효과 적립

## 공통 규칙 (모든 이벤트)

- **응답 봉투**: 성공 `{success,data}` / 실패 `{success,error{code,message}}`.
- **인가**: 조회·작성=공간 멤버(ACTIVE) · 수정·삭제=작성자 본인. 위반 시 `ROOM_MEMBER_NOT_FOUND`(403)/`NOT_WRITER`(403).
- **클라 신뢰 금지**: XP·5분 타이머·정원·도장 상태는 **서버가 최종 판정**. 프론트는 표시·연출만.
- **낙관적 UI**: mutation 성공 후 TanStack Query 캐시 무효화로 갱신. 실패 시 롤백 + 토스트.
- **모달/포커스**: 열림 시 포커스 트랩·`aria-hidden`, ESC는 최상위 레이어만 닫음(전파 차단).
