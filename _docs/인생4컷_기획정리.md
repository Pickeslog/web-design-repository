# 인생4컷 단계 UI — 기획 정리

_Clov. 일정계획 탭 / `growth-card four-cut` 리디자인 · 2026.07_

---

## 1. 배경 & 문제

기존 일정계획의 4단계 카드는 **"카드 안에 카드"** 처럼 보여서 포토부스 인생4컷 스트립 느낌이 나지 않았다. 또한 각 단계가 **언제 열리고 언제 다음으로 넘어가는지 기준이 애매**했다.

## 2. 목표

**디자인**
- `growth-card four-cut`을 일반 카드형 UI가 아니라 **"포토부스 인생4컷 스트립"** 처럼 보이게 한다.
- 내부 4개 영역이 각각 독립 카드처럼 보이지 않게 한다.
- 하나의 긴 세로형 사진 스트립 안에서 4단계가 이어지는 느낌을 준다.

**기능/정책**
- 각 단계가 열리는 기준을 명확히 한다.
- 열린 단계만 색이 들어오고 사진 업로드가 가능하다.
- 아직 열리지 않은 단계는 회색/흐림/잠금 상태로 보여주고 업로드할 수 없게 한다.

## 3. 지켜야 할 서비스 원칙 (Clov.)

- 우정공간에는 **방장·대표자·관리자 개념이 없다.** 초대한 사람에게 특별 권한을 주지 않는다. 모든 멤버는 동등하다.
- 일정계획의 핵심은 **약속이 추억으로 이어지는 흐름**이다.
- 이번 작업은 **일정계획의 인생4컷 단계 UI만** 수정한다. 추억피드·행운편지·우정공간 대시보드의 기존 기능은 건드리지 않는다.

## 4. 확정 단계 이름

| # | 단계명 | 의미 |
|---|--------|------|
| 1 | **제안하기** | 약속이 처음 생성된 첫 기록 |
| 2 | **일정 맞추기** | 준비하고 일정을 조율하는 기록 단계 |
| 3 | **약속 확정** | 약속 날짜에 도달해야 열리는 인증 단계 |
| 4 | **만남** | 인생4컷을 완성하는 마지막 추억 단계 |

> 기존의 "약속 씨앗 / D-day 새싹 / 만남 클로버 / 추억 꽃" 명칭은 화면 표시명에서 폐기하고, 코드 주석에서도 위 새 명칭으로 정리했다.

## 5. 단계 상태 모델

각 단계는 세 가지 상태를 가진다.

- **LOCKED** — 회색·흐림·자물쇠. 업로드 불가.
- **ACTIVE** — 색상·촬영 중(REC)·뷰파인더. 업로드 가능.
- **DONE** — 올린 사진이 컷을 채움. 완료.

### 상태 전환 규칙

**1. 제안하기**
- 열림: 일정이 생성되면 즉시.
- 업로드: 항상 가능. 단, 일정이 취소되면 불가.
- 사진 없음 → `ACTIVE` / 사진 있음 → `DONE`
- 문구: ACTIVE `첫 약속의 순간을 올려주세요` · DONE `제안 완료`

**2. 일정 맞추기**
- 열림: 1단계 사진 업로드 후. (시간 조건 없음)
- 1단계 사진 없음 → `LOCKED` / 있음+2단계 없음 → `ACTIVE` / 2단계 있음 → `DONE`
- 문구: LOCKED `제안하기 사진을 먼저 올려주세요` · ACTIVE `준비와 기대를 기록해보세요` · DONE `일정 맞추기 완료`

**3. 약속 확정**
- 열림: 2단계 사진 완료 **+ `today >= plan_date`** (약속 당일 또는 이후).
- 2단계 없음 → `LOCKED` / 2단계 있음+날짜 전 → `LOCKED` / 2단계 있음+`today>=plan_date`+3단계 없음 → `ACTIVE` / 3단계 있음 → `DONE`
- 문구: LOCKED(2단계 미완료) `일정 맞추기 사진을 먼저 올려주세요` · LOCKED(날짜 전) `약속 당일부터 열려요` · ACTIVE `오늘의 약속을 인증해보세요` · DONE `약속 확정 완료`
- **중요:** 약속 당일에 못 올려도 괜찮다. `today >= plan_date`이면 이후 **언제든** 업로드 가능.

**4. 만남**
- 열림: 3단계 사진 업로드 후. (시간 조건 없음)
- 3단계 없음 → `LOCKED` / 있음+4단계 없음 → `ACTIVE` / 4단계 있음 → `DONE`
- 문구: LOCKED `약속 확정 사진을 올리면 열려요` · ACTIVE `만남의 마지막 장면을 남겨주세요` · DONE `만남 완료`

> **시간/날짜 조건이 걸리는 단계는 3단계(약속 확정) 하나뿐이다.** 2·4단계는 앞 단계 사진만 올리면 바로 열린다.

## 6. 인생4컷 완성 조건

```js
hasProposalPhoto &&   // 제안하기
hasCoordinatePhoto && // 일정 맞추기
hasConfirmPhoto &&    // 약속 확정
hasMeetingPhoto       // 만남
```

네 컷이 모두 채워지면 인생4컷 완성 🍀 — 헤더가 `NOW SHOOTING` → `COMPLETE`, 하단이 `4/4 업로드 완료` → `인생4컷 완성`으로 바뀐다.

## 7. 디자인 구현 요약

- **하나의 크림색 티켓 스트립**: 컷마다 있던 테두리/그림자를 제거하고, 컷 사이를 **점선 퍼포레이션 + 양쪽 노치**로 이어 포토부스 스트립처럼 보이게 함.
- 상하단 **스캘럽(물결) 엣지**, 상단 헤더(제목·D-day 배지·`NOW SHOOTING`), 하단 `clov. memories / N/4 업로드 완료`.
- **ACTIVE 컷**: 초록 뷰파인더 코너 브래킷 + REC 점멸 + 스파클, 클릭 시 사진 업로드.
- **DONE 컷**: 올린 사진이 컷을 채우고 그라데이션 위에 번호·체크·라벨 오버레이.
- **LOCKED 컷**: 그레이스케일·흐림·자물쇠 배지, 클릭·업로드 불가.
- 팔레트: 세이지 그린 배경 `#8a9a82`, 티켓 크림 `#f4f1e8`, 강조 그린 `#4a7c52` / `#2e5233`, REC 레드 `#c0392b`. 서체: Gothic A1 + Space Mono.
