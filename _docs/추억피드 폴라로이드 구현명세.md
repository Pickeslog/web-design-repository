# 추억피드 폴라로이드 카드 + 상세 모달 구현 명세

> Clov 추억피드의 `memory-card / polaroid-card / mine`을 **인스타 감성 폴라로이드**로 재설계하고, 사진을 누르면 **상세 모달**로 확대 보기 + 친구 한 줄 메시지 확인 + 게시글 수정/삭제가 되게 한다.
>
> 시각 기준 파일: `Clov 추억 폴라로이드.html` (이 명세와 함께 첨부). 색·간격·상태는 이 파일을 그대로 따른다.

---

## 1. 목표

- 기존 카드 렌더링(`renderMemoryCard`)을 폴라로이드 스타일 카드로 교체한다.
- 카드의 **대표 사진을 클릭**하면 상세 모달이 열린다. (기존 `openMemoryDetail` 진입점을 모달로 연결)
- 상세 모달에서:
  - 사진 + 제목 + 본문 + 해시태그를 크게 본다.
  - **친구 한 줄 메시지**(친구 1명당 1개)를 확인/작성한다.
  - **게시자**는 제목·본문 **수정**, 게시글 **삭제**가 가능하다.

---

## 2. 화면 구성

### 2-1. 폴라로이드 피드 카드

위에서 아래 순서:

1. **참여자 아바타 레일** — 참여자 아이콘 원형 나열. 게시자(사진 올린 사람)는 민트색 링으로 강조. 우측 끝에 참여자 이름 요약.
2. 구분선
3. **대표 사진** (1:1 정사각) — 클릭 시 상세 모달 오픈. 좌상단 작성자 배지(`내 기록` / `나의 기록`), 우하단 `🔍 자세히` 힌트.
   - 사진 없음: 초록(클로버) 그라데이션 + `🍀` + "사진이 없는 추억은 / 클로버로 보관됩니다" (기존 규칙 유지)
4. **캡션 박스** — 작성자 라벨 칩 + `···더보기`(모달 오픈), 제목(볼드), 본문 미리보기(48자 말줄임)
5. **해시태그** 칩 목록
6. 구분선
7. **메타 행** — `날짜 · 장소` / `💬 메시지 수`

### 2-2. 상세 모달 (중앙 정렬, 데스크톱)

- 배경 오버레이(반투명 + blur), 클릭/`Esc`로 닫힘. 카드 클릭은 전파 차단.
- **헤더**: 작성자 배지 + `날짜 · 장소` + 닫기(✕)
- **본문(2열)**:
  - 좌: 대표 사진(정사각)
  - 우: 제목 / 본문(줄바꿈 유지) / 해시태그
  - **수정 모드**일 때 우측 열이 제목 input + 본문 textarea + [저장][취소]로 전환
- **친구 한 줄 메시지** 섹션 (아래 3장 참고)
- **게시글 액션 바**:
  - 게시자: `[수정(제목·본문)] [삭제] [닫기]`
  - 친구: `닫기`만 ("친구는 메시지만 남길 수 있어요")
  - 삭제 클릭 → "이 추억을 삭제할까요?" 확인 행 → [취소]/[삭제]

---

## 3. 친구 한 줄 메시지 규칙 (핵심)

- **친구 1명당 메시지 1개만.** 댓글 스레드가 아니다.
- 각 참여자 행: `아바타 · 이름 · 메시지(또는 상태)`
- 상태별 표시:
  - **타인이 남긴 메시지** → 텍스트만. 수정/삭제 버튼 없음.
  - **타인 미작성** → "아직 메시지 없음" (흐리게)
  - **내가 남긴 메시지** → 텍스트 + `[수정] [삭제]` (본인만)
  - **내가 미작성** → 한 줄 입력창 + `[등록]` (1개 등록 후 위 목록으로 이동)
- 수정 저장 시 내용이 비면 삭제로 처리.

---

## 4. 권한

| 액션 | 권한 |
|---|---|
| 게시글 제목·본문 수정 | **게시자(사진 올린 사람)만** |
| 게시글 삭제 | **게시자만** |
| 친구 한 줄 메시지 작성 | 참여 친구 각자 |
| 메시지 수정·삭제 | **그 메시지 작성자 본인만** |

- Clov는 방장/관리자 권한 차등이 없다. "게시자"는 소유 개념이 아니라 **그 글을 올린 사람** 기준일 뿐이다.

## 5. 데이터 모델

기존 `post` 구조에 **`messages` 배열만 신규 추가**한다.

```js
post = {
  authorId: 'me',          // 게시자(사진 올린 사람) id  ← 권한 기준
  date: '2026.06.20',
  place: '뚝섬 한강',       // = subtitle
  title: '첫 한강 피크닉',
  body: '떡볶이 사서 돗자리 펴고...\n노을 질 때까지...',  // \n 유지
  bg: '',                  // 사진 URL. 없으면 클로버 플레이스홀더
  tags: ['#소중한순간', '#내기록', '#2026년06월'],
  participants: [          // 기존 구조 그대로
    { id: 'me',  name: '나', icon: '🙂', type: 'mine' },
    { id: 'sol', name: '솔', icon: '🌷', type: 'friend' },
    { id: 'min', name: '민', icon: '🐣', type: 'friend' },
  ],
  messages: [              // ★ 신규: 친구 한 줄 메시지 (authorId당 최대 1개)
    { authorId: 'sol', text: '그날 노을 진짜 예뻤어 🌅 우리 또 가자!' },
  ],
}
```

- `messages`는 `authorId` 기준 유니크(1인 1개). 렌더링은 `participants`를 순회하며 각자의 메시지를 매칭한다.
- `currentUserId`(로그인 사용자)와 `post.authorId` / `message.authorId` 비교로 권한을 판단한다.

## 6. 상호작용 / 상태

- 사진 클릭, `···더보기` → 모달 오픈
- 모달: 오버레이 클릭 / ✕ / `Esc` → 닫기 (내부 클릭 전파 차단)
- 수정: `editing` 토글 → 저장 시 `post.title/body` 갱신
- 삭제: `deleteConfirm` 단계 → 확정 시 게시글 제거(+빈 상태)
- 메시지: `composeDraft`(신규 입력), `editingMsgId` + `msgEditDraft`(수정 중)로 상태 관리

## 8. 기존 코드 연결 지점

- `renderMemoryCard(post, postIndex)` → 폴라로이드 카드 마크업으로 교체
- `openMemoryDetail(postIndex, participantId)` → 페이지 이동 대신 **인라인 상세 모달** 오픈으로 변경 (현재 바텀시트 로직 위치)
- `normalizeMemoryPost` → `messages` 기본값(`[]`) 보강
- 신규 핸들러: `saveMemoryMessage / editMemoryMessage / deleteMemoryMessage`, `updateMemoryPost / deleteMemoryPost`

---

## 9. 예외 상태

- 사진 없는 추억 → 클로버 플레이스홀더
- 메시지 0개 → 참여자별 "아직 메시지 없음"
- 게시글 삭제됨 → "추억이 삭제되었습니다" 빈 상태
- 친구 관점 → 게시글 수정/삭제 버튼 숨김
