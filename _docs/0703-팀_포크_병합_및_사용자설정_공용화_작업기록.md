## 2. 행운편지 — 작성 기능 버그 수정 + 받는사람 피커 재작업 (김대훈 포크)

- **발견한 버그**: 여러 차례 병합을 거치며 `submitLetter`/`toggleLetterToAllBtn`/`selectLetterEmoji`가 **3중으로 중복 정의**돼 있었다. JS는 나중에 정의된 함수가 이전 정의를 덮어쓰므로, 실제로 실행되던 버전은 **편지를 저장하지 않고 성공 토스트만 띄우는 미완성 스텁**이었다 — 편지를 작성해도 편지함에 쌓이지 않는 버그.
- 김대훈 포크의 완결된 버전으로 교체:
  - 받는사람: 자유 텍스트 → 방 멤버 칩(`.letter-recipient-chip`) 선택 방식
  - 보내는사람: 항상 `clov_profile`의 내 이름 (기존엔 자유 입력이라 스푸핑 가능했음)
  - 글자수 제한(한글 500/영어 1000자) 추가, 이모지 장식 필드는 삭제
- 상세 내용은 `02-main/index.md`의 "행운편지 — 선물상자/우체통 UI" 섹션 참고

## 3. 알림 — 가입신청 세션 전용 거절 + 멤버 퇴장 알림 (신동수 포크 아이디어 참고)

- **거절 세션 전용화**: `rejectJoinRequest()`가 더 이상 `localStorage`(`clov_joinRequests`)에 영구 기록하지 않고, 메모리 변수 `notiSessionOverrides`에만 기록 → 새로고침하면 다시 대기(pending) 상태로 리셋됨. 수락(accept)은 기존처럼 영구 저장 유지.
- **가입신청 [삭제] 버튼**: 이미 처리된 항목을 알림 목록에서 지울 수 있는 버튼 추가(`deleteJoinRequest`).
- **멤버 퇴장 알림 시뮬레이션**: "방 나가기" 기능 자체가 코드에 전혀 없었어서, 가입신청 흐름과 대칭되는 `simulateMemberLeave()`를 신규 구현. 참여 멤버 모달에 "👋 멤버 퇴장 테스트" 버튼 추가 → 동적 멤버(`clov_acceptedMembers`) 중 무작위 1명을 제거하고 `"{이름}님이 {방이름}에서 나갔습니다."` 알림을 "🔔 친구들 알림" 탭에 생성.

## 4. 일정계획 — 김규비 포크 병합

- **3칸 그리드 배너**: 우정공간 대시보드의 일정 배너가 기존엔 가장 가까운 일정 1개만 보여줬으나, 다가오는 일정 최대 3개를 그리드로 표시하도록 개편(`updateScheduleUI()`). 일정이 3개 미만이면 남은 칸에 "➕ 새로운 약속 만들기" 회색 점선 placeholder 노출.
- **수정 시 과거 날짜 제한**: 생성 모달엔 원래 있었지만 수정 모달엔 날짜 제한이 아예 없었던 버그를 발견해 수정. 단, 이미 저장된 과거 날짜를 그대로 두는 것(제목만 수정 등)은 허용하고, 새로 과거 날짜로 바꾸려는 시도만 차단하도록 설계.
- **D-day 뱃지 수채화 효과**: `.schedule-dday-badge::before`에 은은한 번짐 블롭 효과 추가.
- **일정 작성 모달 리치에디터**: `<textarea>` → SVG 툴바(제목/굵게/글머리/번호/구분선) + `contenteditable` 리치에디터로 교체, 모달 680px로 확장. 이 작업 중 **"수정하기"를 열어도 기존 내용이 항상 비어있고, 저장하면 기존 리스트 서식이 통째로 사라지는 버그**도 같이 발견해 수정(`openScheduleModal`/`saveSchedule`을 innerHTML 기반으로 교체).
- feed-filter-tabs(`.feed-tab`)의 불필요한 box-shadow 제거.

## 5. 행운편지 테마 — 선물상자 ↔ 우체통 (신동수 포크)

- 신동수 포크에 실제 **우체통(mailbox) SVG**(회전문, 깃발 애니메이션, 편지 아이콘)가 있는 것을 확인 — 기존 선물상자와는 완전히 다른 비주얼.
- 두 비주얼(`.letter-box-visual-giftbox` / `.letter-box-visual-mailbox`)을 같은 버튼 안에 함께 렌더링해두고, 사용자설정에서 고른 테마(`clov_letterBoxTheme`)에 따라 클래스로 토글하는 방식으로 구현. 우체통 테마에는 "편지 있음"(`has-mail`) 상태 애니메이션도 포함 — 편지가 있으면 깃발이 올라가고 내부 편지가 보임.

## 6. 참여자별 추억 증거 카드 테마 — 빨랫줄 ↔ 겹침 카드 (신동수 포크)

- 기존(빨랫줄+빨래집게, 슬롯 ±2)과 신동수 포크의 코드플로우 스타일(와이어/집게 없이 카드가 겹쳐 쌓이는 형태, 슬롯 ±3까지 확장)을 사용자설정에서 고를 수 있는 테마(`clov_evidenceCardTheme`)로 구현.
- 참여자 아바타(`.presence-tile`)를 기존 "이름 텍스트가 붙은 캡슐형"에서 **완전한 원형(28×28px)** 으로 단순화 — 이름 라벨 표시는 제거.

## 7. 하단 필름 스트립 — 드래그/휠 스크롤 (신동수 포크)

- 필름 라벨("과거"/"현재")을 세로쓰기 필름통 모양 박스로 변경.
- 마우스로 필름을 눌러 끌면 스크롤되는 드래그 기능, 마우스 휠(세로)을 가로 스크롤로 변환하는 기능 추가(`initEvidenceInteractions()`).
- 드래그 중 프레임을 실수로 클릭해 사진이 전환되는 것을 막기 위해 `window.isFilmDraggingPreventClick` 플래그로 `setEvidenceIndex()` 진입을 차단.

> **참고**: 위쪽 폴라로이드 스테이지의 연속 슬라이드 애니메이션(88ms 스텝 이동), 빨래집게/와이어 완전 제거, ±3 슬롯 확장은 이번엔 필름 스트립/증거카드 테마에만 부분 반영했고 스테이지 쪽엔 포팅하지 않았다 — 필요 시 추가 작업 여지 있음.

## 9. 사용자설정 — 프로필 사진 필드 + 테마 섹션 확장

- **프로필 사진**: 좌측 레일의 미니 아바타를 클릭 불가능한 표시 전용으로 바꾸고, "기본 정보" 섹션 맨 위(이름/닉네임 필드 위)에 별도의 64px 원형 업로드 버튼을 신설. 레일과 새 필드 두 곳의 이미지/이니셜을 항상 동시에 갱신하도록 처리.
- **테마 탭에 3개 섹션 신규 추가**: 배경(준비중 placeholder), 우정편지 테마(선물상자/우체통), 참여자별 추억 증거 카드(빨랫줄/겹침카드) — 위 5~6절 내용을 여기서 고를 수 있게 연결.
- 나비게이션 라벨을 "라이트모드 · 다크모드"에서 **"테마 설정"**으로 변경(테마 탭에 항목이 늘어나 이름이 실제 내용과 안 맞았음).

## 10. 사용자설정 모달 — 공용 컴포넌트로 리팩터링 (가장 큰 작업)

테마 섹션이 계속 늘어나면서 `index.html`과 `makerooms.html`에 중복 관리되던 모달(HTML + JS 함수 20여 개)을 매번 양쪽에 수동으로 동기화해야 하는 부담이 커져, `clov-header.js`/`clov-modal.js`와 같은 패턴의 공용 컴포넌트로 뽑아냈다.

**신규 파일**: `02-main/components/clov-profile-modal.js` (461줄)
- 모달 HTML을 `document.body`에 주입(`injectHTML()`, 중복 주입 방지 가드)
- 여닫기/저장/테마 전환 관련 함수 전부(약 20개) 포함
- 사용법: `<script src=".../clov-profile-modal.js?v=2">` 추가 후 `ClovProfileModal.init()` 호출

**두 페이지 CSS 클래스 체계가 서로 달라서 생긴 이슈와 해결**:
`index.html`은 `.modal-form-group`+무클래스 `<label>`/`<input>`, 버튼 `.btn-sub`/`.btn-main`를 쓰고, `makerooms.html`은 `.field-wrap`+`.field-label`+`.text-input`, 버튼 `.profile-footer-btn`을 쓴다. 두 페이지가 완전히 별도 스타일시트를 쓰고 있어 클래스 이름이 겹칠 걱정이 없다는 점을 이용해, 컴포넌트의 모든 폼 요소에 **두 체계의 클래스를 동시에** 넣는 방식으로 해결했다(`class="modal-form-group field-wrap"` 등). `makerooms.html`에는 없던 `.is-coming-soon`/`.theme-coming-soon-badge` 두 CSS 규칙만 추가로 이식했다.

**발견/수정한 버그**: `ClovProfileModal.init()`이 `<body>` 상단(다른 요소가 아직 파싱되기 전)에서 호출되다 보니, 저장된 우정편지 테마가 새로고침 시 적용되지 않는 문제가 있었다. `document.readyState === 'loading'`이면 `DOMContentLoaded`까지 테마 적용을 미루도록 수정해 해결.

**부가 효과**: `makerooms.html`에도 이제 배경/우정편지 테마/증거카드 테마 옵션이 전부 노출된다(전엔 라이트/다크모드만 있었음). 이 페이지엔 행운편지 상자나 추억 증거 뷰어가 실제로 없어서 로컬 효과는 없지만, `localStorage`에 저장되는 전역 설정이라 나중에 `index.html`을 방문하면 그대로 적용된다.

## 검증 내용

- 매 변경마다 `node --check`로 JS 문법 확인, `preview_*` 도구로 브라우저에서 직접 클릭/드래그/새로고침 재현
