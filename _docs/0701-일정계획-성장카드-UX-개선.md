# 2026-07-01 일정계획 성장 카드 UX 개선 기록

## 작업 배경

`02-main/index.html`의 일정계획 탭에서 약속 성장 카드가 11개 이상 표시될 때 가로 방향으로 화면 밖으로 밀려나는 문제가 있었다.

기존 UX는 카드 리스트를 가로 캐러셀처럼 보여주고 좌우 페이드와 화살표를 사용하는 구조였다. 이 방식은 데스크톱 화면 폭마다 보이는 카드 수와 잘림 정도가 달라져, 오른쪽 테마 테스트 패널과 함께 볼 때 부자연스럽게 느껴졌다.

이번 작업에서는 일정계획의 성장 카드를 데스크톱에서는 보드형 그리드로, 모바일에서는 가로 스와이프형으로 분리했다.

---

## 최종 UX 방향

### 데스크톱

- 카드 리스트를 가로 캐러셀이 아닌 반응형 그리드 보드로 표시한다.
- 카드가 11개 이상이어도 화면 밖으로 밀리지 않고 다음 줄로 자연스럽게 줄바꿈된다.
- 좌우 화살표와 양끝 페이드 효과는 제거한다.
- 오른쪽 테마 테스트 패널과 카드 영역이 겹치지 않도록 카드 레일의 최대 폭을 제한한다.
- 그림자 효과를 제거해 화면이 더 평평하고 안정적으로 보이게 한다.

### 모바일

- 모바일 창에서는 기존처럼 가로 스와이프 UX를 유지한다.
- 좁은 화면에서는 한 줄 보드보다 손가락으로 넘기는 방식이 더 자연스럽기 때문이다.

---

## 적용된 UI 구조

### 카드 표시 방식

```css
.growth-card-list {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(148px, 148px));
  justify-content: start;
  gap: 14px;
  overflow: visible;
}
```

데스크톱에서는 카드가 고정 폭 `148px` 기준으로 배치되고, 남는 공간에 따라 열 수가 자동으로 바뀐다.

확인된 배치:

| 화면 폭 | 카드 열 수 | 줄 수 | 가로 overflow |
|---|---:|---:|---|
| 1024px | 4열 | 5줄 | 없음 |
| 1366px | 6열 | 4줄 | 없음 |
| 1600px | 7열 | 3줄 | 없음 |

### 모바일 override

```css
.mobile-window .growth-card-list {
  display: flex;
  flex-direction: row;
  flex-wrap: nowrap;
  overflow-x: auto;
  scroll-snap-type: x mandatory;
}
```

모바일은 카드를 줄바꿈하지 않고 수평 스크롤로 유지한다.

---

## 제거한 요소

### 박스 쉐도우 제거

다음 주요 일정계획 요소의 그림자를 제거했다.

- `.growth-hero`
- `.growth-density button.active`
- `.growth-card-list`
- `.growth-card`
- `.growth-card.four-cut`
- `.growth-detail`
- `.desktop-window`

선택된 카드는 그림자 대신 `outline`으로만 강조한다.

### 캐러셀 UI 제거

다음 요소를 제거했다.

- 이전 약속 보기 버튼
- 다음 약속 보기 버튼
- 캐러셀용 JS 스크롤 핸들러 `scrollScheduleCards`
- 버튼 클릭 이벤트 연결 코드

이제 보이는 UX와 코드 의도가 모두 보드형 카드 리스트에 맞춰져 있다.

### 브라우저 렌더링 검증

로컬 서버에서 `02-main/index.html`을 열고 일정계획 탭을 확인했다.

확인 항목:

- 성장 카드 14개 표시
- 필터 칩 유지: 전체 / 인증 가능 / 다가오는 약속 / 완료된 약속
- 카드 리스트 `display: grid`
- 캐러셀 버튼 DOM 0개
- 문서 전체 가로 overflow 없음
- 카드 리스트, 카드, 히어로, 상세 영역의 `box-shadow: none`
- 1024px, 1366px, 1600px에서 오른쪽 패널과 겹침 없음

## 현재 결론

이번 일정계획 카드 UX는 다음 방향으로 확정한다.

> 데스크톱은 한눈에 비교 가능한 보드형 그리드, 모바일은 손으로 넘기기 좋은 수평 스와이프.

이 방식이 13개 이상의 약속 데이터에서도 화면 밖 밀림을 막고, 데스크톱마다 다르게 보이는 문제를 가장 안정적으로 줄인다.
