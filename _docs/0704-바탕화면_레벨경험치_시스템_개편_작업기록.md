## 3. 대시보드 배경 테마 — LP 턴테이블 (계절별 사진 배경)

팀에서 만든 `clover-banner.html`(사계절 LP 배너 데모)을 기반으로, 우정공간 대시보드 배너(`.v5-scene`)에 절차적 클로버 들판 대신 **실사 사진 배경**을 고를 수 있게 했다.

- `V5_WALLPAPERS` 등록소(desktop.js) 신설 — `lp-turntable` 1개 등록, 계절별 이미지 4장(`assets/ai-style/clov_LP_banner_*.png`)
- CSS는 `.v5-scene[data-bg-theme]:not([data-bg-theme="field"])` 처럼 **"field(들판) 아닌 모든 배경은 사진"** 이라는 일반 규칙으로 작성 — 새 벽지를 추가해도 CSS는 안 건드리고 등록소에만 항목을 넣으면 되도록 설계
- 사진 배경 선택 시 절차적 지면 레이어(산/지면/클로버밭/안개/별/천체/구름)와 기존 LP 위젯은 자동으로 숨김
- **레코드판 인터랙션 포팅**: `clover-banner.html`에 있던 회전 하이라이트(`v5-photo-rec-shine`)·클릭 시 색종이 32개(`v5PhotoRecClick`)·음표 3개(♪♫♬) 스프라이트를 그대로 가져옴. 레코드 위치는 원본 좌표(970×215 기준)를 실제 렌더 크기에 맞춰 스케일/오프셋 변환(`v5PositionPhotoRec`)해서 창 크기가 달라져도 정확히 겹치도록 함
- **계절별 트랙 칩**: "OO 추억 재생 중 · N번째 트랙" 배지 추가, 계절별 색상은 `clover-banner.html` 원본 SEASON 설정값 그대로 이식
- 색종이 색상도 처음엔 하양/말차/하늘색/연분홍 고정 팔레트로 바꿨다가, "색종이는 원래대로 계절별로, 저 4색은 배너 테두리 글로우 효과에 쓰려던 것"이라는 피드백을 받아 **색종이는 계절별 원본 색상으로 되돌리고, 4색 고정 팔레트는 레벨업 펄스(아래 6번)의 테두리 글로우 색으로 옮김**

## 4. 바탕화면 시스템 — 앱 전체 배경 (대시보드 배경과 별개)

사용자가 "대시보드 배경이랑 전체 바탕화면을 헷갈린 것 같다"고 짚어줘서, 로그인/피드/편지 등 **화면 전체 바닥 배경**(`global-theme.css`의 body 그라디언트)을 바꾸는 별도 시스템을 새로 만들었다.

- `CLOV_APP_BACKGROUNDS` 등록소(clov-profile-modal.js) 신설, `getAppBackground`/`applyAppBackground`/`setAppBackground`/`renderAppBackgroundOptions`
- **발견한 문제 1**: `body`에만 배경을 넣었더니 화면엔 안 보임 — `.window-content`/`.main-content`가 자체 불투명 배경(`background-color` + 자체 그라디언트)을 갖고 있어서 body를 완전히 가리고 있었음. `applyAppBackground`가 `body` + `.window-content` + `.main-content` 세 곳 모두에 적용하도록 수정
- **발견한 문제 2 (중요)**: 이미지 경로를 `/02-main/...` 처럼 사이트 루트 절대경로로 넣었더니, `makerooms.html`(다른 폴더 깊이)에선 되는데 **`file:///C:/...`로 직접 열면 드라이브 루트로 해석돼 깨짐**(`ERR_FILE_NOT_FOUND`, 콘솔에 `'file:' URLs are treated as unique security origins` 경고까지 발생). `document.currentScript.src`로 스크립트 자기 자신의 실제 로드 경로를 잡아 `02-main/` 위치를 계산하는 `MAIN_BASE` 방식으로 교체 — `http://`로 열든 `file://`로 열든, 어느 페이지에서 부르든 항상 정확한 경로를 가리킴
- **바탕화면 5종 등록**: 🪵 우드&클로버(기본, 등록소 미포함) / 💿 LP 우드 데스크 / 🎶 LP 앨범 컬렉션 / 🌊 클로버 해안 엽서 / 🌆 네온 클로버 시티(사이버펑크풍, 원본 파일명의 특정 작품 레퍼런스는 사용자 화면에서 순화) / 🍃 미니멀 클로버(지오메트릭 스타일) — `02-main/background-concepts/`에 놓인 원본 파일들을 순서대로 확인하며 하나씩 추가

## 6. 사용자설정 UI 전면 개편 — 이모지 제거, 필/칩 스타일

"이모지 다 없애고 트렌디하게" 요청에 따라 테마 목록 6곳(테마/바탕화면/대시보드 배경/대표 커버 장식/우정편지 테마/참여자별 추억 증거 카드) 전부를 정리했다.

- 각 옵션의 이모지 아이콘 span + "✓" 체크마크 span 제거, 텍스트 라벨만 남김
- 세로 리스트+체크마크 방식 → **가로로 나열되는 필(pill) 버튼**으로 전면 교체: 기본은 투명 배경+옅은 테두리, 선택되면 진한 그린 배경+흰 텍스트로 꽉 채워짐(체크마크 대신 배경색 자체가 선택 상태를 표현), `flex-wrap`이라 바탕화면처럼 항목이 늘어나도 자연스럽게 줄바꿈
- 더 이상 안 쓰는 "준비중" 배지 관련 죽은 CSS(`is-coming-soon`, `theme-coming-soon-badge`) 정리

## 7. 우정 레벨/경험치 시스템 전면 재설계

기존엔 레코드판을 클릭할 때마다 레벨이 1~5 사이를 그냥 순환(`friendshipLevel % 5 + 1`)하는 데모용 로직이었다. 이걸 실제 하루 단위 경험치 시스템으로 새로 설계했다.

### 새 규칙
- 클릭 1번 = 경험치 12.5%(1/8), **하루 최대 8번**까지만 오르고 그 이상 클릭은 배너 인터랙션(회전+색종이)은 그대로 재생되지만 경험치는 더 안 늚
- 8번 클릭으로 게이지가 100%에 도달하면 **그 상태로 유지**되고(즉시 레벨업/리셋하지 않음), **다음 날 첫 클릭에서** 비로소 레벨업이 확정되고 게이지가 0%로 리셋되면서 그 클릭분(12.5%)이 곧바로 이어서 채워짐 — 8번째 클릭 순간 바로 다음 레벨 0%로 튕겨나가서 "꽉 찬 상태"를 볼 틈이 없었던 문제를 해결
- 최대 **레벨 777**, 도달 시 배지 표기가 "Lv.777"이 아니라 **"+777"** 로 고정
- 777개 레벨에 다 이름을 붙일 수 없어 111레벨씩 7개 티어로 묶음: 씨앗의 우정 → 새싹의 우정 → 초록 클로버 우정 → 무성한 클로버 들판 → 반짝이는 클로버 우정 → 황금빛 클로버 우정 → 전설의 클로버 우정
- 상태는 그룹별로 저장: `groupsData[x].level`/`levelProgress`(0~100)/`xpDate`(마지막 클릭 날짜)/`xpClicksToday`(0~8), `clov_groupsData`에 영속

### 같이 고쳐야 했던 부분
레벨을 1~5로 가정하고 하드코딩된 곳이 많아서, 최대 777 기준으로 그대로 두면 곧바로 터지거나 말이 안 되는 값이 나오는 상태였다.
- `클로버 개수 = 레벨 × 6` 공식 — 레벨 777이면 클로버 4662개를 렌더링하려던 걸 **7단계 티어 인덱스(0~6) 기준**으로 재계산하도록 수정 (클로버 개수/크기, 지면 색 보간, 네잎클로버 개수 전부 동일하게 티어 기준으로 변경)
- `V5_LVL`(레벨 1~5 고정 테이블, `.name`/`.pct`/`.clovers`/`.fourLeaf`) 전체 삭제 — `V5_LVL[level]`을 그대로 두면 레벨 6부터 `undefined` 참조 에러가 나던 걸 새 티어 시스템(`clovLevelInfo`)으로 교체
- 배경 테마 테스트 패널의 레벨 슬라이더 범위를 1~5에서 1~777로 확장

### 시각 피드백 보강
- 클릭할 때마다(레벨업 여부 상관없이) 배너 전체에 펄스 애니메이션이 항상 재생되도록 함(`triggerLevelPulse`를 `levelUp()` 맨 앞으로 이동) — 테두리에 도는 글로우 색은 하양/말차/하늘색/연분홍 중 클릭마다 랜덤
- 게이지가 실제로 안 보인다는 피드백을 받고, 경험치가 오를 때마다 게이지가 순간적으로 밝게 반짝이는 플래시 효과(`triggerXpFlash`, `.lv-pill-bg.is-pulse-xp`)와, 하루치를 다 채운(100%) 동안 계속 은은하게 빛나는 글로우(`.lv-pill.is-full`) 추가

## 8. 우정공간 대시보드 — 인생4컷 카드 UI 버그 수정

- **제목 말줄임 처리**: `.strip-title`에 `text-overflow: ellipsis`가 빠져 있어서 긴 제목이 그냥 잘리기만 하고 "..."이 안 보였음. 처음엔 2줄 클램프(`-webkit-line-clamp`) 방식으로 고쳤다가, 2줄 안에 다 들어가는 제목은 카드가 그만큼 늘어나 버려서 **한 줄 고정 + 말줄임**으로 재수정 — 모든 카드 높이가 통일됨
- **호버 시 카드 잘림**: `.growth-card-viewport`가 `overflow-x: auto` + `overflow-y: visible`인데, 브라우저 스펙상 가로/세로 중 하나라도 `auto`면 다른 쪽 `visible`도 자동으로 `auto`로 취급되는 규칙 때문에 호버 시 `-3px` 뜨는 카드 위쪽이 살짝 잘려 보였음. `.growth-card-list`에 `padding-top` 여유분을 줘서 해결

## 검증 내용

- 매 변경마다 `node --check`로 `desktop.js`/`clov-profile-modal.js` 문법 확인
- 브라우저 프리뷰(`localhost:3000`)로 실제 클릭 동작까지 확인. 단, 이 세션 내내 `preview_screenshot`(스크린샷 캡처)이 계속 타임아웃 나서 시각적 확인은 `preview_inspect`/`getComputedStyle`/`getBoundingClientRect` 등 코드 레벨 검증으로 대체함
- 레벨/경험치: 8번 연속 클릭 → 진행률 12.5/25/.../100%로 정확히 오르고 8번째에서 딱 멈추는 것, 9번째 클릭은 무반응인 것, 날짜를 어제로 돌린 뒤 클릭하면 그제서야 레벨업+리셋되는 것, 레벨 776→777 전환 및 "+777" 배지까지 각각 확인
- 배경 시스템: 등록한 배경 전부 사용자설정에 나열되는지, 선택 시 이미지가 200 OK로 로드되고 `body`/`.window-content`/`.main-content` 세 곳에 다 적용되는지, index.html·makerooms.html 양쪽에서 동일하게 동작하는지 확인
- 색종이: 계절(여름/겨울)별로 정확히 다른 색상 팔레트가 나오는 것 확인
- 매번 테스트 후 로컬스토리지/그룹 상태를 기본값으로 되돌려놓음

## 팀 공유 시 주의할 점

- **`desktop.css`/`desktop.js`/`clov-profile-modal.js`를 고치면 `index.html`(및 이걸 불러오는 다른 페이지)의 `?v=` 번호를 반드시 같이 올릴 것.** 안 올리면 실사용 브라우저가 예전 코드를 계속 캐시로 서빙한다 — 이번 세션에서 여러 번 이 문제로 "고쳤다고 했는데 안 바뀐다"는 혼선이 있었다
- **공유 컴포넌트(`clov-profile-modal.js`)에 새 이미지 경로를 넣을 땐 `MAIN_BASE`(파일 자기 자신의 로드 경로 기준)를 쓸 것.** `/02-main/...` 같은 사이트 루트 절대경로나 상대경로를 직접 쓰면, 페이지 폴더 깊이가 다르거나 `file://`로 직접 여는 경우 깨진다
- **바탕화면/대시보드 배경 추가는 각각 `CLOV_APP_BACKGROUNDS`(clov-profile-modal.js) / `V5_WALLPAPERS`(desktop.js) 등록소에 항목만 추가하면 된다.** CSS는 이미 등록소 기반 일반 규칙으로 짜여 있어서 새 항목을 위해 따로 안 고쳐도 됨
- **레벨 관련 코드를 만질 땐 "레벨은 1~5"라고 가정하지 말 것.** 최대 777이고, 이름/시각효과는 `clovLevelInfo(level)`(7티어 기준)로 조회해야 한다
- 대표 커버 장식은 현재 "준비중" 상태 — 장식을 정하면 `getCoverTheme`/`setCoverTheme` 등 기존 함수를 재사용하거나 바탕화면과 같은 등록소 패턴으로 다시 만들 것
