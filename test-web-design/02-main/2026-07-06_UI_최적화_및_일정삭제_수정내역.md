## 1. 일정계획 삭제 기능 추가 및 다각화 (신규)
- **문제점**: 기존 일정계획(D-day 약속)을 삭제하려면, 약속을 선택한 후 하단의 영수증 디테일 영역까지 스크롤하여 내려가야만 삭제 버튼을 찾을 수 있었습니다. 또한 일정을 수정하는 모달 창 내부에는 삭제 버튼이 없어 관리가 불편했습니다.
- **개선 내용**:
  1. **약속 정보 수정 모달(`dt-schedule-modal`) 삭제 연동**:
     - 모달 하단 좌측에 붉은색 톤의 **[삭제]** 버튼(`.danger`)을 배치했습니다.
     - 기존에 등록된 약속을 수정하려고 창을 열었을 때만 삭제 버튼이 동적으로 나타나며(`display: inline-block`), 새 약속을 생성할 때는 자동으로 숨겨집니다.
     - 삭제 버튼 클릭 시 모달이 즉시 닫히며, 확인 알림창(`clovConfirm`)과 함께 안전하게 일정을 삭제하는 `deleteScheduleFromModal` 함수를 구현했습니다.
  2. **4컷 약속 카드(`.growth-card`) 상단 즉시 삭제 버튼 추가**:
     - 일정계획 목록에 나열된 각 약속 카드의 헤더(`.strip-header`) 우측(D-day 알약 뱃지 옆)에 **휴지통 아이콘 버튼(`.strip-card-delete-btn`)** 을 신규 추가했습니다.
     - 불필요한 스크롤 없이도 목록을 보며 마우스 클릭 한 번으로 약속을 간편하게 지울 수 있도록 UX를 극대화했습니다.
     - 호버 시 코랄 레드 그라디언트 배경(`hover: #ff7675`)과 부드러운 스케일 애니메이션(`transform: scale(1.08)`)을 적용하여 고급스러운 반응성을 부여했습니다.
- **수정 파일**: `index.html`, `js/schedule.js`, `styles/schedule.css`

## 2. 행운편지 / 우정편지 카드 1줄 고정 및 슬림 규격화
- **문제점**: 편지 본문이 길 경우 여러 줄로 개행되면서 카드 전체의 세로 높이가 아래쪽으로 불균형하게 늘어났으며, 편지 개수가 적을 때 남는 여백을 채우기 위해 카드가 강제로 세로로 위아래로 길어지는 현상이 있었습니다.
- **개선 내용**:
  - 편지 카드 본문(`.letter-inbox-card p`)에 `white-space: nowrap; overflow: hidden; text-overflow: ellipsis;` 속성을 적용하여 아무리 긴 편지라도 무조건 깔끔하게 **1줄만 보이고 말줄임표 처리**되도록 고정했습니다.
  - 편지 리스트 그리드(`.letter-inbox-list`)에 `align-content: start; grid-auto-rows: max-content;`를 적용하고, 각 카드(`.letter-inbox-card`)의 높이를 **`76px`로 고정**하여 편지 개수와 관계없이 항상 균일하고 슬림한 컴팩트 박스를 유지하도록 수정했습니다.
- **수정 파일**: `css/desktop.css`, `styles/letter.css`

## 3. 월별 추억 아카이브 텍스트 및 흰색 배경 개선
- **문제점**: 다크모드 전환 시 아카이브 타이틀과 부제목이 흰색으로 변해 배경색과 묻히는 문제가 있었고, 텍스트 뒤의 흰색 반투명 박스 배경이 너무 연해 글자 가독성이 저하되었습니다.
- **개선 내용**:
  - 아카이브 타이틀과 부제목 텍스트를 어떤 모드에서나 항상 진한 검정 계열(`#1a1a1a`, `#333333`)로 고정되도록 CSS 규칙을 명시했습니다.
  - 글자 뒤쪽의 흰색 반투명 박스(`.archive-text-overlay`)의 불투명도를 기존 75%에서 **88%~82% 수준으로 대폭 강화**하여 배경 패턴이 비치지 않고 글자가 뚜렷하게 부각되도록 만들었습니다.
- **수정 파일**: `css/desktop.css`

## 5. 우정공간 참여 멤버 동적 동기화 및 아바타 4개 제한

## 6. 참여자별 추억 증거 카드 호버 시 scale 제거 및 마우스 위치 기반 동적 3D 회전(rotate)+float 부유 효과 적용
- **문제점**: 다른 카드들의 확대(scale) 효과를 제거하는 과정에서 참여자별 추억 증거 카드만의 특별한 인터랙션이 밋밋해지거나 원근감이 부족해질 수 있었으며, 부모 슬롯(`transform: scale(...)` 등)의 2D 변형 레이어로 인해 내부 3D 회전 각도가 평면화되는 현상이 발생했습니다.
- **개선 내용**:
  - **마우스 위치 기반 동적 3D 회전 각도 계산**: 마우스가 게시물 카드 위를 움직일 때(`pointermove`), 카드 중심점을 기준으로 마우스 커서가 오른쪽으로 이동하면 우측이 입체적으로 다가오고(`+rotateY`), 왼쪽으로 이동하면 좌측이 다가오도록(`-rotateY`) 정밀한 비례 각도를 계산하는 인터랙션 로직을 적용했습니다. (사용자 요청에 따라 입체감을 50% 더 증폭하여 좌우 최대 ±18도, 상하 최대 ±15도로 상향)
  - **CSS 3D 렌더링 파이프라인 정규화 (`perspective` & `preserve-3d`)**: 카드의 `transform` 속성 자체에 `perspective(800px)`를 주입하고, 부모 컨테이너(`.cline-cards`, `.cline-card-slot`) 및 폴라로이드 카드 요소에 `transform-style: preserve-3d;`를 적용하여 빨랫줄, 겹침 카드(코드플로우), 부채꼴(팬) 테마 등 모든 뷰 모드에서 마우스 호버 시 입체 회전(`--rotateX`, `--rotateY`)이 왜곡이나 덮어쓰기 없이 생생한 원근감으로 표현되도록 완벽 최적화했습니다.
  - **실시간 CSS 변수 제어 및 최적화**: 계산된 각도는 실시간으로 CSS 변수(`--rotateX`, `--rotateY`)에 주입되며, 마우스가 카드에서 벗어나면(`pointerout`) 각도가 즉시 0deg로 초기화되어 원래의 평평한 상태로 돌아옵니다. 윈도우 레벨의 이벤트 위임 방식을 사용하여 DOM이 새로고침되거나 카드가 추가되어도 성능 저하 없이 부드럽게 작동합니다.
  - **좌우 기울기 제거 및 부유(`float`) 높이 60px 상향 조정**: 호버 시 카드가 좌우로 기울어지거나 슬롯의 기본 회전 각도(2D Z축 회전)가 변하던 모션을 완전히 제거하고 오직 마우스 위치 기반 3D 입체 회전만 작동하도록 정규화했습니다. 또한, 부유 애니메이션(`@keyframes evidenceCardFloat`)의 최대 상승 높이를 기존 `-8px`에서 `-60px`로 대폭 상향 조정하여 호버 시 시원하고 극적인 떠오름 효과를 연출했습니다.
  - **3D 입체 회전 시 카드 간 간섭/잘림 방지 (`z-index: 100`)**: 카드가 3D로 크게 회전(±18도)하고 위로 부유(-60px)할 때 옆에 있는 인접 슬롯의 쌓임 맥락(Stacking Context)으로 인해 카드가 파고들거나 잘리는 현상이 없도록, 마우스 호버 및 `is-3d-hovering` 활성화 시 카드 자체뿐 아니라 **부모 슬롯(`.cline-card-slot`, `.polaroid-fan-slot` 등)에도 최상위 계층인 `z-index: 100 !important;`를 동시 부여**하여 어떤 각도에서도 다른 카드와 간섭 없이 완벽히 최전방에 렌더링되도록 개선했습니다.
  - **제일 앞 카드 Z축 전진(`translateZ`)을 통한 물리적 간섭 원천 차단**: 겹침 카드(Coverflow) 및 부채꼴(Fan) 테마에서 제일 앞에 위치한 활성 카드(`.is-active`, `.fan-center`)에 **`translateZ(90px) scale(1.08)` 및 `z-index: 50`을 부여**하여 3D 공간상에서 사용자 쪽으로 더 확실하게 튀어나오도록 배치했습니다. 이를 통해 18도 이상의 큰 3D 회전 시에도 카드가 뒤쪽 평면(Z=0)의 인접 카드들과 물리적으로 교차하거나 파고드는 현상을 원천 차단했습니다.
  - **3D 호버 시 마우스 터치 떨림(Jittering) 현상 완벽 해결**:
    - **원인 분석**: 3D 회전 각도와 부유 모션(-60px)에 의해 실시간으로 변형 및 이동 중인 카드 요소 자체의 바운딩 박스(`getBoundingClientRect()`)를 기준으로 마우스 좌표를 계산할 경우, 각도가 바뀔 때마다 영역이 이동하면서 계산 각도가 튀고 무한 피드백 루프가 발생하는 고전적인 3D 인터랙션 떨림 현상이 원인이었습니다.
    - **JS 기준점 고정**: 마우스 트래킹 시 회전/이동하는 카드 대신 절대 변형되지 않는 **고정된 부모 슬롯(`.cline-card-slot`, `.polaroid-fan-slot` 등)의 영역을 불변 기준점(`refEl`)으로 삼아 마우스 좌표 및 각도를 정밀 계산**하도록 개선하여 무한 피드백 루프를 원천 제거했습니다. 또한 `pointerout` 판단 시에도 카드뿐 아니라 슬롯 내부에 마우스가 머물고 있다면 호버를 유지하도록 안정화했습니다.
    - **CSS 저역 통과 필터링**: 실시간 각도 렌더링 시 기존의 급격한 선형 전환(`0.06s linear`)을 부드러운 저역 통과 이징인 `transform 0.15s cubic-bezier(0.2, 0, 0.2, 1)`로 업그레이드하여 마우스 이동 시 미세한 떨림이나 진동 없이 묵직하고 매끄러운 3D 입체 모션을 완성했습니다.
  - **카드 슬라이드 이동 방향에 맞춘 3D 기울기 모션 연동**:
    - **방향성 슬라이드 기울기 연동**: 겹침 카드(Coverflow) 슬라이드 전환 시(`cf-deck-left`, `cf-deck-right`), 카드 뭉치가 이동하는 진행 방향에 맞춰 자연스럽게 공기 저항을 받는 듯한 3D 기울기(`rotateY(±8deg)`)를 추가하여 이동 모션의 역동성을 극대화했습니다. (마우스 호버에 의한 3D 회전 각도는 사용자 피드백에 따라 기존의 입체 회전 각도인 `rotateY = normX * 18; rotateX = -normY * 15;`로 복구 유지)
- **수정 파일**: `js/space.js`, `js/desktop.js`, `styles/space.css`, `css/desktop.css`
