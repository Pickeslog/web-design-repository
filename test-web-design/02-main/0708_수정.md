## 1. 777 레벨(만렙) 달성 시 교감 이펙트 추가

- **요청 내역**: 현재까지 프로젝트를 봤을 때 수정하고 싶은 것 제안 → 만렙 상태 교감 개선
- **문제/원인**: 우정 레벨이 최고치(777)에 도달한 상태에서 마스코트를 클릭하면 단순히 "이미 최고치에 도달했습니다" 토스트 메시지만 뜨고 아무 반응이 없어 어색했습니다.
- **수정 내용**: 만렙 달성 후에도 하루 3회 교감 제한을 유지하면서, 클릭 시 마스코트 주변에서 빨간 하트가 5개 동시에 여러 방향으로 흩어지며 위로 떠오르는 애니메이션이 재생되도록 추가했습니다. 동시에 마스코트가 "사랑이 넘치는 우리 우정! 하트를 받았어" 말풍선을 띄웁니다.
- **수정 파일**: `space.js`, `desktop.js`

## 2. 777 레벨(만렙) 시 게시글 작성 및 일정 계획 작성·완료 시 반짝이 이펙트 추가

- **요청 내역**: 현재까지 프로젝트를 봤을 때 수정하고 싶은 것 제안 → 만렙 상태 경험치 획득 처리 개선
- **문제/원인**: 우정 레벨이 777(만렙)에 도달한 후에도 추억 피드 게시글 작성 또는 일정 계획 작성·완료 시 경험치(XP) 획득 로직이 그대로 동작하고 있었습니다. 만렙 상태에서는 경험치가 더 이상 의미 없는데도 동일한 처리가 이루어져 어색했습니다.
- **수정 내용**: 777 레벨 상태에서 게시글 작성 또는 일정 계획 작성·완료 시, 경험치를 올리는 대신 화면에 반짝이(Sparkle) 이펙트가 터지는 연출로 교체했습니다. 만렙임을 축하하는 시각적 피드백을 제공합니다.
- **수정 파일**: `space.js`, `desktop.js`

## 3. '작성 완료' 성공 모달 개선 — 일정 계획 & 추억 피드 모두 적용

- **요청 내역**: "약속 여정도 작성완료 나오게 해줘"
- **문제/원인**: **일정 계획(약속)**과 **추억 피드** 두 가지 모두, 작성 후 저장하면 아무 안내 없이 창이 그냥 닫혀버렸습니다. 사용자가 저장이 정상적으로 됐는지 알 수 없는 상태였습니다.
- **수정 내용**: 두 가지 모두 작성 완료 시 "작성 완료" 성공 모달 창이 나타나도록 로직을 각각 추가했습니다. 또한 성공 모달 내의 불필요한 "나중에 하기" 버튼을 제거하여 디자인을 단순하고 깔끔하게 통일했습니다.
- **수정 파일**: `index.html`, `desktop.js`

## 4. 모달 외부 배경 클릭 시 자동 닫힘 방지 — 일정 계획 & 추억 피드 모두 적용

- **요청 내역**: (프로젝트 개선 제안 일환)
- **문제/원인**: **일정 계획 작성 모달**과 **추억 피드 작성 모달** 모두, 실수로 모달 바깥의 어두운 배경 영역을 클릭하면 작성 중이던 내용이 모두 날아가며 창이 닫혀버리는 문제가 있었습니다.
- **수정 내용**: 모달 외부 영역(배경) 클릭 시 창이 닫히도록 연결되어 있던 이벤트 리스너를 두 모달 모두에서 제거했습니다. 이제 반드시 'X' 버튼이나 '취소' 버튼을 명시적으로 눌러야만 창이 닫힙니다.
- **수정 파일**: `index.html`

## 5. 다크 모드 시 일정 계획 작성 글자 안 보임 수정

- **요청 내역**: "다크모드일경우 일정계획 게시글 작성 시 글자가 안 보여 추억피드처럼 수정해줘"
- **문제/원인**: 다크 모드 상태에서 일정 계획 작성 폼(form)의 입력 칸 안에 글자를 입력하면, 글자 색상이 배경과 동일한 어두운 색으로 처리되어 보이지 않았습니다.
- **수정 내용**: 해당 입력 칸에 다크 모드용 텍스트 색상 변수(`var(--text-color)`)가 올바르게 적용되도록 CSS 선택자를 수정하여 어느 모드에서도 글자가 잘 보이도록 통일했습니다.
- **수정 파일**: `desktop.css`

## 6. 다크 모드 시 마스코트 대사(말풍선) 시인성 개선

- **요청 내역**: "다크모드때 마스코트의 대사가 잘 안 보여" / "마스코트 대사의 글자 두께는 이전으로 돌려줘"
- **문제/원인**: 다크 모드에서 마스코트 말풍선의 배경색이 어두워져 그 위에 있는 텍스트가 함께 어두워지면서 가독성이 매우 낮아지는 문제가 있었습니다. 이를 수정하는 과정에서 실수로 `font-weight: bold` 속성이 추가되어 글자가 원래보다 굵어지는 2차 문제가 발생했습니다.
- **수정 내용**: 다크 모드에서 말풍선 배경을 흰색으로 고정하고 글자색을 진한 색으로 명시하여 가독성을 높였습니다. 이후 실수로 추가된 굵은 글씨 속성을 제거하고 원래의 얇고 깔끔한 폰트 두께로 복구했습니다.
- **수정 파일**: `croby-mascot.css`

## 7. 추억 피드 카드 전체 크기 및 태그/메타 정보 간격 조정

- **요청 내역**: (프로젝트 개선 제안 일환)
- **문제/원인**: 추억 피드의 흰색 카드 전체 크기(높이 및 내부 여백)가 고정되어 있어 콘텐츠 양에 따라 레이아웃이 어색하게 보이는 문제가 있었습니다. 또한 카드 내부에서 해시태그(Tag) 영역과 날짜·시간 등의 메타 정보 영역 사이의 간격이 너무 좁아 답답하게 느껴졌습니다.
- **수정 내용**: 카드의 전체 높이와 `padding` 값을 조정하여 크기를 개선했습니다. 태그 영역과 메타 정보 영역 사이의 `gap` 및 `margin` 값도 함께 조정하여 여백을 조금 더 넉넉하게 벌렸습니다.
- **수정 파일**: `desktop.css`

## 9. 날짜 입력 칸 클릭 범위 확장 (달력 팝업 편의성 개선)

- **요청 내역**: "달력 이모지만 클릭했을때만 달력을 나오게 하지말고 여기 코드를 클릭 했을때 달력이 나오게 해줘"
- **문제/원인**: 기존에는 입력칸 우측의 작은 달력 아이콘 부분만 정확하게 클릭해야 달력 창이 열려 불편했습니다.
- **수정 내용**: `input[type="date"]` 태그에 `onclick="this.showPicker ? this.showPicker() : null"` 속성을 추가하여, 텍스트 영역이나 빈 공간 등 입력칸 안의 아무 곳이나 클릭해도 달력 선택 창이 바로 열리도록 개선했습니다.
- **수정 파일**: `index.html`
