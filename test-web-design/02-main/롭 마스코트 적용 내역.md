# 롭(Rob) 마스코트 적용 내역

기존 크로비(Croby) 마스코트 위젯(`js/croby-mascot.js`, `css/croby-mascot.css`)에 두 번째 캐릭터 **롭(rob)**을 추가하고, 롭 전용 인터랙션(코드창 말풍선, 클릭 리액션, 드래그로 들어올리기 연출)을 붙였다. 크로비 쪽 동작은 전혀 건드리지 않았다.

## 추가/수정한 파일

| 파일 | 내용 |
|---|---|
| `assets/rob/` (신규) | 롭 스프라이트 — `idle`, `dizzy`, `sleep`, `pulled`, `scared`, `angry`, `find`, `pencil` (총 8장) |
| `js/croby-mascot.js` | `CHARACTERS` 레지스트리에 `robot` 항목 추가, 캐릭터별 대사(`TEXT`) 분리, 롭 전용 타이핑 효과·글리치·드래그 시퀀스·클릭 리액션 로직 추가 |
| `css/croby-mascot.css` | 롭 전용 말풍선(코드 에디터 스타일), 글리치/커서 파괴/드래그 단계별 키프레임 추가 |
| `components/clov-profile-modal.js` | 사용자설정 > 테마 탭에 "마스코트 캐릭터"(크로비/로봇) 선택 UI 추가 |
| `components/clov-header.js` | 드롭다운의 "사용자설정" 아이콘을 Phosphor `Gear`(PiGear)로 교체, 호버 시 반 바퀴 회전 |

## 캐릭터 선택

- 사용자설정 > 테마 > "마스코트 캐릭터"에서 크로비/로봇 중 선택, `localStorage.clov_mascotCharacter`에 저장
- `window.CrobyMascot.setCharacter(id)`로 실시간 전환 (진행 중이던 타이핑/오버라이드 스프라이트도 함께 정리)

## 롭 전용 인터랙션

### 1. 말풍선 — 코드 에디터 스타일
- 다크 배경(`#1e1e2e`) + 모노스페이스 폰트 + 좌상단 신호등 점(빨/노/초) + `>` 프롬프트 프리픽스
- 대사가 한 글자씩 타이핑되고(글자당 55ms) 옆에 깜빡이는 커서가 붙는다 (`typeBubble()`)
- 크로비는 기존처럼 흰 말풍선 + 즉시 표시 그대로 유지

### 2. 클릭 리액션
- 기본 대사 풀: "Clov.에 온걸 환영해", "안녕 (닉네임) 내 이름은 롭이야!", "인간 시대에 끝이 도래했다" (닉네임은 `localStorage.clov_profile_nickname`에서 읽음, 없으면 "사용자")
- 특수 리액션 2종 — 대사와 함께 스프라이트도 잠깐 바뀜:
  - `find.png` + "기록된 추억을 되돌아보자, (닉네임)!"
  - `pencil.png` + "추억을 남기는 습관은 좋은거야"
- 0.9초 내 3연타 시 dizzy 진입 — 어지러움 문구는 `001011010101(어지러워..)`, 근처에 빨간 0/1이 튀는 글리치 이펙트(`spawnGlitch`) 동반

### 3. 머리 잡고 들어올리기 (드래그)
스프라이트 상단 절반(머리 부분)을 잡고 끌 때만 시작됨.

1. **들어올림(lifted)** — `pulled.png` + "오오 늘어난다..", 커서를 따라 이동
2. **무서워함(scared)** — 잡은 채로 **일정 높이(150px) 이상** 들어올려야 전환됨(시간이 아니라 높이 기준). `scared.png` + "너무 높아!!", 좌우로 버둥거리는 애니메이션
3. **화남(angry)** — scared 진입 후 3초 뒤 `angry.png` + "날 내려놔, (닉네임)!", 이 순간 **커서 파괴 연출** 실행(유리조각 12개 튕김 + 2초간 시스템 커서 숨김) 후 롭은 즉시 원위치로 낙하

낮게 들어올린 채로 오래 잡고 있어도(150px 미만) 계속 lifted 상태만 유지되고 scared/angry로 넘어가지 않는다. 임계 높이 도달 전에 손을 놓으면 특수 대사 없이 즉시 원위치로 복귀한다.

## 검증 방법

로컬 프리뷰 서버에서 `http://localhost:3000/02-main/index.html` 접속 후:
- `setMascotCharacter('robot')`으로 전환, `PointerEvent`를 직접 dispatch해 드래그 시퀀스(50px 저고도 → lifted 유지, 180px 고고도 → scared → 3초 후 angry) 확인
- `localStorage.clov_profile_nickname` 값을 바꿔 화남/클릭 리액션 문구에 정확히 반영되는지 확인
- 클릭을 반복해 `find.png`/`pencil.png` 리액션과 스프라이트 전환이 정상 노출되는지 확인
- 커서 파괴 시 `document.documentElement.classList.contains('croby-cursor-hidden')`와 `.croby-cursor-shard` 개수로 이펙트 발생 여부 확인
