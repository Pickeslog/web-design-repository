# 버거노인(Burger Oldman) 마스코트 적용 내역

크로비(Croby)·롭(Rob)에 이어 **세 번째 캐릭터**를 추가했다. 크로비와 같은 **종이 오려낸 듯한 질감과 굵은 검은 외곽선**을 유지해 세계관을 맞췄고, 기존 두 캐릭터의 동작은 전혀 건드리지 않았다.

## 추가한 파일

| 파일 | 내용 |
|---|---|
| `assets/burger-oldman/` (신규) | `idle`(기본 스프라이트) · `body`(몸통 레이어) · `wave-arm`(인사 팔 레이어) · `draft.jpg`(사용자 초안) |
| `burger-oldman.html` (신규) | 레이어 분리 기반 마스코트 실험 — 종이 흔들림·김·클릭 인사·팔 흔들기 |

프로덕션(`clov-web`) 반영은 아래 "앱 반영" 참고.

## 캐릭터 콘셉트

- 인자하고 따뜻한 **햄버거 할아버지**
- 참깨가 박힌 번, 버거 재료(양상추·치즈·패티), 하얀 수염, 둥근 안경, 장갑과 큰 신발

### 디자인 결정

| 결정 | 이유 |
|---|---|
| 지친 표정 → **눈동자 하이라이트가 있는 큰 눈 + 부드러운 미소** | 인자한 톤이 콘셉트인데 지친 표정이 그걸 깎았다 |
| **붉은 볼 제거** | 토마토 재료와 색이 겹쳐 얼굴이 산만해졌다 |
| 볼 포인트 → **양쪽 작은 참깨 주근깨** | 볼을 비우니 허전한 자리를, 번의 참깨와 같은 요소로 채웠다 |
| 최종본 **투명 PNG로 분리** | 배경 테마 위에 얹히는 자리라 배경이 있으면 안 된다 |

## HTML 실험 (`burger-oldman.html`)

정적 이미지가 아니라 **HTML/CSS/SVG 필터 위에서 반응하는** 형태로 만들었다.

### 구현한 동작

- 종이 질감의 **미세한 흔들림** (SVG `feTurbulence` 기반 `#wobble` 필터)
- 따끈한 **김이 올라오는** 효과
- **클릭 시 인사 + 말풍선**
- **몸통과 왼쪽 팔을 분리**한 뒤 팔만 어깨 기준으로 회전하는 손 흔들기

팔 흔들기 때문에 `body.png` / `wave-arm.png` **두 장이 따로 필요하다.** `idle.png`는 두 레이어가 합쳐진 완성본으로, 앱에서 쓰는 것은 이쪽이다.

### 제외한 동작

| 시도 | 왜 뺐나 |
|---|---|
| 한 장의 PNG 위에 **가짜 눈꺼풀·치즈**를 덧씌우기 | 덧씌운 위치가 실제 그림과 안 맞아 어긋나 보였다 |
| 눈 깜빡임 · 치즈 늘어남 | 위와 같은 이유. **눈·치즈 레이어를 따로 만든 뒤** 다시 구현한다 |

## 앱 반영 (`clov-web`)

- 사용자설정 > 테마 > "마스코트 캐릭터"에 **버거노인** 추가 (`value: 'burgerOldman'`)
- 대시보드 마스코트 스프라이트와 **전용 대사 4종** ("어서 와!", "오늘도 든든하게 보내자!" …)
- 계약 `mascotType` 허용값에 `burgerOldman` 추가

### ★ 앱에 넣는 스프라이트는 리사이즈했다

원본이 **1024×1536(1,170KB)**인데 화면에는 **110px 높이**로 그린다 — 14배 과대였다. 앱에는 **427×640(256KB)**으로 줄여 넣었다(기존 `crobi.png` 366×640/326KB와 같은 급). 대시보드는 진입할 때마다 이 이미지를 받는 자리다.

**이 레포의 `assets/burger-oldman/`에는 원본 해상도를 그대로 둔다** — 디자인 소스이고, 레이어를 다시 만들 때 기준이 된다.

### 레이어 파일은 앱에 넣지 않았다

`body.png`·`wave-arm.png`는 앱이 import하지 않는다(합쳐진 `idle`만 쓴다). 눈 깜빡임·팔 흔들기를 프로덕션에 구현하기 전까지는 **디자인 소스**라 이 레포에만 둔다.

## 다음 단계

1. 버거노인의 **눈·치즈·오른팔을 별도 레이어로** 제작
2. 눈 깜빡임 · 치즈 늘어남 · 재료별 흔들림을 HTML 애니메이션으로 추가
3. 확정되면 롭(`js/croby-mascot.js`의 `CHARACTERS` 레지스트리)처럼 프로토타입 위젯에 편입 검토

> **피넛(땅콩) 캐릭터**도 같은 세션에서 초안을 검토했다(두 알이 이어진 실루엣·껍질 결·얇은 팔). **캐릭터 형태를 더 다듬은 뒤** 같은 방식으로 웹 마스코트화하기로 하고 보류했다.

## 참고 — `robot` vs `rob`

프로토타입 위젯(`js/croby-mascot.js`)의 `CHARACTERS` 레지스트리는 롭을 **`robot`**으로 부르고, 프로덕션(`clov-web`)과 DB는 **`rob`**을 쓴다. 계약에는 `robot`이 적혀 있었는데 **실제 저장값은 `rob`**이라 계약 쪽을 정정한다(별건). 버거노인은 양쪽 모두 `burgerOldman`으로 통일했다.
