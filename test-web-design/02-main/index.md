# 우정공간 메인 앱 (index) — 화면 명세서

> **위치**: `02-main/index.html` — 앱의 메인 컨테이너. 4개 탭(우정공간·추억피드·일정계획·행운편지)을 한 페이지에서 전환. 렌더: `pages/*.js`, 로직: `js/space.js`·`schedule.js`·`feed.js`·`data.js`·`utils.js` 등.
> **최종 갱신**: 2026-07-10 · **실제 구현 기준**
> **핵심 원칙**: 우정공간은 **최대 8명** 단일 구조 · 모든 멤버 동등 · 약속 완료 → 추억 작성.

---

## 1. 화면 목적

로그인 후 진입하는 앱의 홈. 상단 **헤더 + 4탭**으로 우정공간(대시보드), 추억피드, 일정계획(인생4컷), 행운편지를 오간다. 이 문서는 **앱 셸 + 우정공간 대시보드 + 일정계획**을 다룬다(추억피드·행운편지는 별도 문서).

---

## 2. 진입 · 이탈 경로

**진입**: 로그인/방 선택(`03-rooms/makerooms.html`) 후 진입.
**이탈**: 헤더 로그아웃 → 로그인. 탭 전환은 페이지 내 이동. 알림/설정/상세는 모달.

---

## 3. 화면 레이아웃 (앱 셸)

```
┌───────────────────────────────────────────────┐
│ 🍀 Clov.        🔔  [☀️/🌙]  (김) 설정          │  ← 헤더
├───────────────────────────────────────────────┤
│ [우정공간] [추억피드] [일정계획] [행운편지]      │  ← 탭
├───────────────────────────────────────────────┤
│                                               │
│           (선택된 탭 콘텐츠)                     │
│                                               │
└───────────────────────────────────────────────┘
```
- 헤더: 로고, 🔔 알림(대기 배지), 다크모드 토글, 프로필/설정(사용자설정 모달), 로그아웃.
- 로그아웃은 토큰 정리 후 로그인 화면 이동(방 목록으로 튕기지 않음).

---

## 4. 컴포넌트별 상세

### 4-1. 우정공간 대시보드 (탭: 우정공간)
| 영역 | 내용 |
|---|---|
| **대표 커버** | 공간 제목(수정 가능) + **참여 멤버 아바타 스택** + 대표 사진(변경 가능) |
| **참여 멤버 카드** | 겹침 아바타 + "N명 함께하는 중" → 클릭 시 **참여 멤버 리스트 모달**(상태메시지, 초대 코드 복사, 가입 신청/퇴장 테스트) |
| **일정 배너** | 다가오는 약속(D-day) 요약 |
| **참여자별 추억 증거 카드** | 멤버별 기록을 카드로. 테마 3종: **겹침 카드(coverflow, 기본)** / 빨랫줄(wire) / 일기장(diary). 필름 스트립 현재 프레임 가로 중앙 정렬 |
| **마스코트** | 크로비(따뜻함) / 롭(디스토피아 AI). 클릭 시 교감 + **경험치** + 말풍선(캐릭터별 톤) |
| **우정 레벨 바** | 레벨/진행도. 레벨에 따라 색 진화(`--level-accent`), 지면 클로버 성장 |

### 4-2. 일정계획 — 인생4컷 (탭: 일정계획)
| 영역 | 내용 |
|---|---|
| **약속 여정 영수증** | 선택 약속을 영수증(CLOV. MEMORIES)으로 표시 — DATE/D-DAY + 도장(미래 빨강 / 지난 초록) + MEMO(편집) + 수정/삭제 |
| **새 D-day 만들기** | 모달에서 **영수증 위에 직접** 제목·날짜·본문 작성(라이트/다크 동일한 크림 종이). 저장 시 경험치(+3) |
| **성장 카드(필름)** | 약속별 4컷 진행: NOW SHOOTING / COMPLETE. 4컷 채우면 인생4컷 완성 |
| **필터** | 전체 / 인증 가능 / 다가오는 약속 / 완료된 약속 |
| **인생4컷 극장** | "입장하기" → 넷플릭스 로비형 극장(완성작 상영) |

### 4-3. 공통 모달 (index.html에 정적 배치)
- 참여 멤버 리스트, 알림, 사용자설정, 추억 기록(글쓰기), 추억 여권 상세, 사진 모아보기 갤러리, 약속 여정/인생4컷 여정, 새 D-day 등.

## 5. 사용자 액션 & 상태 전이

| 액션 | 결과 |
|---|---|
| 탭 클릭 | 해당 탭 콘텐츠로 전환 |
| 대표 사진 변경 | 카메라 업로드 → 대표 사진·"기본 사진"에 반영(customPhoto) |
| 참여 멤버 카드 클릭 | 멤버 리스트 모달(상태메시지 편집은 내 것만) |
| 마스코트 클릭 | 교감 XP(+2, 하루 3회) + 말풍선. 만렙(777) 시 하트/반짝이 |
| 약속 추가/완료/삭제 | XP 연동(+3 / +15 / 회수) |
| 게시글 작성 | XP(기본25+사진+정성). 100%↑ 시 연속 레벨업(초과분 이월) |
| 로그아웃 | 토큰 정리 → 로그인 |

- **상태**: 활성 그룹 · 활성 탭 · 우정 레벨/진행도 · 선택 약속 · 마스코트 캐릭터.

## 6. 데이터 / 저장 (localStorage)

| 키 | 내용 |
|---|---|
| `clov_groupsData` | 그룹별 posts·schedules·notifications·level·대표사진 등(깊은 복사로 원본 보존) |
| `clov_acceptedMembers` / `clov_joinRequests` | 참여 멤버 / 가입 신청 |
| `clov_darkMode` · `clov_appBackground` · `clov_appBgCustomColor` | 테마/배경 |
| `clov_my_status_msg` | 내 상태메시지 |

- 저장은 안전 래퍼(`saveGroupsData`)로 — 용량 초과 시 예외를 던지지 않고 안내(모달 흐름 유지).

---

## 7. 예외 / 경계 케이스

- **저장 공간 부족**: 사진 자동 압축 + 재압축 재시도, 실패 시 롤백·안내.
- **레벨 데이터 비동기화(777)**: UI 레벨과 저장 레벨을 동기화해 오발동 방지.
- **로그아웃 후 방목록 튕김**: 토큰 정리로 방지.
- **새로고침 시 증거 카드로 스크롤 튐**: 필름 가로 정렬만 하도록 수정(세로 미개입).
- **XP 100% 초과 표기**: while 루프로 연속 레벨업 처리(초과분만 이월).

---

## 8. 반응형 · 테마

- 데스크톱/모바일 동시 미리보기 프레임. 라이트 = 아이보리·포레스트, 다크 = 미드나잇 올리브.
- 약속 여정 영수증·행운편지 편지함 등은 **다크에서도 라이트 종이/배경 유지**(가독성).
