# 크로비(Croby) 마스코트 적용 내역

`# 크로비 사이드바 마스코트/handoff/` 폴더의 명세(`CROBY_MASCOT_SPEC.md`)와 바닐라 JS 데모(`croby-mascot-demo.html`)를 기준으로 `index.html`에 실제 적용했다.

## 추가/수정한 파일

| 파일 | 내용 |
|---|---|
| `js/croby-mascot.js` (신규) | 상태 머신(default/dizzy/sleepy) 구현. 테스트 패널(`v5-banner.js`)과 동일하게 DOM을 동적 생성해 `document.body`에 삽입 |
| `css/croby-mascot.css` (신규) | float/nudge/dizzy/sleepy 키프레임, 말풍선 스타일, `prefers-reduced-motion` 대응 |
| `assets/croby/` (신규) | 스프라이트 3장 복사 — `croby_default.png`, `croby_dizzy.png`, `croby_sleepy.png` |
| `index.html` | `<head>`에 `css/croby-mascot.css` 링크 추가, `js/v5-banner.js` 다음 줄에 `js/croby-mascot.js` 스크립트 태그 추가 |

## 명세와 달라진 부분

- **배치**: 원본 명세는 데스크톱에서 우측 **사이드바 안** `position: sticky`를 가정하지만, 이 페이지(`index.html`)에는 별도 사이드바 레이아웃이 없어 **우측 하단 `fixed`** 로 배치했다.
  - 데스크톱: `right: 18px; bottom: 18px; z-index: 9998` (배너 테마 테스트 패널의 `z-index: 9999`보다 아래)
  - 모바일(≤768px): `right: 12px; bottom: calc(64px + env(safe-area-inset-bottom) + 12px); z-index: 50` (명세와 동일)
- **스프라이트 크기**: 데스크톱 기본값은 명세대로 140px이었으나, 사용자 요청으로 **180px**로 확대. 모바일은 명세대로 80px 유지.

## 상태 머신 동작 (변경 없이 명세 그대로 구현)

- 단일 클릭 → 좌우 흔들(nudge) + 랜덤 대사 말풍선 1.8초 표시
- 0.9초 내 3연타 → dizzy 상태 진입, 1.2초 후 자동으로 default 복귀
- 20초간 무입력(마우스/스크롤/클릭/키입력 없음) → sleepy 상태, 아무 입력에나 즉시 기상
- default 상태에서 8~15초 랜덤 간격으로 혼잣말 말풍선 2.6초 표시

## 검증 방법

로컬 프리뷰 서버(`npx serve test-web-design`)에서 `http://localhost:3000/02-main/` 접속 후:
- `document.getElementById('croby')`의 `computedStyle`로 위치(`position/right/bottom`)와 스프라이트 크기(`height`) 확인
- `#croby-hit` 클릭 이벤트로 nudge/말풍선 전환, 3연타로 dizzy 전환 및 1.2초 후 자동 복귀 확인
- 스크린샷(우측 하단에 크로비 + 말풍선 노출) 확인

※ 프리뷰 도구의 `preview_screenshot`이 페이지 애니메이션 때문에 간헐적으로 타임아웃되어, 일부 검증은 `getComputedStyle` 기반 확인으로 대체했다.
