# 우정공간 목록 (My Spaces) — 화면 명세서

> **위치**: `03-rooms/makerooms.html` (독립 페이지). 헤더는 공용 `ClovHeader`.
> **최종 갱신**: 2026-07-10 · **실제 구현 기준**(보딩패스 카드·입장 스탬프 연출·공용 헤더 로그아웃).
> **핵심 원칙**: 우정공간은 인원 제한 없는 단일 구조 · 모든 멤버 동등.

---

## 1. 화면 목적

내가 속한 **우정공간 목록**에서 공간을 골라 입장하고, **초대 코드로 다른 공간에 입장**하거나 **새 공간을 만든다**. 로그인 후 처음 만나는 허브.

---

## 2. 진입 · 이탈 경로

**진입**: 로그인 성공 후. **이탈**: 방 카드 클릭 → **입장 연출(탑승 스탬프)** → `../02-main/index.html`. 헤더 로그아웃 → `../01-auth/login.html`.

---

---

## 4. 컴포넌트별 상세

| 요소 | 표시 / 상태 | 동작 |
|---|---|---|
| **보딩패스 카드**(room-card.ticket) | 공간별 탑승권. 선택 시 강조 | 클릭 → 입장 |
| **편집 모드** | 드래그 핸들·편집 컨트롤 노출 | 카드 **드래그 정렬**, 이름 수정/삭제 |
| **코드 입장** | `CLOV-` 코드 입력 | "입장" → 해당 공간 |
| **새 우정공간 만들기** | 만들기/완료 패널 | 새 공간 생성 |
| **테마 색 스와치** | 대표 사진/보딩패스 배경 프리셋 | 카드 배경색 지정 |

---

## 5. 사용자 액션 & 상태 전이

| 액션 | 결과 |
|---|---|
| 카드 클릭 | **탑승 스탬프 연출** 후 우정공간(02-main) 입장 |
| 코드 입장 | 유효 코드 → 해당 공간 입장 |
| 새 공간 만들기 | 생성 패널 → 목록에 추가 |
| 편집 | 드래그 정렬 / 이름 수정 / 삭제 |
| 로그아웃 | 토큰 정리 → 로그인 화면 |

---

## 6. 데이터 / 저장

- 내 우정공간 목록·정렬 순서, 초대 코드, (헤더) `accessToken`.

---

## 7. 예외 / 경계 케이스

- **유효하지 않은 코드**: 입장 차단·안내.
- **편집 모드**: 편집 중에는 카드 클릭이 입장이 아니라 편집 대상.
- **로그아웃**: 토큰 미정리 시 방목록으로 튕기던 문제 → 공용 `ClovHeader.logout()`으로 해결.

---

- 라이트/다크. 카드 그리드는 반응형(모바일 세로 나열).
