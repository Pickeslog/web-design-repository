# 친구 초대 (Invite) — 화면 명세서

> **위치**: `03-rooms/invite.html` (독립 페이지).
> **최종 갱신**: 2026-07-10 · **실제 구현 기준**.
> **핵심 원칙**: 초대한 사람에게 특별 권한 없음 — 모든 멤버 동등.

---

## 1. 화면 목적

친구를 우정공간에 초대한다. **내 공간의 초대 코드를 복사해 전달**하거나, **친구에게 받은 코드를 입력**해 입장 흐름으로 넘어간다.

---

## 2. 진입 · 이탈 경로

**진입**: 우정공간에서 초대. **이탈**: 코드 입력·확인 → `index.html?action=invite&code=…`(입장 처리).

---

## 3. 화면 레이아웃

```
┌───────────────────────────────┐
│      🤝 친구 초대하기            │
│           📨                   │
│  친구에게 받은 6자리 초대코드를    │
│  입력하거나, 아래 코드를 복사해     │
│  친구에게 전달하세요.             │
│  [ CLOV-XX ]        [ 복사 ]     │
│  [        확인/입장        ]      │
└───────────────────────────────┘
```

---

## 4. 컴포넌트별 상세

| 요소 | 표시 | 동작 |
|---|---|---|
| 초대 코드 입력 | `CLOV-XX`(6자리) | 받은 코드 입력 |
| 복사 버튼 | 내 공간 코드 | 클립보드 복사 → 친구에게 전달 |
| 확인/입장 | | 코드 유효 시 입장 파라미터로 이동 |

---

## 5. 사용자 액션 & 상태 전이

| 액션 | 결과 |
|---|---|
| 코드 복사 | 초대 코드 클립보드 복사 |
| 코드 입력 후 확인 | `index.html?action=invite&code=…`로 이동(입장 흐름) |

---

## 6. 데이터 / 저장

- 초대 코드(공간 식별). 입장 파라미터로 다음 화면에 전달.
