# 방 입장 (Join Room) — 화면 명세서

> **위치**: `03-rooms/join_room.html` (독립 페이지).
> **최종 갱신**: 2026-07-10 · **실제 구현 기준**.
> **핵심 원칙**: 방장 없이 **참여 멤버 누구나 1명만 수락하면 입장**(가입 신청 → 알림에서 수락).

---

## 1. 화면 목적

친구에게 받은 **방 코드**로 우정공간에 **가입 신청**을 넣는다. 신청은 공간의 알림(가입 신청 탭)에서 멤버가 수락하면 입장이 확정된다.

---

## 2. 진입 · 이탈 경로

**진입**: 초대 링크/코드(`?code=…` 사전 채움 지원). **이탈**: 신청 성공 → "메인(알림)으로 이동"(`../02-main/index.html?tab=join`).

---

## 3. 화면 레이아웃

```
┌───────────────────────────────┐
│  방 코드로 접속                  │
│  친구에게 전달받은 우정공간의       │
│  고유 방 코드를 입력하여 접속하세요. │
│  방 코드 입력 [ __________ ]      │
│  (유효하지 않은 코드 형식입니다)    │
│  [ →  방 접속하기 ]              │
│  ── (성공) ✓ 신청 완료 ──         │
│  [ 메인(알림)으로 이동 ]          │
└───────────────────────────────┘
```

---

## 4. 컴포넌트별 상세

| 요소 | 표시 / 상태 | 동작 |
|---|---|---|
| 방 코드 입력 | 형식 오류 시 경고 문구 | 코드 입력 |
| 방 접속하기 | | 유효 시 가입 신청 생성 |
| 성공 화면 | ✓ 성공 아이콘 | "메인(알림)으로 이동" |

---

## 5. 사용자 액션 & 상태 전이

| 액션 | 결과 |
|---|---|
| 방 접속하기 | 코드 검증 → **가입 신청 생성**(`clov_joinRequests`에 추가) → 성공 화면 |
| 메인(알림)으로 이동 | `02-main`의 알림(가입 신청 탭)으로 — 멤버 수락 대기 |

---

## 6. 데이터 / 저장

- `clov_joinRequests` — 신청(신청자·코드·상태 `pending`)을 추가. 수락은 [알림](../07-notification/notification.md)에서 처리.

---

## 7. 예외 / 경계 케이스

- **유효하지 않은 코드 형식**: 경고 문구, 접속 차단.
- **정원 초과(최대 8명)**: 이미 8명(ACTIVE)인 방은 가입 신청 생성 차단·안내(`ROOM_CAPACITY_EXCEEDED`).
- 신청 후 **수락 전까지 대기**(방장이 없으니 참여 멤버 1명 수락으로 입장 확정).

---
