## 주요 작업 내용 (6/30)

### 내 프로필 모달 신규 도입

- 우측 상단 드롭다운 → `내 프로필` 클릭 시 `openProfileSettingsModal()` 호출
- Discord 설정창 구조: 좌측 사이드바 + 우측 설정 패널
- `localStorage` 기반 저장 (`clov_profile`, `clov_profile_nickname` 등)
- 저장 즉시 헤더 프로필 버튼에 반영

### 전체화면 레이아웃 전환

- 기존 `70vw` 제한 → `100vw / 100vh` 전체화면
- `body`, `workspace`, `desktop-window` 모두 전체화면 기준 확장
- 카드 비율 보정 (과도한 가로 늘어남 방지)

### 추억 피드 더보기 → 바텀시트

- `window.location.href = 'memory_detail.html?...'` 방식 폐기
- 현재 페이지 내 하단 시트(`.memory-detail-sheet`) 방식으로 전환
- 시트 내 제목·작성자·날짜·본문·태그·수정/삭제 기능 포함

### 스크롤바 스타일

- 기본 회색 스크롤바 → 얇은 초록 계열로 교체
- 다크모드 대응
