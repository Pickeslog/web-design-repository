## 2. 추억 증거 카드 → 폴라로이드 디자인 전환

**배경**: 기존 메모리 카드가 일반 둥근 카드 형태로 개성 없어 보인다는 의견 → 폴라로이드 사진 스타일로 교체.

### 2-1. HTML 구조 변경 (`renderMemoryCard` in `desktop.js`)

| 기존 | 변경 |
|---|---|
| `.memory-image` | `.polaroid-photo` (사진 영역) |
| `.presence-board` (56px 직사각형 타일 그리드) | `.polaroid-presence-row` (아바타 도트 + 이름 알약 칩) |
| `.memory-body` | `.polaroid-caption` (폴라로이드 하단 흰 여백) |

### 2-2. 폴라로이드 CSS 핵심

```css
.polaroid-card {
    background: var(--card-bg);         /* 흰 종이 */
    padding: 10px 10px 52px;            /* 하단 두꺼운 흰 여백 */
    border-radius: 3px;                  /* 사진 느낌 */
    transform: rotate(-1.5deg);         /* 살짝 기울어짐 */
    transform-origin: center bottom;
    box-shadow: 0 2px 4px … , 0 10px 30px … , 0 24px 60px …;
}
.polaroid-card:hover {
    transform: rotate(0deg) scale(1.015); /* 집어드는 느낌 */
}
```

- 사진 영역(`.polaroid-photo`): 고정 높이 `172px`, 배경 `cover`
- 빈 사진 상태: 클로버 아이콘 + 대각선 패턴 배경 유지
- 다크모드: 카드가 `#f7f9f7` 크림빛 유지 → 어두운 배경에 사진처럼 떠 있는 효과

### 2-3. 이벤트 버블링 방지

참여자 칩·더보기 버튼에 `event.stopPropagation()` 추가 → 카드 클릭 이벤트와 분리.

## 3. 증거 카드 뷰어 레이아웃 변천

### 3-1. 1단계: 3장 나란히 (flex row)

- `.polaroid-row` + `.polaroid-slot` 구조
- 각 슬롯 `flex: 0 1 calc((100%−28px)/3)` → 항상 1/3 너비 고정
- 비활성 카드: opacity 0.62, 더 기울어짐
- 하단 `과거 / 현재` 알약 버튼 + 타임라인 도트

**문제점**: 하나뿐일 때 늘어나고 카드가 옆으로 단순히 나열되어 밋밋하다는 피드백.

### 3-2. 2단계: 삼성페이식 팬(fan) 레이아웃 ✅ 현재 적용

**참고 이미지**: 삼성페이 카드 나열 UI (중앙 카드 앞, 좌우 카드가 뒤에서 비스듬히 팬처럼 펼쳐지는 구조)

**슬롯 구성**

| 슬롯 | 내용 | z-index | CSS |
|---|---|---|---|
| `fan-left` | 더 오래된 게시글 | 5 | `rotate(-24deg) translateY(14px)`, `margin-right: -82px` |
| `fan-center` | 현재 활성 게시글 | 10 | `rotate(-1deg)`, 강한 그림자 |
| `fan-right` | 더 최근 게시글 | 5 | `rotate(24deg) translateY(14px)`, `margin-left: -82px` |

**핵심 기법**
- `transform-origin: bottom center` → 카드 하단을 축으로 부채꼴 회전 (삼성페이와 동일한 피벗)
- 음수 마진(`-82px`)으로 카드가 겹쳐 뒤에서 비어져 나오는 효과
- 비활성 카드: `opacity: 0.68`, `filter: saturate(0.55) brightness(0.96)`
- 비활성 카드 클릭 → `setEvidenceIndex()` 로 해당 게시글 활성화
- 호버 시 회전 감소 + 살짝 앞으로 나오는 효과로 클릭 유도

**아직 미적용**: 5장 레이아웃 논의 중 (다음 작업 예정)
