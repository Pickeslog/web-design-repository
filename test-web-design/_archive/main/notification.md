# notification.html — 알림

## 개요

서비스 공지와 친구 활동 알림을 탭으로 구분해 보여주는 독립 페이지다.  
`index.html` 헤더의 🔔 아이콘을 누르면 진입한다.

---

## 화면 구성 (2탭)

| 탭 | 내용 | 스타일 |
|---|---|---|
| 📢 관리진 공지 | 서비스 업데이트, 기능 공지 | 초록 왼쪽 보더 카드 형식 |
| 🔔 친구들 알림 | 친구의 게시글 작성, D-day 임박 등 활동 알림 | 일반 카드 형식 |

---

## 탭 스타일

- 활성 탭: `--primary-green` 배경 + 흰 글자
- 비활성 탭: 테두리만 있는 아웃라인 스타일
- 빈 상태: 가운데 정렬 아이콘 + 안내 문구 (`.empty-state`)

---

## 알림 배지 연동

`index.html`의 헤더 🔔 아이콘에 빨간색 배지가 표시되는 로직:

- 편지 작성 또는 추억 글 작성 시 `desktop.js`의 순수 DOM 조작 방식으로 배지 추가
- 알림창(`notification.html`)을 열면 배지 즉시 제거 (읽음 처리)
- 스크립트 충돌 방지를 위해 jQuery 없이 순수 DOM API 사용

---

## 다크모드

URL 파라미터 `?theme=dark|light` 우선 적용, 없으면 `localStorage` 폴백

---

## 스타일 특징

- 외부 CSS 없이 `<style>` 블록 인라인 선언
- 단일 카드 레이아웃 (`max-width: 600px`)
- `fadeUp` 진입 애니메이션
