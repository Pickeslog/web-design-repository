# signup.html — 회원가입 (signup 폴더 버전)

## 개요

Clov 회원가입 화면이다. Glassmorphism 카드 UI와 Outfit 폰트를 사용하며, 4단계 step 구조로 구성되어 있다.  
`profile/signup.html`과 동일한 소스 기반으로, signup 폴더에 배치된 작업본이다.

---

## 화면 구조

- 배경: `linear-gradient` + 3개 `orb` (blur 80px, 드리프트 애니메이션, 12초 주기)
- 중앙 카드: glassmorphism (`backdrop-filter: blur(24px) saturate(160%)`, `border-radius: 28px`, `max-width: 560px`)
- 진입 애니메이션: `slideUp` (`translateY 36px → 0, scale 0.97 → 1, 700ms`)

---

## 4단계 회원가입 플로우

| 단계 | 내용 |
|---|---|
| Step 1 | 기본 정보 (이메일 · 전화번호 · 비밀번호) |
| Step 2 | 약관 동의 (전체 / 필수 2개 / 선택 1개) |
| Step 3 | 프로필 설정 (이미지 · 닉네임 · 생년월일) |
| Step 4 | 가입 완료 (이메일 앞부분으로 인사 + 입장 버튼) |

---

## 입력 검증

| 항목 | 검증 |
|---|---|
| 이메일 | 이메일 형식 |
| 전화번호 | `010-XXXX-XXXX` 자동 포맷 변환 |
| 비밀번호 | 8자 이상 |
| 닉네임 | 한글·영문·숫자 1~12자 |

- 빈 값 이동 → 경고 없음
- 잘못된 값 작성 후 이동 → 경고 표시 (붉은 캡슐 형태)
- 다음 단계 클릭 시 필수값 비어 있으면 경고 표시

---

## 비밀번호 기능

- 눈 아이콘 토글: 보기/숨기기
- 보임 상태: `조심하세요! 비밀번호가 보여요!` 표시
- 강도 표시 bar: 4개 segment (8자 / 12자 / 대문자·숫자 / 특수문자)

---

## 약관 동의 (Step 2)

- 전체 동의 체크박스
- 필수: 서비스 이용약관 / 개인정보 처리방침
- 선택: 마케팅 정보 수신
- 필수 항목 미체크 시 약관 박스 흔들림 애니메이션

---

## 프로필 설정 (Step 3)

- 원형 이미지 미리보기 (클릭 → 파일 선택 → 즉시 반영)
- 닉네임 입력 → 🎂 버튼 클릭 → 카드 180도 회전으로 생년월일 카드 전환
- 생년월일: 클릭 시 년/월/일 선택 모달 → `YYYY-MM-DD` 형식 반영

---

## 이스터에그

- 클로버 로고 클릭 → 랜덤 메시지 캡슐 팝업 (4종)
- 10% 확률 희귀 이벤트: 카드 반으로 갈라지는 애니메이션 (`cracking` 클래스)

---

## OAuth2 UI

- 카카오 · 네이버 · 구글 소셜 버튼 (원형 아이콘)
- hover 시 라벨 표시, `title` 속성 미사용

---

## 폰트 및 CSS 변수

- 폰트: `Outfit` (Google Fonts, 300–900)
- CSS 변수: `--p1(#0d4a28)` ~ `--p5(#a8f0c6)`, `--bg`, `--text`, `--muted`, `--border`, `--glow`
