# 알림 (Notifications) — 화면 명세서

> **위치**: `02-main` 헤더 🔔 → **알림 모달**(`#noti-backdrop`, 로직 `index.html` 내 스크립트). 단독 파일 `07-notification/notification.html`.
> **최종 갱신**: 2026-07-10 · **실제 구현 기준**
> **핵심 원칙**: 모든 멤버 동등 — **방장 없이 참여 멤버 누구나 1명만 수락하면 입장**.

---

## 1. 화면 목적

우정공간의 **가입 신청 처리**(수락/거절/되돌리기), **친구들 활동 알림**(멤버 입·퇴장 등), **관리진 공지**를 한곳에서 확인하는 모달.

---

## 2. 진입 · 이탈 경로

**진입**: 헤더의 🔔 버튼(대기 중 가입 신청 수가 있으면 **빨강 배지**). **이탈**: 닫기(×), 바깥 클릭, ESC.

---

## 3. 화면 레이아웃

```
┌───────────────────────────────┐
│ 🔔 알림                    [×] │
├───────────────────────────────┤
│ [관리진 공지][친구들 알림][가입 신청 ③]│  ← 탭
├───────────────────────────────┤
│  ✓ 강한나님 수락함     되돌리기 4:47 │
│  실수로 수락했다면 5분 안에 …        │
│           [ 되돌리기 ]              │
│  …                                 │
└───────────────────────────────┘
```

---

## 4. 컴포넌트별 상세

| 탭 | 내용 |
|---|---|
| **관리진 공지** | 서비스/공간 공지 카드 |
| **친구들 알림** | 멤버 입·퇴장 등 활동 알림(예: "○○님이 나갔습니다") |
| **가입 신청** | 대기 중인 가입 신청 목록. 탭 라벨에 **대기 수 배지**. 각 신청: 신청자·초대 경로(초대받음/코드 직접)·상태 |

- 헤더 🔔 배지: 대기 신청 수(0이면 숨김).

---

## 5. 사용자 액션 & 상태 전이

| 액션 | 결과 |
|---|---|
| 가입 신청 **수락** | 멤버 추가 → 참여 멤버 수·프로필 아바타 반영. **5분 되돌리기 카운트다운** 시작(방장 없으니 강퇴 대신 되돌리기로만 취소) |
| **되돌리기**(5분 내) | 수락 취소 → 다시 대기 상태, 멤버에서 제거 |
| **거절** | 세션 메모리에만 '거절' 표시(새로고침 시 다시 대기로 복원) |
| 경합(다른 멤버가 먼저 처리) | 늦은 클릭은 "이미 처리된 신청" 안내로 무효 처리 |

- **상태**: 신청별 `pending / accepted(+acceptedAt) / rejected(세션)`. 수락 시 `clov_acceptedMembers`에 반영.

---

## 6. 데이터 / 저장

| 키 | 내용 |
|---|---|
| `clov_joinRequests` | 가입 신청 목록(신청자·코드·상태·초대 경로) |
| `clov_acceptedMembers` | 수락된 참여 멤버 |
| 그룹 `notifications` | 친구들 알림(퇴장 등) |

---

## 7. 예외 / 경계 케이스

- **경합 수락/거절**: 이미 처리된 신청은 무효(중복 방지).
- **되돌리기 만료**: 5분 지나면 되돌리기 불가.
- **거절 비영속**: 새로고침 시 대기로 복원(파괴적 삭제 아님).
- 빈 탭: 각 탭에 항목 없을 때 빈 상태 안내.
