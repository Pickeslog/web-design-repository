# 추억피드 (Memory Feed) — 화면 명세서

> **위치**: `02-main/index.html`의 추억피드 탭(`#dt-tab-feed`) · 렌더 `pages/feed-page.js` · 로직 `js/space.js`·`js/feed.js`. 단독 페이지 `04-feed/feed.html`로도 진입 가능.
> **최종 갱신**: 2026-07-10 · **실제 구현 기준**(원본 HTML 계획이 아니라 현재 동작하는 화면)
> **핵심 서비스 원칙**: 모든 멤버 동등 · 같은 약속에 대해 친구별 관점 기록 · 기록 보존(익명화만).

---

## 1. 화면 목적

우정공간에서 친구와 남긴 추억 게시글을 **월별 타임라인**으로 모아보고, 검색·정렬·사진 모아보기로 탐색하며, 새 추억을 기록하는 화면. "약속이 추억으로 자란다"는 서비스 흐름의 종착점으로, 완료된 약속(일정계획)이 이 피드의 게시글로 이어진다.

---

## 2. 진입 · 이탈 경로

**진입**
- 우정공간 대시보드 상단 탭 **📸 추억피드** 클릭 → 탭 전환(같은 페이지 내)
- 방 목록(`03-rooms/makerooms.html`)에서 방 진입 후 접근
- (단독 뷰) `04-feed/feed.html` 직접 진입 — makerooms에서도 연결

**이탈**
- 다른 탭(우정공간 · 일정계획 · 행운편지) 전환
- 헤더 로고/뒤로가기 → 방 목록
- 글쓰기·상세 등 모달을 열면 피드는 뒤에 유지(모달 닫으면 복귀)

## 4. 컴포넌트별 상세

### 4-1. 헤더 (feed-hero)
| 요소 | 표시 / 상태 | 동작 |
|---|---|---|
| 제목 "월별 추억 아카이브" + 부제 | 다크모드에서도 밝은 양피지 배경 + 어두운 글자(프로스티드 판)로 가독성 확보 | — |
| 월/전체 요약(feed-month-summary) | 선택된 월(또는 "전체 추억") | 월 선택/필터에 따라 갱신 |
| **글쓰기** 버튼 | 초록 CTA | 추억 기록 모달 열기 |

### 4-2. 컨트롤 (feed-controls)
| 요소 | 표시 / 상태 | 동작 |
|---|---|---|
| 검색 입력 | placeholder "추억 검색(제목·내용·태그·친구)", 입력 시 우측 지우기(✕) 노출 | 입력 중 **본문만 갱신**해 포커스 유지. ESC/✕로 초기화. 해시태그는 **화면 표시 태그** 기준 매칭, `#` 유무 무관 |
| 정렬 토글 | 최신순(기본) / 오래된순, 활성 pill | 목록 재정렬, 월별 섹션 순서도 반전 |
| 사진 모아보기(▦) | 격자 아이콘 | 방 전체 사진 전체화면 갤러리 |
| 월 선택(📅) | 달력 아이콘 | 연/월 그리드 팝오버 열기 |
| 필터 탭 | 전체 / 내 기록 / 친구 기록, 활성 pill | 표시 게시글 필터 |

### 4-3. 폴라로이드 카드
| 요소 | 표시 | 예외 |
|---|---|---|
| 대표 사진 | `post` 대표 이미지 | 없으면 **"사진 없음" SVG 플레이스홀더**(증거 카드와 통일) |
| 참여 멤버 아바타 | 함께한 멤버 이니셜 원형(겹침) | — |
| 제목 / 날짜 | `post.title` / 작성일 | — |
| 해시태그 | `getMemoryHashtags()` 표시값 | 커스텀 태그 + 자동 태그 혼합 |
| 본문 미리보기 + "···더보기" | REMARKS 일부 | — |
| 💬 카운트 | 친구 한 줄 메시지 수 | 0이면 0 표시 |

### 4-4. 월별 섹션
- "YYYY년 M월" **sticky 헤더** + 섹션별 장수. 정렬 방향에 따라 섹션·카드 순서 반전.

## 5. 사용자 액션 & 상태 전이

| 액션 | 결과 |
|---|---|
| 카드 · "···더보기" 클릭 | **추억 여권(MEMORY PASSPORT) 상세** 열림 — 표지 밴드 + 대표/썸네일 + 약속 영수증(도장 4상태) + STATUS/PHOTOS/REMARKS |
| 여권의 **약속 영수증** 클릭 | 연결된 일정의 **인생4컷 여정** 모달(제안→일정→확정→만남). 단계별 완료/진행/잠김 |
| 사진(대표·썸네일·+N) 클릭 | 전체화면 슬라이드 갤러리(화살표·썸네일 점프·드래그 스와이프·ESC, 상세와 위치 동기화) |
| **글쓰기** | 추억 기록 모달: 사진(≤15장)·제목(≤25자)·본문(≤100자)·해시태그·함께한 친구·**약속 연결(선택)**. 저장 시 피드 상단 추가 + **경험치 지급**(기본+사진+정성 보너스) |
| 검색어 입력 / 정렬 / 필터 / 월 선택 | 표시 목록 즉시 갱신 (본문만 리렌더) |
| 사진 모아보기(▦) | 방 전체 사진 갤러리(자체 검색·정렬·월별 섹션·라이트박스, "이 추억 보기"로 해당 여권 이동) |

**상태 변수**: 활성 그룹 · 검색어 · 정렬(new/old) · 필터(all/mine/others) · 선택 월 — `renderFeeds()`가 조합해 표시 목록 결정.

## 6. 데이터 / 저장

- **저장소**: `localStorage['clov_groupsData']` → `groupsData[활성그룹].posts[]`
- **post 주요 필드**

| 필드 | 의미 |
|---|---|
| `date` / `title` | 작성일 / 제목(≤25자) |
| `text` (REMARKS) | 본문(≤100자, 실시간 카운터) |
| `photos[]` | 압축 base64 사진(≤15장) · `bg`는 photos[0]과 동기화 |
| `tags[]` | 커스텀 해시태그(최대 5) |
| `participants[]` | 함께한 멤버(동등, 방장 개념 없음) |
| `messages[]` | 친구들의 한 줄 메시지 |
| `scheduleId` | **약속 연결**(일정 참조, 복제 아님). null이면 자유 기록(FREE MEMORY) |

- **사진 처리**: 업로드 시 자동 압축(≈1000px·JPEG 0.72). 저장 실패(용량 초과) 시 기존 사진 **자동 재압축 후 재시도**.

---

## 7. 예외 / 경계 케이스

- **사진 없는 추억**: "사진 없음" SVG 플레이스홀더.
- **저장 공간 부족**: 재압축 재시도 → 그래도 실패 시 방금 글 **롤백** + "공간 부족" 안내, **모달은 닫힘**(유령 글 방지, 저장 안 된 글이 새로고침 시 사라지는 문제 예방).
- **검색 결과 없음 / 해당 월 게시글 없음**: 빈 상태 안내.
- **탈퇴 멤버**: 작성자 표기를 "언노운"으로 익명화, **기록 본문은 보존**.
- **약속 미연결(FREE MEMORY)**: 여권의 영수증 클릭 불가.

---

## 8. 반응형 · 테마

- **라이트/다크**: 헤더는 다크에서도 밝은 양피지 배경 유지(어두운 글자). 카드·플레이스홀더는 양쪽 대비 확보.
- **데스크톱/모바일**: 그리드 열 수 축소, 검색/컨트롤 줄바꿈. 사진 갤러리는 정적 오버레이(body 직속)로 모바일 미러링 이슈 회피.
