# 추억 여권 상세 (MEMORY PASSPORT) — 화면 명세서

> **위치**: `02-main` 추억피드에서 카드/"···더보기"/참여자 클릭 시 열리는 **상세 모달**(렌더 `js/space.js`). 단독 파일 `04-feed/memory_detail.html`.
> **최종 갱신**: 2026-07-10 · **실제 구현 기준**
> **핵심 원칙**: 같은 약속에 대해 친구별 관점 기록 · 기록 보존(익명화만).

---

## 1. 화면 목적

추억 게시글 하나를 **여권(passport) 형식**으로 상세히 보여주고, 연결된 **약속(영수증)·사진·친구 한 줄 메시지**를 확인하며, 수정 모드에서 약속 연결을 편집한다.

---

## 2. 진입 · 이탈 경로

**진입**: 추억피드에서 카드/"···더보기"/참여자 타일 클릭. 사진 모아보기 갤러리의 "이 추억 보기"로도 진입.
**이탈**: ESC(상세만 닫힘, 다른 모달로 전파 안 됨), 닫기 버튼, 바깥 클릭.

---

## 3. 화면 레이아웃

```
┌──────────────────────────────────────────────┐
│  ═══ MEMORY PASSPORT ═══   (표지 밴드)         │
│  [대표 사진]  [썸네일][썸네일][+N]             │
│  ┌ 약속 영수증 ───────────────────────────┐   │
│  │  DATE  2026.07.12(일)     [ D-2 도장 ]   │   │
│  │  D-DAY  D-2                              │   │
│  └─────────────────────────────────────────┘   │
│  STATUS  …                                     │
│  PHOTOS  …                                     │
│  REMARKS  (본문 ≤100자)                        │
│  ── 친구 한 줄 메시지 ──                        │
└──────────────────────────────────────────────┘
   모달 높이 94vh · 스크롤바 숨김(스크롤은 유지)
```

---

## 4. 컴포넌트별 상세

| 영역 | 내용 |
|---|---|
| **표지 밴드** | "MEMORY PASSPORT" |
| **사진** | 대표 사진 + 썸네일 + `+N` |
| **약속 영수증** | 연결된 일정의 DATE / D-DAY + **도장**. 도장 4상태: ① D-Day만 · ② D-Day+4컷 대기 · ③ D-Day+**추억 완성 도장** · ④ FREE MEMORY. (D-Day 도장은 상태 무관 **빨강 고정·영구 유지**) |
| **STATUS / PHOTOS / REMARKS** | 상태·사진·본문(REMARKS ≤100자, 실시간 카운터) |
| **친구 한 줄 메시지** | 함께한 친구들의 짧은 메시지(멤버 동등) |

---

## 5. 사용자 액션 & 상태 전이

| 액션 | 결과 |
|---|---|
| 사진(대표·썸네일·+N) 클릭 | 전체화면 **슬라이드 갤러리**(화살표·썸네일 점프·드래그 스와이프·ESC, 상세와 위치 동기화) |
| **약속 영수증 클릭** | **인생4컷 여정** 모달 — 단계별 완료(사진 확대)/진행 가능(**바로 4컷 업로드**)/잠김(안내). 업로드 시 **여정·여권 영수증·일정계획 탭 동시 갱신**(잠금 해제 연쇄) |
| 수정(편집) 모드 | **약속 연결 편집**: 가져오기 → 미니 영수증 목록 → 연결됨 칩(변경/해제) → `＋새 약속` 폴백 |
| FREE MEMORY(약속 미연결) | 영수증 클릭 불가 |

---

## 6. 데이터 / 저장

- post의 **`scheduleId`(약속 참조, 복제 아님)** 로 D-Day·4컷·완성 도장이 **한 소스에서 동기화**된다.
- 사진은 압축 base64. 4컷 업로드 저장 실패 시 자동 재압축·재시도.

---

## 7. 예외 / 경계 케이스

- **FREE MEMORY**: 영수증 클릭 불가(연결된 약속 없음).
- **ESC 전파 방지**: 여정/갤러리 ESC가 상세까지 닫던 문제 해결(전파 차단).
- **z-index**: 4컷 업로드 확인/결과 모달이 여정 모달 위로 오도록 정리(클릭 가능).
- **모바일 갤러리**: 정적 오버레이(body 직속)로 모바일 미러링 이슈 회피.
