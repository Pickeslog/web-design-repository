# 행운편지 (Lucky Letter) — 화면 명세서

> **위치**: `02-main`의 행운편지 탭(`#dt-tab-letter`, 렌더 `pages/letter-page.js` · 로직 `js/letter.js`). 받은 편지 상세는 `05-letter/letter_detail.html`.
> **최종 갱신**: 2026-07-10 · **실제 구현 기준**
> **핵심 원칙**: 모든 멤버 동등 · 익명/응원 메시지 문화.

---

## 1. 화면 목적

친구에게 **응원·감사·행운의 편지**를 보내고, 나에게 도착한 편지를 편지함에서 확인하는 화면. 팝업 모달이 아니라 **탭 내 인라인 전환**으로 작성한다.

---

## 2. 진입 · 이탈 경로

**진입**: 우정공간 상단 탭 **💌 행운편지** 클릭 → 탭 전환.
**이탈**: 다른 탭 전환. 인라인 작성/받은편지함 모달은 열고 닫아도 편지함 화면 유지.

---

## 3. 화면 레이아웃 (편지함 무대)

```
┌──────────────────────────────────────────────┐
│               LUCKY LETTER                     │
│               행운 편지함                       │  ← letter-stage
│      상자를 열어 편지를 천천히 확인해보세요.       │
│                                                │
│            [ 📮 우편함 / 🎁 선물상자 ]           │  ← 편지함 trigger (테마별 비주얼)
│                                                │
│        총 N통의 편지가 ○○님에게 도착했어요!       │  ← 요약(dt-letter-zone)
│                                                │
│                 [ 편지 작성 ]                    │
└──────────────────────────────────────────────┘
```

---

## 4. 컴포넌트별 상세

### 4-1. 편지함 무대 (letter-stage)
| 요소 | 표시 | 비고 |
|---|---|---|
| 키커 / 제목 / 부제 | LUCKY LETTER · 행운 편지함 · 안내문 | **다크모드에서 어두운 배경 + 밝은 글자**(가독성 확보) |
| 편지함 비주얼(trigger) | **우체통** 또는 **선물상자** SVG | 우정편지 테마 설정으로 전환. 클릭 → 받은 편지함 모달 |
| 요약 | "총 N통의 편지가 ○○님에게 도착했어요!" | 도착 편지 수 동적 반영 |
| 편지 작성 버튼 | 초록 CTA | 인라인 작성 카드 토글 |

### 4-2. 인라인 편지 작성 카드
| 요소 | 내용 |
|---|---|
| 받는 사람 | 멤버 칩 선택 + "모두에게" 토글 |
| 편지 내용 | textarea, 한글 500 / 영어 1000자 카운터 |
| 액션 | 취소 / **편지 발송!** |

### 4-3. 받은 편지함 · 편지 상세
- 편지함 trigger → 받은 편지 목록. 개별 편지 열람(상세). 즐겨찾기 지원.

---

## 5. 사용자 액션 & 상태 전이

| 액션 | 결과 |
|---|---|
| 편지함(우체통/선물상자) 클릭 | 받은 편지함 열림 |
| 편지 작성 | 인라인 카드 펼침 → 받는 사람·내용 입력 → 발송 |
| "모두에게" 토글 | 전체 멤버 수신자 선택 |
| 편지 발송! | 편지 저장·전송, 카드 닫힘 |
| 편지함 테마 변경(사용자설정) | 우체통 ↔ 선물상자 비주얼 전환 |

---

## 6. 데이터 / 저장

- 편지 데이터(받는 사람·내용·작성자·즐겨찾기)를 localStorage에 저장.
- 우정편지 테마(우체통/선물상자) 설정값 저장.

---

## 7. 예외 / 경계 케이스

- **다크모드 가독성**: 편지함 무대가 밝은 배경으로 남아 흰 글자가 묻히던 문제 → 다크 배경 + 밝은 글자로 정정.
- **받는 사람 미선택 / 내용 없음**: 발송 차단(안내).
- **도착 편지 0통**: 빈 편지함 안내.

---

## 8. 반응형 · 테마

- 라이트/다크 모두 대응(편지함 무대 어두운 배경 분기). 데스크톱/모바일 레이아웃.
