## 1. 추억피드 · 약속 연결 + MEMORY PASSPORT 상세
핸드오프(`추억 피드 확장판/handoff`) 스펙 구현.

- `MemoryPost.scheduleId`(nullable) 신규 — 일정계획의 약속을 **참조**(복제 아님)해 D-Day·4컷·완성 도장이 한 소스에서 동기화.

- 글쓰기 모달에 **약속 연결(선택)** 섹션: 가져오기 → 미니 영수증 목록 → 연결됨 칩(변경/해제) → `＋새 약속` 폴백.

## 3. 사진 전체보기 슬라이드 갤러리
- 대표사진/썸네일/`+N` 클릭 → 전체화면 갤러리(화살표·썸네일 점프·드래그 스와이프·ESC·상세와 위치 동기화).
- **버그**: `createElement`로 body에 append하니 앱의 모바일 미러링 로직이 노드를 다른 컨테이너로 옮기고 class를 제거 → `position:fixed` 오버레이가 깨짐.
- **수정**: 다른 모달처럼 오버레이를 `index.html`에 **정적 배치**, 이벤트 1회 바인딩.

## 4. 사진 자동 압축 + 기존 저장분 재압축(자기 치유)
- **문제**: "저장 공간이 부족해요" — 사진을 원본 base64로 localStorage(≈5MB)에 저장 + 상한 6→30장.
- **1차(유입 차단)**: 업로드 시 `compressMemoryPhoto`로 1080px·JPEG 0.7 압축(6.4MB→26KB, ~99.6%↓).
- **2차(재고 회수)**: 이미 꽉 찬 저장소는 그대로 남는 문제 → `compactStoredPhotos`로 저장된 원본 사진 재압축(로드 시 1회 자동 + 4컷 저장 실패 시 재압축·재시도). 포화 14MB→256KB(~98%↓), 데이터 무손실.

## 15. 대표사진 — 사용자 업로드 사진을 "기본 사진"으로
문제: "대표 사진 > 기본 사진" 옵션이 원본 프리셋 GIF(`defaultGroupsData.photo`)를 가리켜, 사용자가 카메라로 올린 사진이 "기본 사진"에 반영되지 않고 선택 시 원본으로 되돌아갔다.

- **`customPhoto` 필드 신설**: 사진 업로드(카메라) 저장 시 `groupsData[activeGroup].customPhoto`에 보관하고 대표사진으로 건다.
- **"기본 사진" 옵션이 내 사진을 가리킴**: 업로드가 있으면 "기본 사진" 선택 시 그 사진을 적용하고, 목록에 **썸네일 + "내 사진" 라벨 + 활성** 표시. 프리셋을 골랐다가 다시 눌러도 업로드 사진이 복원된다.
- **잠재 버그 수정**: `data.js`의 `groupsData = defaultGroupsData`(얕은 참조 공유) → **깊은 복사**. 대표사진을 바꿀 때 원본 `defaultGroupsData`까지 오염돼 '기본 사진' 복원 기준이 무너지던 문제 해결.
- 검수: 업로드→대표사진·대시보드 갱신·customPhoto 저장, "내 사진" 라벨/썸네일/활성, 프리셋→복원, 참조 분리·원본 보존·업로드 없는 그룹은 진짜 원본, 콘솔 0.

## 16. 추억피드 사진 모아보기 갤러리 (애플 갤러리 스타일)
추억피드 툴바에 **격자 아이콘**을 추가하고, 클릭하면 현재 방(활성 그룹)의 모든 멤버 사진을 한 곳에 모아보는 전체화면 갤러리를 넣었다.

- **격자 갤러리**: 방 전체 게시글 사진을 정사각 격자(반응형 `auto-fill`, 모바일 축소)로 수집·표시. 정적 오버레이(`#space-photo-gallery-overlay`, body 직속)로 모바일 미러링 이슈 회피.
- **라이트박스**: 격자 사진 클릭 → 전체화면(이전/다음·카운터·닫기·"이 추억 보기"→해당 여권 상세). Esc 2단계(라이트박스→갤러리), 바깥 클릭 동일.
- **검색·정렬·월별 섹션 (2차 추가)**:
  - 검색: 제목·본문·태그·친구 이름으로 필터(입력 중 본문만 갱신해 포커스 유지, 지우기 버튼).
  - 정렬: 최신순 / 오래된순 토글.
  - 월별 섹션: 애플 갤러리처럼 "YYYY년 M월" sticky 헤더로 묶고 섹션별 장수 표시. 정렬 방향 따라 섹션 순서도 뒤집힘. 라이트박스는 필터·정렬된 목록 기준 이동.
- 검수: 사진 수집·격자·라이트박스·"이 추억 보기"·Esc 2단계, 월별 6섹션(최신 6월→1월/오래된 1월→6월), 검색 "성수"→1장·입력 유지·지우면 복원, 콘솔 0.

## 17. 로그아웃이 방 목록으로 튕기던 문제 수정
- **문제**: 로그아웃하면 로그인 화면이 아니라 방 목록(makerooms)으로 이동.
- **원인**: 로그아웃이 `login.html`로 이동만 하고 `accessToken`을 지우지 않음 + login.html에 "토큰 있으면 로그인 유지 → makerooms로" 자동 리다이렉트(§7에서 추가)가 있어, 로그아웃→login.html→(토큰 남음)→makerooms로 튕김. (두 기능이 같은 토큰을 공유하는데 로그아웃이 정리를 안 한 게 핵심)
- **솔루션**: `ClovHeader.logout()` 신설 — 토큰(`localStorage`/`sessionStorage`)을 지운 뒤 `MAIN_BASE` 기준 경로로 로그인 화면 이동. 02-main 헤더 기본 메뉴와 **makerooms.html의 자체 dropdownItems 로그아웃** 양쪽을 `ClovHeader.logout()`으로 교체, makerooms 헤더 스크립트 v11→v12.
- 검수: 02-main·makerooms 양쪽 로그아웃 → 토큰 삭제(true→false)·URL `/01-auth/login` 유지(makerooms로 안 튕김)·콘솔 0. (자체 로그아웃 보유 페이지는 makerooms뿐 — 전수 확인)
