# 0702 일정계획 인생4컷 / 우정공간 복원 작업 기록

## 작업 목적

일정계획의 `growth-card four-cut` 영역을 기존 성장 카드에서 **인생4컷 인증 흐름**으로 바꾸고, 우정공간의 `참여자별 추억 증거 카드`는 기존 **빨랫줄 폴라로이드 + 카메라 필름 스트립** 콘셉트를 유지하도록 복원/정리했다.

---

## 1. 일정계획 — 인생4컷 인증 카드

### 변경된 단계명

기존 식물 성장 단계 문구 대신 인생4컷 제작 흐름에 맞게 4단계를 변경했다.

| 단계 | 표시 문구 |
|---|---|
| 1 | 제안하기 |
| 2 | 일정 맞추기 |
| 3 | 약속 확정 |
| 4 | 만남 |

### 업로드 UX

- 각 프레임 클릭 시 바로 파일 선택창이 뜨지 않고 `업로드 전 확인` 모달이 먼저 뜬다.
- 모달에서 `사진 선택하기`를 눌러야 파일 선택이 진행된다.
- 인증사진은 한 번 업로드하면 변경할 수 없도록 잠금 처리했다.
- 이미 업로드된 프레임 클릭 시 `이미 업로드됐어요` 안내 모달만 표시된다.
- 모든 4단계가 업로드되면 `인생 4컷 완성!` 모달이 표시된다.

### 저장 안정성

- 업로드 이미지는 localStorage 용량 부담을 줄이기 위해 압축 저장한다.
- 저장 공간 부족 시 기존 사진을 덮어쓰지 않고, `저장 공간이 부족해요` 모달을 표시한다.

관련 코드:

- `02-main/js/desktop.js`
  - `buildGrowthStages()`
  - `requestStagePhotoUpload()`
  - `uploadStagePhoto()`
  - `showLockedStagePhotoModal()`

## 2. 전체 약속 보기 — 예시 8개 / 5개 캐러셀

`전체 약속 보기`에 인생4컷 테스트용 예시 약속을 총 8개 구성했다.

기존 약속:

- 제주도 여름 우정 여행
- 중간고사 시험공부 스터디

추가된 예시:

- 홍대 전시회 나들이
- 한강 야간 피크닉
- 성수 카페 투어
- 여름 바다 당일치기
- 방탈출 성공 인증
- 생일 케이크 픽업

### 배치 규칙

- 데스크톱 기준 한 화면에 최대 5개 카드만 보이도록 제한했다.
- 6번째 카드부터는 좌우 화살표로 옆에서 한 장씩 들어오는 캐러셀 방식이다.
- 카드 영역은 가운데 정렬했다.

관련 코드:

- `02-main/js/desktop.js`
  - `lifeFourCutScheduleExamples`
  - `ensureLifeFourCutScheduleExamples()`
  - `scrollGrowthCards()`
- `02-main/css/desktop.css`
  - `.growth-card-rail`
  - `.growth-card-viewport`
  - `.growth-card-list`

## 3. 인생4컷 카드 스타일 정리

### 변경 내용

- `growth-card four-cut`의 `border-radius` 제거
- 카드 외곽은 각진 인생4컷 스트립 느낌으로 정리
- 카메라 이모지 대신 인라인 SVG 카메라 아이콘 사용
- 기존 필름형 4컷 느낌은 우정공간에서 사용하므로, 일정계획은 흰 포토부스 스트립 느낌으로 유지

## 4. 우정공간 — 추억 증거 카드 복원

일정계획 작업 중 우정공간의 `참여자별 추억 증거 카드` 영역이 의도와 다르게 예전 단일 폴라로이드 뷰어처럼 보이는 문제가 있었다.

복원한 구조:

```text
빨랫줄
  └─ 집게 SVG
      └─ 폴라로이드 카드 5장 배치

하단 카메라 필름 스트립
  └─ 과거 → 현재 순서 썸네일
```

### 유지된 콘셉트

- 빨랫줄 폴라로이드
- 빈티지 집게 SVG
- 카드 5장 배치
- 하단 카메라 필름 스트립
- 필름 썸네일 클릭 이동

관련 코드:

- `02-main/js/desktop.js`
  - `clothespinSvg`
  - `renderEvidenceViewer()`
  - `renderEvidenceViewers()`

## 5. 우정공간 글래스모피즘 제거

`memory-evidence-viewer cline-viewer desktop-evidence` 컨테이너에 적용된 유리 느낌이 콘셉트와 맞지 않아 제거했다.

제거한 스타일:

- 반투명 배경
- blur / backdrop-filter
- 큰 border-radius
- 외곽 그림자
- inset highlight

현재 상태:

- 컨테이너는 투명
- 와이어, 집게, 폴라로이드, 필름 스트립 자체 디자인만 남김

관련 CSS:

- `02-main/css/desktop.css`
  - `.memory-evidence-viewer`

## 팀 공유 시 주의할 점

- 우정공간 `참여자별 추억 증거 카드`는 필름/빨랫줄 콘셉트로 확정된 영역이므로, 일정계획 인생4컷 작업과 분리해서 봐야 한다.
- 일정계획의 4컷 카드는 “인생4컷 인증 과정” UI이고, 우정공간의 필름 스트립은 “추억 탐색/보관” UI다.
- 인증사진은 증거 성격이므로 한 번 업로드 후 변경 불가 정책으로 정리했다.
