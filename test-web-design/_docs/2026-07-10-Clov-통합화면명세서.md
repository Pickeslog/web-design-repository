## 1. 화면 개요 및 목적

`test-web-design/02-main/index.html`은 Clov 서비스의 4대 핵심 메뉴(우정공간, 추억피드, 행운편지, 일정계획)를 **단일 페이지(SPA) 구조** 안에서 탭 전환 방식으로 모두 미리보고 테스트할 수 있는 **통합 메인 프로토타입** 화면이다.

- **핵심 원칙 1 (약속 -> 추억 전환)**: 만남 일정이 끝나면 자연스럽게 추억 작성 후보로 이어지는 Clov 핵심 경험 제공
- **핵심 원칙 2 (다중 관점 기록)**: 동일한 약속에 대해서도 친구마다 각자의 시점과 사진, 감정을 남길 수 있는 아카이브
- **핵심 원칙 3 (동등한 권한)**: 방장이나 초대한 사람 구분 없이 모든 참여자가 동등한 자격을 가짐

## 4. 공통 상태 관리 및 테마 명세

1. **테마 호환성 (Light / Dark Mode)**
   - `body.dark-mode` 토글 시 글로벌 CSS 변수(`--card-bg`, `--bg-light`, `--border-color`, `--accent-green`)가 즉각 변환됨
   - 라이트 모드 오버라이드와 다크 모드 오버라이드가 조화롭게 적용되어 흰색 배경 충돌을 방지함

2. **인터랙션 및 모달 관리**
   - 글쓰기 모달 및 프로필 모달은 CSS 애니메이션(`.open`, `@keyframes wm-rise`)을 적용하여 부드럽게 표시됨
   - 모달 닫기 시 배경 오버레이 클릭, 닫기(`X`) 버튼, `Esc` 키 입력을 공통으로 지원함
