## 화면별 명세 9섹션 표준 템플릿 (확정, 사용자 승인함)
```
# 화면명 — 화면 명세서
> 위치 / 최종 갱신 / 핵심 원칙
1. 화면 목적 (한 줄 + 맥락)
2. 진입 · 이탈 경로
3. 화면 레이아웃 (ASCII 스케치)
4. 컴포넌트별 상세 (표: 요소 · 표시/상태 · 동작/비고)
5. 사용자 액션 & 상태 전이 (표: 액션 → 결과) + 상태 변수
6. 데이터 / 저장 (localStorage 키·필드)
7. 예외 / 경계 케이스
8. 반응형 · 테마 (라이트/다크·데스크톱/모바일)
9. 관련 화면 / 모달 (링크)
```

## 작성 원칙 (CLAUDE.md)
- **코드/함수 나열 금지** → 사용자 흐름·UI 영역·상태·데이터·예외 중심.
- **실제 동작하는 화면 기준**(원본 HTML 계획이 아니라 현재 구현). 02-main은 `space.js`/`schedule.js`/`feed.js`/`pages/*.js`가 실제 로직(`desktop.js`는 **미로드**).
- 핵심 서비스 원칙 유지: 인원 제한 없는 단일 구조 · 모든 멤버 동등(방장 없음) · 약속완료→추억작성 · 친구별 관점 기록 · 기록 보존(익명화만).

## 명세에 반영된 최신 구현(이번 세션들 기준)
- 사용자설정: 테마 색 스와치 + **물감 커스텀 색상 피커**(자동 라이트/다크) + 바탕화면 **아이콘 스와치**(이모지 폴백).
- 추억피드/여권: 검색·정렬·사진 모아보기·월별 섹션, MEMORY PASSPORT 상세(약속 영수증 도장 4상태), "사진 없음" SVG, 저장 재압축·롤백.
- 일정계획: **영수증 위에 직접 작성**(라이트/다크 동일 크림 종이), 인생4컷 극장.
- 다크모드 방향: 영수증·행운편지 편지함은 **다크에서도 라이트 유지/가독성 보정**.
- XP: 100%초과 while 다중 레벨업, 안전 저장 래퍼.
- 멤버: 가입 수락 시 참여 멤버 수 + 아바타 동적 반영.
