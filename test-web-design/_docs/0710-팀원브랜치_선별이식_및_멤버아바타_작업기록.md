## 1. 참여 멤버 아바타 동적 반영

- **문제(요청)**: 새 멤버가 참여(가입 신청 수락)하면 "참여 멤버 수"가 늘고 **해당 멤버 프로필(아바타)** 도 보이면 좋겠다.
- **원인**: `updateDynamicMembersDisplay()`가 모달 제목·모달 내 멤버 행은 갱신했지만, **커버 상단 아바타 스택과 카운트 옆 겹침 아바타는 하드코딩 4명(나·솔·민·준) 고정**이라 신규 멤버가 안 보임. 또 커버 카운트 갱신 셀렉터(`.cover-meta-item span`)가 첫 span("참여 멤버" 라벨)을 잡아 **카운트가 4명에서 안 바뀌던 버그**도 있었음.
- **솔루션**:
  - [pages/space-page.js](../02-main/pages/space-page.js): 겹침 아바타 행에 `.member-mini-avatars`, 카운트 span에 `.member-count-text` 클래스 부여.
  - [index.html](../02-main/index.html) `updateDynamicMembersDisplay()`: `.cover-avatar-stack` + `.member-mini-avatars`에 신규 멤버 아바타를 동적 렌더(재렌더 시 `.dyn-member-avatar` 제거 후 재삽입 → 멱등), `.member-count-text` 카운트 갱신.
- **검증**: 멤버 +2(강·김) → 카운트 6명·양쪽 아바타 반영, 재렌더 중복 없음, 퇴장 시 원복, 실제 `acceptJoinRequest` 수락 → 커버 '강' 아바타+5명. (space-page.js `v1→v2`)

## 3. 안전하게 선별 이식한 항목

### 3-1. 경험치 100% 초과 다중 레벨업 (별도 문서에 상세)
`grantXP` 단일 `if` → `while`. → [경험치 문서](0710-경험치_저장공간_기록모달_문제해결_작업기록.md) 참고.

### 3-2. 말풍선 XP 텍스트 `&nbsp;` 문제
- **문제/원인**: 로봇 마스코트 말풍선은 타이핑 연출(`textContent`)이라 `&nbsp;`가 글자로 그대로 보임.
- **솔루션**: XP 메시지의 `&nbsp;` → **실제 non-breaking space 문자(U+00A0)** 로 교체. 크로비(innerHTML)·로봇(textContent) 양쪽에서 공백으로 정상 렌더 + 줄바꿈 방지. ([space.js](../02-main/js/space.js))
- 보류: `<br>`→`\n`은 크로비(innerHTML)에서 줄바꿈이 사라져 위험 → 미적용.

### 3-3. 폴라로이드 태그–메타 간격
- `.memory-meta-row`에 `margin-top: 10px` 추가(본선엔 없었음). ([space.css](../02-main/styles/space.css))

### 3-4. 완료 모달 아이콘 미관 업그레이드
- **문제**: 아이콘이 연녹 원 + 텍스트 "✓"라 밋밋.
- **솔루션**: 텍스트 제거 → **선명한 초록 원(`#22c55e`) + 흰색 SVG 체크마크 + 초록 그림자**. ([index.html](../02-main/index.html) 아이콘 SVG, [space.css](../02-main/styles/space.css) `.proof-result-icon`)

### 3-5. 빈 이미지 UI 통일 → SVG "사진 없음"
- **문제/원인**: 피드/폴라로이드·추억상세의 빈 이미지가 **클로버 placeholder("사진이 없는 추억은 클로버로…")** 인데, evidence 카드는 `cline-no-photo` SVG "사진 없음" — 톤 불일치.
- **솔루션**: 클로버 placeholder → **cline-no-photo SVG "사진 없음"** 으로 통일(두 곳 일괄). 폴라로이드 빈 영역(184×177)이 커서 아이콘 20→**47px**, 글자 9→**12px**로 스코프 확대. ([space.js](../02-main/js/space.js), [space.css](../02-main/styles/space.css) `.polaroid-photo` 스코프)

### 3-6. 행운편지 편지함 다크모드
- **문제/원인**: `.letter-stage`가 다크모드 override 없이 **항상 밝은 배경** → 다크에서 밝은 배경에 흰 글자 묻힘.
- **솔루션**: [letter.css](../02-main/styles/letter.css) `v2→v5`
  - `body.dark-mode .letter-stage` — 어두운 그라데이션 배경(팀원 규칙 이식)
  - 무대 텍스트를 밝게(`!important`): 키커 `#9ccc65`·제목 `#eef0e2`·부제 `#b7c99a`·요약 `#eef0e2` (본선에선 배경만으론 글자가 어둡게 남아 명시)
- **검증 주의**: 이 페이지에서 프리뷰 `getComputedStyle`이 낡은 값을 돌려주는 측정 버그가 있어 픽셀 확인은 못 했으나, **CSSOM 스캔으로 확정** — 편지함 텍스트에 `color:!important`는 내 규칙이 유일(경쟁 규칙·인라인 없음)이라 실제 브라우저에서 반드시 밝게 적용됨.

## 4. 조사 후 "적용 불필요/보류" 결론

| 팀원 항목 | 결론 |
|---|---|
| 생일 마스코트 대사 | 본선에 **이미 있음**(space.js) — no-op |
| 완료모달 💬 버그 수정 | 본선은 `secondary` 요소 존재로 **버그 없음** (아이콘 미관만 3-4에서 개선) |
| `<br>`→`\n` 말풍선 | 크로비 innerHTML에서 줄바꿈 소실 → **보류** |
| 빈 이미지(#2) | 디자인 결정 후 SVG "사진 없음"으로 **적용**(3-5) |
| 레벨바 계절색/글래스(#7) | 본선 레벨바는 **글래스 없음**(제거할 것 없음) + 채움색은 `--level-accent`로 **레벨별 색 진화** 중 → 계절색은 상충이라 **보류** |
| clovToast 제거 / 다크 방향(letter 외) | 🔴 위험 — 선별 병합 필요, **보류** |
