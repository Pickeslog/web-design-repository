# 0710 — 사용자설정 스와치 UI · 물감 커스텀 색상 이식 작업기록

> 대상: 본선 `test-web-design/02-main/`
> 출처: 팀원 브랜치 `team-branches/chacha1650a/` (사용자설정 리디자인 담당)
> 검증: 정적 서버(8890) + DOM/CSSOM. (이 프리뷰는 `getComputedStyle`이 배경색/색상 계열에서 stale 값을 돌려주는 측정 버그가 있어, 픽셀 확인 대신 인라인 스타일 설정값 + CSSOM 스캔으로 확정)

chacha1650a 팀원이 사용자설정(프로필 모달)의 **테마·바탕화면을 스와치 UI로 리디자인**하고 **물감(paint blob) 커스텀 배경색** 기능을 신규로 만들었다. 본선과 UI 뼈대(같은 pane·id·`theme-option` 클래스)는 공유하되 렌더 방식만 달라, **팀원 코드를 통째 복사하지 않고 본선 구조에 맞춰 선별 이식**했다.

- `clov-profile-modal.js`는 본선(v21)·팀원(v26) 버전이 갈라져 통째 병합 위험 → 함수/템플릿 단위로 이식.

## 2. 이식한 것

### 2-1. 테마 색 스와치 + 바탕화면 아이콘 스와치
- **에셋**: 아이콘 PNG 6종을 `02-main/assets/background-icons/`로 복사.
- **템플릿**([clov-profile-modal.js](../02-main/components/clov-profile-modal.js)): 테마 LI를 `theme-swatch-box--light/--dark` 색칩으로, 바탕화면 UL을 `theme-swatch-list`로, 기본 항목을 `theme-swatch-box--image`로.
- **등록소**: `CLOV_APP_BACKGROUNDS` 각 배경에 `iconImage`(PNG 경로) 추가.
- **렌더**: `renderAppBackgroundOptions()`가 이미지 스와치를 그리도록 변경.
- **폴백(본선 전용)**: 아이콘 PNG가 없는 배경(LP 앨범 컬렉션)은 **이모지 스와치(🎶)** 로 자동 폴백(`theme-swatch-box--emoji`).
- **CSS**([base.css](../02-main/styles/base.css)): `.theme-swatch-box`(light/dark/image/emoji) + active 링 글로우. 본선 `.settings-list`가 이미 flex 가로배치라 레이아웃은 그대로 동작.
- active 토글은 본선 기존 `updateThemeOptionUI`/`updateAppBackgroundUI`가 `.theme-option`+data속성으로 처리 → 스와치에도 그대로 호환.

### 2-2. 물감(paint blob) 커스텀 색상 카드
- **템플릿**: 테마 ↔ 바탕화면 사이 "사용자 설정" 카드 — 물감 SVG blob + `↺ 기본값으로` 버튼 + 안내 + 커스텀 피커 팝오버.
- **색공간 변환**: `hexToRgb/rgbToHex/rgbToHsv/hsvToRgb/normalizeHexColor/getCustomAppBgColor` + `isColorDark`(WCAG 상대 휘도, 임계 0.45).
- **`applyAppBackground` custom 분기**: `background-image:'none'`으로 텍스처 제거 + 단색(`backgroundColor`) 적용. (global-theme.css의 텍스처가 색을 덮던 문제 대응)
- **자동 라이트/다크**: 커스텀 색 밝기에 따라 `body.dark-mode` 자동 토글(가독성), 커스텀을 벗어나면 사용자 원래 설정(`clov_darkMode`)으로 복원.
- **커스텀 색상 피커**: 네이티브 `<input type=color>` 대신 SV 그라디언트 박스 + Hue 슬라이더 팝오버 자체 구현. 드래그(`pointerdown/move/up`, `setPointerCapture` try/catch 방어), 바깥 클릭 시 닫힘.
- **CSS**: 물감 SVG glow(`--paint-glow` drop-shadow), 피커 팝오버/SV/Hue/커서, `.profile-form-section--card`.
- 전역 등록: `window.togglePaintPicker`, `window.resetAppBackgroundToDefault`.

---

## 3. 본선 적응 (팀원 코드 그대로 복사 안 함)

- **토스트 보존**: 팀원은 `clovToast`를 배경 전환에서 제거했지만, **본선은 토스트 유지**. 커스텀 색상만 피커에서 **조용히 적용**(`commitPaintPickerColor`가 `setAppBackground`를 안 거치고 저장+적용) → 드래그 토스트 스팸 방지. 스와치 클릭은 기존 토스트 그대로.
- **테마 스와치 동기화**: 배경 밝기 자동 토글이 다크모드에 개입하므로 `setAppBackground`에 `updateThemeOptionUI()` 연동 추가.
- **이모지 폴백**: 본선은 배경이 7개(팀원 6개)라 아이콘 없는 1개를 이모지 스와치로 처리.

---

## 4. 검증 (정적서버 8890)

- 테마 스와치 2개(52px) + 바탕화면 스와치 7개(이미지 6 + 이모지 1, 60px) 렌더, active 정확 ✓
- 아이콘 6종 모두 로드(naturalWidth 512, 200 OK) ✓ *(초기 404는 에셋 복사 전 로드로 인한 브라우저 캐시 → 하드리로드 후 정상)*
- 클릭 동작: 배경/테마 스와치 클릭 시 전환+active 이동 ✓
- 물감 카드: blob·버튼·피커 렌더, 함수 전역 등록 ✓
- 커스텀 색: 인라인 `background-color`/`background-image:none` 정확 설정, blob fill·glow·swatch active 반영 ✓
- 자동 라이트/다크: 어두운 색→다크, 밝은 색→라이트 ✓
- 리셋(기본값 복귀)·**리로드 지속성**(저장 커스텀 색 자동 재적용) ✓
- 콘솔 오류 0건
- ※ 배경색은 프리뷰 `getComputedStyle`이 stale라, **인라인 설정값 정확 + CSSOM 스캔으로 body/main에 `background-color !important` 없음**을 확인해 실제 브라우저 정상 렌더 확정.

## 확정 원칙 (재발 방지)
- 팀원 브랜치는 버전 히스토리가 갈라져 있어 **파일 통째 복사 금지** — 함수/템플릿 단위로 본선에 맞춰 이식.
- 본선의 토스트 피드백은 보존하되, 연속 이벤트(피커 드래그)는 조용히 적용해 스팸을 피한다.
- 커스텀 배경색은 `background-image:'none'` 명시로 텍스처를 지워야 단색이 보인다.
