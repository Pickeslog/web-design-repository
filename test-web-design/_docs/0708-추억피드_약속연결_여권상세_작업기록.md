# 0708 — 추억피드 약속 연결 + MEMORY PASSPORT 상세 작업기록

> 핸드오프: `추억 피드 확장판/handoff/추억피드-약속연결-스펙.md` + `약속연결-확정-레퍼런스.dc.html`
> 작업 범위: `02-main` (추억피드 상세 모달 · 글쓰기 모달 · 데이터 모델)

## 개요

추억 게시글(MemoryPost)에 일정계획의 약속(Schedule)을 연결하는 기능을 구현했다.

- `MemoryPost.scheduleId`(nullable) 신규 필드 — 약속 데이터를 복제하지 않고 **참조**만 한다 → D-Day·4컷 진행률·완성 도장이 일정계획과 항상 동기화.
- 추억 상세 모달을 **MEMORY PASSPORT(여권형)** 으로 리디자인 — 여권 표지 밴드 + 대표사진/썸네일 스트립 + 약속 영수증 + STATUS/PHOTOS/REMARKS/MRZ.
- 글쓰기(추억 기록하기) 모달에 **약속 연결(선택)** 섹션 추가 — 일정계획에서 가져오기 / 연결됨 칩(변경·해제) / ＋새 약속 만들기 폴백.

## 약속 영수증 도장 규칙 (스펙 §2 — 절대 규칙)

| 상태 | 조건 | 표시 |
|---|---|---|
| before | 만남 전 (`diffDays > 0`) | D-Day 도장만 (`함께할 그날까지`) |
| pending | 만남 당일/지남 · 4컷 미완성 | D-Day 도장 + `4컷 기록 대기` 점선 스탬프 |
| complete | `proofCount === 4` | D-Day 도장 + **추억 완성 도장 추가** (교체 아님) |
| free | `scheduleId == null` | FREE MEMORY 스탬프 (초록 이중 테두리) |

- D-Day 도장은 상태와 무관하게 **빨강(#c0392b) 고정 · 영구 유지** (회색처리/축소/교체 금지).
- 완성 도장: `assets/stamps/memory-complete-stamp.png`, `rotate(-12deg)` + `mix-blend-mode: multiply` + `opacity:.9`, 영수증 하단 배치(제목·사진·D-Day 도장 안 가림 — 검증 완료).
- 4컷 진행률은 `getScheduleProofCount(schedule)`(일정계획 `stagePhotos`)를 그대로 조회.

## 유지한 것 (스펙 '하지 말 것')

- 피드 폴라로이드 카드 그리드·클릭 → `openMemoryDetail` (변경 없음)
- **친구 한 줄 메시지 영역** — 마크업/동작 그대로 유지
- 게시자 수정/삭제, 친구 메시지 작성·수정·삭제 동작 유지
- 여권/영수증은 라이트·다크 공통 고정 색 (다크에서도 크림 종이 유지 — 의도된 대비)
