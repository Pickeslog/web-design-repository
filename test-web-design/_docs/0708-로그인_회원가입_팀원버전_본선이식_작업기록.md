# 0708 — 로그인/회원가입 팀원 개선본 본선 이식

> 출처: `web-design-repository/로그인+회원가입/test-web-design/01-auth/` (팀원 작업, 2026-07-07)
> 대상: 본선 `test-web-design/01-auth/`

## 개요
팀원이 전면 개선한 로그인·회원가입 standalone 페이지를 본선에 이식했다. 로그인 성공 후 이동 경로만 본선 진입 흐름(로그인 → 우정공간 선택 → 메인)에 맞춰 조정했다.

## 팀원 개선본에 포함된 것 (0707 작업)
- 회원가입: 글래스모피즘/3D 카드 제거 → 플랫 재설계, **5단계 위저드**(이메일·비밀번호 → 약관 → 프로필 사진 → 닉네임·생년월일 → 완료)
- 검증 실패 시 경고 문구 대신 **입력창 흔들림(shake)** 으로 로그인과 UX 통일
- **Enter 키 내비게이션**(`enterNext`) — 다음 입력/제출로 이동 (로그인·회원가입 공통)
- **약관 동의 키보드 접근성**(`handleTermsKey`, `role="checkbox"`, `aria-checked`, Space 토글/Enter 진행)
- 스텝 인디케이터 차오르는 애니메이션, 로그인 유지(`accessToken`) + 성공 오버레이(`ClovSuccessOverlay`)

## 변경 파일
| 파일 | 내용 |
|---|---|
| `01-auth/login.html` | 팀원 버전으로 교체 + **리다이렉트 목적지 조정**: 자동 로그인(accessToken 보유 시)·로그인 성공 오버레이 목적지를 `../02-main/index.html` → **`../03-rooms/makerooms.html`** |
| `01-auth/signup.html` | 팀원 버전 그대로 이식 (완료 시 `localStorage.clov_profile` 저장, "로그인하러 가기" → `login.html`) |

## 의존성
팀원 login/signup이 참조하는 지원 파일은 본선 `02-main`에 **이미 동일 버전으로 존재**해 추가 이식 불필요:
- `02-main/css/global-theme.css`, `02-main/css/success-overlay.css`
- `02-main/js/auth.js`(`ClovAuth`), `02-main/js/success-overlay.js`(`ClovSuccessOverlay`)
- (4개 파일 모두 팀원 폴더와 `diff` 결과 동일)

## 검수 (본선, 정적 서버)
- 로그인 페이지: `ClovAuth`/`ClovSuccessOverlay`/`enterNext` 로드, 디자인 토큰(`--forest` 등) 적용, 콘솔 오류 0
- 로그인 실행 → 성공 오버레이 표시 + `accessToken` 저장 → **`03-rooms/makerooms`로 리다이렉트** 확인
- 회원가입 페이지: 스텝 점 5개, `goStep`/`handleTermsKey`/`enterNext`, `role="checkbox"` 약관 4행, step-4 존재, 콘솔 오류 0
- `goStep` 단계 전환 정상(`validateStep0`은 진행 게이트 검증 함수)

## 남은 참고
- 본선 진입 흐름 유지를 위해 로그인은 makerooms를 거치도록 함(팀원 원본은 02-main 직행이었음).
- 이전 본선 login/signup(개선 전)은 이 교체로 대체됨.
