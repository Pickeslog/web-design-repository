# 추억피드 검색 + 정렬 필터 추가 작업기록 (2026-07-07)

우정공간 추억피드(`02-main` 데스크톱 탭)에 **추억 검색**과 **정렬(최신순/오래된순)** 컨트롤을 추가했다. 기존 월 선택·전체/내 기록/친구 기록 필터는 그대로 두고, 세 컨트롤이 서로 조합(compose)되도록 했다.

## 바꾼 파일

| 파일 | 내용 |
|---|---|
| `pages/feed-page.js` | `.feed-controls` 재구성 — 왼쪽에 검색 입력창(`.feed-search`, 돋보기 아이콘 + `type=search` + 지우기 버튼), 오른쪽에 정렬 토글(`.feed-sort` 최신순/오래된순) + 기존 필터 탭 |
| `js/data.js` | 상태 변수 2개 추가 — `activeFeedSort='new'`, `activeFeedSearch=''` (기존 `activeFeedFilter/Month` 옆, `let` 전역 바인딩이라 feed.js에서 공유됨) |
| `js/feed.js` | `setFeedSort`/`setFeedSearch`/`clearFeedSearch` + 헬퍼(`getPostDateKey` 전체 날짜키, `postMatchesFeedSearch`). `renderFeeds()`에 검색 필터·날짜 정렬·검색 전용 빈 상태 메시지 추가 |
| `styles/feed.css` | 검색창·지우기 버튼·정렬 세그먼트 토글 스타일 + `.feed-controls` `space-between`/`wrap` 오버라이드, `.feed-controls-right` 그룹 |
| `index.html` | 캐시 버전: `feed.css v1→2`, `feed-page.js v1→2`, `data.js v1→2`, `feed.js v1→2` |

## 동작 규칙

- **검색 대상**: 제목·부제·본문·날짜·태그·참여자 이름·참여자 메시지(`post.messages[].text`)를 한 문자열로 합쳐 소문자 부분일치. 검색은 `normalizeMemoryPost`를 거친 포스트 기준(참여자 메시지가 `messages`로 이관된 뒤).
- **정렬**: `post.date`("YYYY.MM.DD")를 `YYYY-MM-DD` 키로 정규화해 문자열 비교. 최신순=내림차순, 오래된순=오름차순. 날짜 파싱 불가 항목은 항상 맨 뒤.
- **조합**: 월 선택 → 필터 탭(전체/내/친구) → 검색 → 정렬 순으로 적용. 카드의 편집/삭제 인덱스는 정렬과 무관하게 `currentPosts.indexOf(post)` 원본 인덱스를 그대로 사용(동작 회귀 없음).
- **빈 상태**: 검색 중 결과 없으면 "검색어와 일치하는 추억이 없습니다", 그 외에는 기존 문구.
- 상단 요약 배지(`전체 · N개`)는 검색/정렬 후 보이는 개수를 그대로 반영.

## 검증 (프리뷰 `02-main/` 피드 탭, 12개 카드)

- 콘솔 에러/경고 0
- 정렬: 최신순 `06.20→06.15→06.08…`, 오래된순 `01.01→02.22→03.14…` 정상 반전
- 검색: "한강" 2개, "노래방" 1개(본문/메시지 매칭), 없는 단어 → 0개 + 빈 상태, 지우기 → 12개 복귀·입력창 비움·× 버튼 숨김
- 조합: 친구 기록 필터 + "스터디" 검색 → 1개
- 반응형: 데스크톱은 좌(검색)·우(정렬+탭) 양끝 배치, 375px에서는 검색이 전체폭 상단, 정렬+탭이 아래로 자연 줄바꿈

## 후속 수정 (같은 날)

피드백 2건 반영 (`styles/feed.css` `?v=2→3`):

1. **검색창 가운데 정렬** — `.feed-controls`를 `flex-direction: column`으로 바꿔 검색창을 `margin: 0 auto`로 가운데(최대 440px), 정렬/필터 줄은 그 아래 오른쪽 정렬.
2. **다크모드 검색 텍스트 안 보이던 문제** — 검색 알약 배경은 라이트/다크 공통으로 밝은색(`rgba(255,255,255,0.9)`)인데 입력 텍스트가 `var(--text-color)`(다크모드에서 밝은 크림 `#eef0e2`)라 흰 배경에 묻혔음. 텍스트를 `#2c3e35`, 플레이스홀더를 `#61766a`로 **고정**(대비 ≈10.7:1). 정렬 토글·필터 탭이 이미 쓰는 "밝은 알약 유지" 패턴과 동일하게 맞춤.

검증: 검색창 좌우 여백 동일(가운데), 다크모드 입력 텍스트 `rgb(44,62,53)` 정상 표시, 콘솔 에러 0.

## 비고

- 레거시 `js/desktop.js`(모놀리식)의 `renderFeeds`에는 반영하지 않음. 이 로직을 쓰는 `04-feed/feed.html`은 현재 어떤 페이지에서도 링크되지 않는 **orphan**이라 본선 흐름에 영향 없음. 나중에 그 페이지를 살릴 경우 동일 패턴으로 미러 필요.
