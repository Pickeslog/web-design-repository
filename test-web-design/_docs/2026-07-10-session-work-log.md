# 2026-07-10 UI 및 기능 버그 수정 작업 기록

## 1. 하단 토스트 메시지 노출 제거
*   **작업 목적:** 화면 하단에 검은색으로 뜨는 알림(Toast) 메시지를 사용자 요청에 따라 완전히 제거.
*   **작업 내용:**
    *   `test-web-design/02-main/components/clov-modal.js` 파일 수정.
    *   `window.clovToast` 함수 내부 로직을 모두 지우고 `return;` 처리.
    *   기존 다른 코드에서 `clovToast`를 호출하더라도 아무런 동작을 하지 않으며 에러가 발생하지 않도록 조치.

## 2. 마스코트 경험치(XP) 100% 초과 버그 수정
*   **작업 목적:** 방치형 보상 등 대량의 경험치를 한 번에 획득할 때, 게이지바가 142%처럼 100%를 넘겨 비정상적으로 표기되는 현상 수정.
*   **작업 내용:**
    *   `test-web-design/02-main/js/space.js`의 `grantXP` 함수 수정.
    *   기존의 단일 `if`문 레벨업 판정 방식을 `while` 반복문으로 변경.
    *   초과된 경험치 양만큼 여러 번의 레벨업을 연속으로 정상 처리한 뒤, 나머지 잉여 경험치만 진행도(`levelProgress`)에 이월하여 표시되도록 안정화.

## 3. 마스코트 대사 및 시간 초기화 로직 검토 (코드 분석)
*   **작업 목적:** 로봇 마스코트 대사 출력 안정성 및 자정(00시) 초기화 기준 확인.
*   **확인 결과:**
    1.  **로봇 마스코트 대사:** 
        *   `typeof CrobyMascot.getCharacter === 'function' && CrobyMascot.getCharacter() === 'robot'` 조건을 사용하여 런타임에 동적으로 캐릭터 종류를 판별함.
        *   타 팀원이 파일을 병합해 로봇 캐릭터를 활성화하더라도 전용 대사(예: "데이터 획득")가 완벽하게 분기 처리되어 잘 출력됨을 확인함.
    2.  **자정(00:00) 초기화 기준:**
        *   `new Date()` 객체를 사용하므로 사용자의 **로컬 디바이스 시간**에 맞춰 초기화됨.
        *   한국 유저의 경우 디바이스가 KST(한국 표준시)이므로 정상적으로 한국 시간 00시에 초기화됨. (글로벌 고정 KST가 필요할 경우 추후 오프셋 로직 추가가 필요함)

## 4. 추억 피드 태그-날짜 간격 조정
*   **작업 목적:** 추억 폴라로이드 카드의 태그 영역(`.memory-footer-tags`)과 하단 날짜/메타 영역(`.memory-meta-row`)이 너무 붙어있는 문제 해결.
*   **작업 내용:**
    *   `test-web-design/02-main/css/desktop.css` 및 `test-web-design/02-main/styles/space.css` 파일 수정.
    *   `.memory-meta-row` 클래스에 `margin-top: 10px;` 속성을 추가하여 디자인 원본 훼손 없이 정확히 10px 아래로 배치.

## 5. 약속 여정 다크모드 글자색 보이지 않는 이슈 수정
*   **작업 목적:** 다크모드 활성화 시 '약속 여정' 탭 상단 타이틀 텍스트가 하얀색으로 변해, 밝은 옐로우/오렌지 톤의 배경 이미지와 겹쳐 글자가 안 보이는 현상 수정.
*   **작업 내용:**
    *   `test-web-design/02-main/css/desktop.css` 및 `test-web-design/02-main/styles/schedule.css` 파일 수정.
    *   `body.dark-mode .journey-page-title` 선택자를 추가하여, 다크모드에서도 텍스트 색상이 밝은 배경에서 선명히 보이도록 짙은 색상(`#1c1a17`)으로 고정.
