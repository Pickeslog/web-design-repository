# 2026-07-10 작업 일지: UI 버그 수정 및 개선 사항 요약

본 문서는 오늘 팀 프로젝트 진행 간 발견된 UI/UX 버그와 기능적 오류를 어떻게 수정했는지 세부적으로 기록한 것입니다. 다른 팀원들이 작업 내역을 파악하고 향후 비슷한 문제를 해결하거나 참고하는 데 활용할 수 있습니다.

## 1. 레벨바 계절별 색상 적용 및 글래스 효과 제거
- **수정 위치:** `js/v5-banner.js`
- **원인/요청:** 레벨바가 계절과 관계없이 동일한 색상이거나 시각적으로 불필요한 글래스(Glass) 효과가 들어가 있어 디자인 기획과 맞지 않았습니다.
- **해결 방법:** 
  - 레벨바 컨테이너 및 채움 막대에 걸려 있던 `backdrop-filter: blur(...)` 등의 글래스 효과를 제거했습니다.
  - 현재 설정된 `season` 데이터를 바탕으로 레벨바가 각각의 계절(봄, 여름, 가을, 겨울) 테마에 맞는 색상 변수를 참조하여 색이 변하도록 로직과 CSS 속성을 조정했습니다.

## 2. 마스코트 교감 제한 해제 버그 수정
- **수정 위치:** `js/space.js` 내 마스코트 클릭 이벤트 (`window.CLOV_DISABLE_CLICK_LIMIT` 로직 부분)
- **원인:** 하루 교감 횟수 제한(예: 3회)을 해제(OFF)하는 기능을 활성화하더라도, 내부 로직에서 조건문이 잘못 묶여 있어 `xpClicksToday >= CLOV_MAX_CLICKS_PER_DAY`에 걸리면 마스코트 클릭이 무시되는 버그가 있었습니다.
- **해결 방법:** `if (!window.CLOV_DISABLE_CLICK_LIMIT && grp.xpClicksToday >= CLOV_MAX_CLICKS_PER_DAY)`와 같이 명시적으로 제한 해제 변수(`CLOV_DISABLE_CLICK_LIMIT`)를 가장 먼저 확인하도록 `space.js`의 조건문을 수정하여 무제한 교감이 가능하게 만들었습니다.

## 3. 경험치 출력 오류 및 다크모드 글자 굵기(폰트 웨이트) 수정
- **수정 위치:** `js/space.js` (경험치 메시지 출력부), 관련된 다크모드 CSS
- **원인:** 
  - 경험치 지급 시 HTML 엔티티(`&nbsp;`)를 `innerText` 혹은 렌더링 과정에 그대로 넣어버리면서 "+25&nbsp;XP"처럼 문자가 깨져 출력되는 문제가 있었습니다.
  - 다크모드 시 텍스트 시인성을 높이기 위해 굵은 폰트(bold)가 전역적으로 들어가는 스타일이 있어 라이트 모드와 위화감이 있었습니다.
- **해결 방법:** 
  - 문자 깨짐을 막기 위해 `&nbsp;` 대신 유니코드 공백 문자(`\u00A0`)를 사용하여 `+25 XP`가 올바르게 렌더링되게 수정했습니다.
  - 다크모드 관련 CSS에서 폰트 굵기를 라이트 모드와 동일한 기본 웨이트로 유지하도록 오버라이드 코드를 추가/수정했습니다.

## 4. 추억 피드의 빈 이미지(Placeholder) UI 통일
- **수정 위치:** `js/space.js`, `js/feed.js` (게시물 렌더링 부분)
- **원인:** 사용자가 사진을 등록하지 않았을 때 피드에 표시되는 기본 이미지(🍀 아이콘 및 텍스트)가 '참여자별 추억 증거 카드'의 빈 이미지 플레이스홀더 디자인과 달라 통일감이 떨어졌습니다.
- **해결 방법:** `js/space.js` 등의 포스트 렌더링 구역에서 이미지가 없는 경우 들어가는 HTML 마크업을 증거 카드와 완전히 동일한 마크업(`<div class="cline-no-photo"...>`)과 디자인 시스템 내장 SVG 아이콘으로 교체하여 디자인을 통일했습니다.

## 5. '자세히' 버튼 오동작 수정
- **수정 위치:** `js/space.js` 폴라로이드 카드 렌더링부
- **원인:** 첨부된 사진이 없음에도 불구하고 폴라로이드 카드 하단에 돋보기 아이콘과 '🔍 자세히' 버튼이 무조건 렌더링되어 사용자의 혼란을 초래했습니다.
- **해결 방법:** 삼항 연산자 등을 사용해 `coverPhoto`가 존재하는 경우에만 `<span class="polaroid-zoom-hint">🔍 자세히</span>` 버튼이 DOM에 렌더링되도록 조건을 추가했습니다.

## 6. 마스코트 말풍선 경험치 및 가속 문구 잘림 현상 해결
- **수정 위치:** `js/space.js` (말풍선 문구 조합 및 `say()` 함수)
- **원인:** 마스코트가 말풍선을 표시할 때 텍스트가 너무 길거나 HTML 줄바꿈 태그(`<br>`)가 일부 텍스트 요소 안에서 잘못 해석되어 가속(x2 등) 문구 및 경험치 텍스트가 컨테이너를 벗어나거나 잘리는 현상이 있었습니다.
- **해결 방법:** 메시지를 생성하는 `buffSuffix`에서 `<br>` 대신 `\n` 이스케이프 문자를 사용하여 말풍선 영역에서 문구가 잘리지 않고 올바른 줄바꿈으로 예쁘게 출력되도록 처리했습니다.

## 7. 일정계획 & 행운편지 다크모드 색상 동기화
- **수정 위치:** `styles/schedule.css`, `styles/letter.css`
- **원인:** 
  - 다크모드일 때 일정계획 본문 영역은 여전히 밝은 회녹색 등 다른 톤을 유지하여 제목/날짜 입력란(어두운 배경)과 이질감이 있었습니다.
  - 행운편지 구역 역시 배경이 라이트 모드 톤을 그대로 유지하는 바람에 다크모드 텍스트 컬러(보통 흰색 계열)와 겹쳐서 글씨가 거의 보이지 않았습니다.
- **해결 방법:**
  - `schedule.css`에서 다크모드 `.dark-mode` 활성화 시 일정계획 본문 배경을 `var(--input-bg)`와 동일한 어두운 테마 변수로 통일했습니다.
  - `letter.css`에서 `.dark-mode .letter-stage` 영역에 어두운 바탕색(`var(--surface-color)`, `var(--input-bg)` 등)을 오버라이드하여 글자색과의 대비(Contrast)를 맞춰 가독성을 확보했습니다.

## 8. 생일 이벤트 마스코트 전용 대사 추가
- **수정 위치:** `js/space.js` (`msg` 조립 로직)
- **원인:** 화면(배너)의 상태(`v5state.event`)가 `my_birthday` 거나 `friend_birthday` 일 때, 마스코트를 클릭해도 일반적인 교감 대사만 출력되어 생일이라는 특별 이벤트 몰입감이 떨어졌습니다.
- **해결 방법:** `if` 문을 추가해 `window.v5state.event`가 생일 이벤트인지 확인하고, 설정된 마스코트 생일 대사(`window.lastMascotLine`)를 경험치 획득 안내(`+1 XP`)와 조합하여 출력되도록 조건을 삽입했습니다.

## 9. 비정상적 만렙(777렙) 달성 반짝이 이펙트 발생 버그 수정
- **수정 위치:** `js/space.js` (초기화 부분 및 `friendshipLevel`)
- **원인:** 화면 UI의 레벨바와 텍스트는 `v5-banner.js`의 초기값(3레벨)에 맞춰져 표시되었지만, 내부 엔진에서 이펙트 발생 여부를 판단할 때 사용하는 `groupsData[activeGroup].level` 값은 브라우저(로컬 스토리지)에 과거 테스트용으로 저장되어 있던 777레벨을 그대로 참조하고 있었습니다. 이로 인해 화면상으로는 레벨이 3임에도 불구하고, 글을 작성(`grantXP` 호출)하면 내부적으로 `777 >= CLOV_MAX_LEVEL` 조건을 통과하여 만렙 전용 칭찬 이펙트(반짝이와 "추억 데이터 반짝임 감지 ✨🔋" 알림)가 터지는 데이터 비동기화 오류였습니다.
- **해결 방법:** `space.js`가 로드될 때 UI 표시 레벨인 `friendshipLevel = 3`으로 무조건 초기화되던 구문을 수정했습니다. 로컬 저장소의 실제 레벨 데이터(`groupsData[activeGroup].level`)를 우선 파악하여 존재할 경우 해당 값으로 화면 UI를 초기화하도록 동기화 코드를 작성했습니다. 그 결과 UI가 내부 데이터를 올바르게 반영하게 되어 버그가 원천 해결되었습니다.
