# 롭(Rob) 마스코트 본선 이식 작업기록 (2026-07-07)

팀원 브랜치 `team-branches/chacha1650a/test-web-design/02-main`에 만들어져 있던 두 번째 마스코트 **롭(로봇)** 을 본선(`web-design-repository/test-web-design`)에 반영했다. 기존 크로비(Croby) 동작은 그대로 두고 로봇 캐릭터와 전용 인터랙션만 추가했다.

## 이식 방식 — 선별 추출 (전체 머지 아님)

chacha1650a 브랜치는 **본선보다 오래된 스냅샷**이라 파일 통째 복사 시 본선의 최신 작업이 퇴행한다. 실제로 브랜치 `clov-profile-modal.js`에는 아래 회귀 요소가 남아 있어 **가져오지 않았다**:

- `field`(클로버 들판) 대시보드 배경 옵션 — 본선은 0707에 전면 제거함
- 구버전 계정 탈퇴 확인 플로우(`정말 계정을 탈퇴하시겠습니까?`) — 본선의 익명화 보존 플로우가 최신
- `diary`(일기장) 증거 카드 테마 누락 — 본선은 0707에 추가함

또한 브랜치 `clov-header.js`에 섞여 있던 **로그아웃 `ClovAuth.clearAccessToken()` 변경은 롭과 무관한 별도 인증 작업**이라 제외했다.

## 로드 지점 / 캐시 버전

- 마스코트 위젯(`croby-mascot.js`/`.css`)은 `02-main/index.html`에서만 로드 → `assets/rob/` 상대경로 정상 해석. 캐시 `?v=1 → ?v=2`
- `clov-profile-modal.js`는 `02-main/index.html`(v15→16)과 `03-rooms/makerooms.html`(v14→15) 공유. makerooms엔 마스코트 스크립트가 없지만 `applyMascotCharacter`가 `window.CrobyMascot` 존재를 가드해서 그 페이지에선 **설정값만 저장**(기존 공용 컴포넌트 패턴 그대로)

## 검증 (프리뷰 서버 `02-main/`)

- 콘솔 에러 0, 실패 네트워크 요청 0
- 초기 크로비 정상(`croby_default.png`) → 설정 UI에서 로봇 선택 시 `assets/rob/idle.png`로 실시간 전환, `data-character="robot"` 반영, 스토리지 저장
- 설정 모달 "마스코트 캐릭터" 목록에 크로비/로봇 2옵션 렌더 + 현재 선택 항목 active 표시
- UI에서 크로비 재선택 시 되돌아옴, 로봇 스프라이트 이미지 정상 디코드(900×510)
- 로봇 상태로 새로고침 → 재진입 시 로봇으로 초기화(영속성 확인)
- 반응형: 뷰포트 ≤768px에서 로봇 스프라이트 52px(모바일 보정), 데스크톱 115px
