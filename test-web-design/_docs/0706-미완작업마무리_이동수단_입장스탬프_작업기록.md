## 1. 미완 작업 3건 마무리 (0706 A-8 등)

### 1-1. 미사용 레거시 CSS 정리 — `makerooms.html`
보딩패스 티켓 카드(`tk-*`)로 전면 교체되며 죽은 구 카드/구 모달 CSS를 **grep으로 사용처 전수 검증 후** 제거.
- 구 카드: `.card-top .icon-wrap .room-icon .new-badge .fav-btn .room-name .room-intro` + D-day 버튼군(`.dday-btn .dday-icon .dday-inner .dday-count .dday-label`)
- 구 편집 모달: `.photo-row .photo-preview-box .photo-hint`
- 구 3탭 미리보기: `.preview-tab .preview-tab-dot .preview-list-item/-title/-desc/-time`
- **유지(오탐 방지):** `.drag-handle`, `.copy-btn`(초대 코드 복사에 사용), `.preview-empty`(신규 소식 피드 빈 상태에서 사용)

### 1-2. 대표사진 폴백 (A-8) — `makerooms.html`
**근본 원인:** `room.photo`가 추억 SVG 원본만 저장하고 **출처 추억과의 연결 고리(id)가 없어** 삭제를 감지할 수 없었음.
- `MEMORY_PHOTOS` 각 항목에 안정 `id` 부여 + 방에 `photoMemId` 저장(`saveRoomProfile`).
- `resolveRoomPhoto(room)` 신규: `photoMemId`가 가리키는 추억이 사라지면 `photo→null`(테마 폴백) + 소식 피드에 "대표사진이 원본 추억 삭제로 테마 일러스트로 바뀌었어요" 기록.
- 추억 피커에 **삭제(✕) 버튼**(`deleteMemoryPhoto`) 추가 — 명세의 "추억 삭제 이벤트"를 데모 가능하게(삭제 시 그 사진을 쓰던 모든 방을 폴백 + 토스트).
- 출처 감지(`openRoomEditView`)를 `photoMemId` 우선으로 정리, 관련 CSS(`.rp-mem-cell/.rp-mem-del/.rp-mem-empty`) 추가.
- 신규/변경: `rpEditPhotoMemId`, `resolveRoomPhoto`, `deleteMemoryPhoto`, `rpRenderMemoryPicker`(id 기반·삭제 버튼), `rpPickMemoryPhoto(id)`.

### 1-3. 회원탈퇴 익명화 "언노운" (A-8) — `02-main`
스텁이던 `confirmDeleteProfileAccount`를 실제 구현.
- `utils.js`: `isAccountWithdrawn()`(localStorage `clov_withdrawn`) + `CLOV_ANON_NAME='언노운'`. `normalizeMemoryPost`에서 내 참여자(`me`) 이름→"언노운", 아이콘→"?".
- `space.js`: 작성자 라벨 "내 기록" → 탈퇴 시 "언노운의 기록" (카드/상세 2곳, `replace_all`).
- `clov-profile-modal.js`: 탈퇴 확정 시 `clov_withdrawn` 플래그 + 저장 데이터 즉시 익명화(`normalizeMemoryPost`+`saveGroupsData`) + `renderFeeds` + 토스트. **본문·편지·폴라로이드는 그대로 보존.**
- 참고: 이 프로토타입의 편지 데이터는 전부 **수신(inbound)** 이라 현재 사용자가 작성자인 편지가 없어 익명화 대상은 **추억(폴라로이드)+메시지+참여자 표기**.

## 2. 후속 UI 개선

### 2-1. 편집 모드 연필(수정) 버튼 제거 — `makerooms.html`
- 카드의 `edit-mod-btn`(✏️) 삭제 → 편집 모드는 **순서 변경(드래그)·삭제(🗑)만**. 방 정보 수정은 **카드→미리보기 ⚙️** 한 곳으로 일원화(0706 C-11c와 일관).
- 죽은 `.edit-mod-btn` CSS 제거, 편집 안내 배너 문구 갱신("… 방 정보 수정은 카드를 열고 ⚙️에서 할 수 있어요"). `openEditModal` 함수는 잔존(무해, 재사용 여지).

### 2-2. "요청한 방" 페이지네이션 — 3개(한 줄)씩 — `makerooms.html`
- 사용자 결정: **데스크톱 한 줄(3개) 단위**로 넘김. 기존 방 목록의 `.page-btn` UI 재사용.
- `REQ_PER_PAGE=3`, `reqPage`, `renderReqPagerHTML()`, `goReqPage()` 신규. `.req-pagination { margin-top:14px }`.
- **자동 클램핑:** 카드 취소/지우기로 개수가 줄면 현재 페이지를 `totalPages`로 클램프(빈 페이지 방지), 1페이지면 페이저 숨김.
- **새 요청 시 1페이지로:** 코드 입장으로 새 신청 생성 시 `reqPage=1`(맨 앞에 unshift된 신규가 보이도록).

### 2-3. 이동수단 선택 (보딩패스 중앙 아이콘) — `makerooms.html`
- 카드 중앙 아이콘을 **방 설정에서 4종 선택**: ✈️비행기(`ti-plane`) · 🚌시외버스(`ti-bus`) · 🚢배(`ti-ship`) · 🚂기차(`ti-train`). (이미 로드된 Tabler 웹폰트, 신규 에셋 없음)
- 데이터: 방에 `vehicle` 필드. 기존 방은 id별 4종 순환 시드, 신규 방(`createRoom`)은 기본 `plane`.
- 기존 `ticketIcon`/`TICKET_ICONS` 순환(비행기/캘린더/카메라/핀) → **이동수단으로 대체**하고 죽은 코드 제거. `VEHICLES` 배열 + `vehicleIcon(key)` 신규.
- 편집 뷰(⚙️)에 이동수단 칩 4개(`#rp-ed-vehicles`, `.ed-chip` 재사용). `rpEditVehicle` 상태 + `rpSelectVehicle`/`rpHighlightVehicle`. `openRoomEditView`에서 현재값 활성화, `saveRoomProfile`에서 변경 시 저장 + 소식 피드 "이동수단 수정" 기록.
- ⚠ **주의(이번에 잡은 버그):** 시드 `if(!r.vehicle) r.vehicle=VEHICLES[...]`를 방 보강 forEach(상단)에 넣었더니 **`VEHICLES`(const, 하단 정의) TDZ ReferenceError로 스크립트 전체 중단 → 카드 0개.** 시드를 **`VEHICLES` 정의 뒤로 이동**해 해결. (const는 정의 라인 전엔 참조 불가)

### 2-4. 입장 순간 "찍히는" 탑승 스탬프 연출 — `makerooms.html`
- 하단 **입장 영역(스텁 전체)** 클릭 → 티켓 위에 원형 "✓ 탑승 / CLOV BOARDING" 스탬프가 회전(-15°)한 채 축소(scale 2.6→1)로 찍히고(`tkStampIn` 0.48s), 본체가 살짝 눌리는 밝기 연출(`tkStampPress`) → **0.72초 후 입장**.
- 트리거를 `입장 ›` 텍스트만 → **스텁 전체**로 확대(+`cursor:pointer`, 호버 밑줄). 목적지 D-day 바로가기도 동일 연출로 통일.
- `enterRoomStamp(id, ev)` 신규: `stopPropagation`(입장 클릭이 미리보기 안 열리게) + `_entering` 연타 가드 + **`prefers-reduced-motion`이면 애니메이션 생략 즉시 입장**. 실제 이동은 기존 `enterRoom` 재사용.
