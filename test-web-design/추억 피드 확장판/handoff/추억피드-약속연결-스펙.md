# 추억피드 · 약속 연결 + 스크랩북 도장 — 구현 스펙

> Clov 추억피드 기능 확장 스펙. 확정된 디자인 결정을 구현용으로 정리한 문서입니다.
> 비주얼 레퍼런스: `약속연결-확정-레퍼런스.dc.html` (같은 폴더). 도장 에셋: `assets/stamps/memory-complete-stamp.png`.

---

## 0. 개요

추억피드의 각 추억(게시글)에 **약속(일정계획의 D-Day)** 을 연결한다. 연결된 추억은 상세에서 **약속 영수증**으로 보이고, 인생4컷을 완성하면 영수증에 **추억 완성 도장**이 찍힌다.

핵심 3개 지점:
1. **글쓰기(추억 기록하기) 모달** — 작성/수정 시 약속을 연결(일정계획에서 가져오기)
2. **추억 상세(MEMORY PASSPORT)** — 연결된 약속을 영수증으로 렌더 + 완성 도장
3. **추억 피드** — 폴라로이드 카드는 그대로, 클릭 시 상세를 연다 (변경 없음)

## 1. 데이터 모델

```
Schedule (일정계획 D-Day 항목)
  id: string
  title: string          // "성수 스터디 카페"
  date: string (ISO)     // "2026-06-15"
  memo?: string
  proofCount: number     // 인생4컷 인증 사진 수 (0~4)

MemoryPost (추억 게시글)
  id: string
  title, body, hashtags[], friends[], photos[]   // 기존 필드
  scheduleId: string | null   // ★ 신규: 연결된 약속. null이면 자유 기록(FREE MEMORY)
  createdAt: string
```

파생값:
- `diffDays = date - today` (일 단위). `dday = diffDays > 0 ? "D-"+diffDays : diffDays === 0 ? "D-DAY" : "D+"+(-diffDays)`
- `isComplete = schedule.proofCount === 4`
- 상세의 영수증은 `post.scheduleId`로 Schedule을 **조회(참조)** 해서 렌더한다. 추억이 약속 데이터를 복제하지 않는다 → D-Day·4컷·완성 도장이 항상 한 소스에서 동기화된다.

## 2. 약속 영수증 도장 규칙 (★ 최우선 · 절대 규칙)

영수증은 크림색 종이(`#faf6ee`) + 세이지 마운트. 폰트: 영문/숫자 `Space Mono`, 한글 `Gothic A1`.

### 2-1. D-Day 도장은 영구 유지
- D-Day 도장은 **이 추억이 어떤 약속에서 출발했는지 보여주는 원본 기록**이다.
- 약속이 지난 뒤에도, 완료된 뒤에도 **없애거나 회색 처리하거나 작게 밀지 않는다.**
- 색은 **상태와 무관하게 빨강(`#c0392b`) 고정.** (과거라고 초록으로 바꾸지 말 것)
- 캡션: 미래 `함께할 그날까지`, 당일 `드디어 오늘`, 과거 `함께 보낸 그날`.

### 2-2. 완성 시 '추억 완성' 도장을 **추가**
- 인생4컷 완성(`proofCount === 4`) 시, D-Day 도장을 **교체하지 않고** 별도의 완성 도장을 **추가**로 찍는다.
- 에셋 사용: `assets/stamps/memory-complete-stamp.png` (투명 배경, 초록 원형 "추억 완성 / MEMORY COMPLETE / 클로버").
- 종이에 실제로 찍힌 느낌: 살짝 기울여(`rotate(-11~-13deg)`) + `mix-blend-mode: multiply` + `opacity:.9`.
- 위치: 영수증 하단(바코드·정보 위)에 대각선으로. **제목·사진·D-Day 도장을 가리지 않게** 배치.

### 2-3. 상태별 표시 (4가지)
| 조건 | 표시 |
|---|---|
| 일정 연결 · 만남 전 (`diffDays < 0`) | **D-Day 도장만** |
| 일정 연결 · 만남 지남 · 4컷 미완성 (`diffDays >= 0 && proofCount < 4`) | D-Day 도장 + 작은 점선 `4컷 기록 대기` 스탬프 (아직 안 찍힌 빈 도장) |
| 일정 연결 · 4컷 완성 (`proofCount === 4`) | D-Day 도장 + **추억 완성 도장** (교체 아님, 추가) |
| 일정 없음 (`scheduleId == null`) | 영수증 대신 **FREE MEMORY** 스탬프 (초록 이중 테두리) |

### 2-4. 디자인 의도 (요약)
- D-Day 도장 = 약속의 날짜 기록 · 완성 도장 = 추억 만들기까지 끝낸 성취 기록.
- 두 도장이 함께 있을 때 **"약속이 추억으로 완성됐다"** 는 느낌이 나야 한다.

### 2-5. 하지 말 것
- D-Day 도장을 완료 상태 표시로 **대체 금지.**
- 완성 도장이 **제목·사진**을 가리지 않게 할 것.
- 하단 **친구 한 줄 메시지 영역은 건드리지 말 것.**

## 3. 추억 기록하기(글쓰기) 모달 — 약속 연결

기존 모달(`✏️ 추억 기록하기`, 다크 올리브)의 **함께한 친구** 아래에 `약속 연결 (선택)` 섹션을 추가한다.

동작(가져오기 방식 = 확정):
1. 기본 상태: `🗓️ 일정계획에서 약속 가져오기` 버튼 + "연결 안 하면 자유 기록(FREE MEMORY)으로 저장돼요" 안내.
2. 누르면 **일정계획의 약속 목록**을 펼친다. 각 항목은 미니 영수증 카드(빨강 D-Day + 제목 + 4컷 진행률 `n/4`).
3. 하나를 탭 → `post.scheduleId`에 저장 → 섹션이 접히고 **연결됨 칩**(`[D+22] 성수 스터디 카페 · 연결됨` + `변경`/`해제`)으로 표시.
4. 목록 하단 `＋ 새 약속 만들기` = 폴백. 누르면 제목·날짜 입력(라이브 영수증 미리보기) → 추가하면 일정계획에 생성되고 목록 맨 위 `NEW`로 등록·자동 선택. (일정계획 생성 API 재사용)
5. **수정 시**: 같은 섹션을 열어 연결 변경/해제 가능.

배치: 함께한 친구 → **약속 연결** → 기록 남기기 버튼.
스타일: 모달 팔레트 그대로. 라벨 `#c9dc9e`, 입력 배경 `#1b2013` / 테두리 `#4a5a2f`, 기본 버튼 `#8cbf5f`(글자 `#22300f`).

레퍼런스: `약속연결-확정-레퍼런스.dc.html` 의 "② 글쓰기 모달" 섹션.

## 4. 추억 상세 — MEMORY PASSPORT (여권형, 확정)

피드에서 폴라로이드/카드를 클릭하면 이 상세 모달이 열린다. 밝은 피드 → 다크 여권 상세(의도된 대비).

구성(위→아래):
1. **여권 표지 밴드** (딥그린 `#12301d→#1b4332`): `★ CLOV MEMORY PASSPORT ★`, 제목, `REPUBLIC OF CLOVER · 우정 여권`, × 닫기.
2. **사진 라인 + 약속 영수증** (좌우):
   - 좌: **대표사진 1장 크게** + 코너 마운트. 좌상단 `01 / N` 인덱스, 좌우 화살표. 아래 **썸네일 스트립**(가로 스크롤), 초과분은 `+N` 타일로 접기. 사진(대표/썸네일) 클릭 → **전체보기 슬라이드 갤러리**(화살표·썸네일·드래그 스와이프, `03 / N` 카운터).
   - 우: **약속 영수증** (`post.scheduleId` 참조). §2 규칙대로 D-Day 도장(빨강 고정) + 4컷 완성 시 완성 도장. `scheduleId == null`이면 **FREE MEMORY** 스탬프.
3. **데이터 필드**: STATUS(예: `달성 · 인생4컷 완성`), PHOTOS(`N장 기록`), REMARKS(본문), 해시태그, MRZ 라인(장식).
4. **친구 한 줄 메시지** (기존 그대로 유지 — 나/친구 행, "친구는 메시지만 남길 수 있어요").
5. **닫기** 버튼.

사진 상한: 대표1 + 썸네일 스트립으로 최대 30장 처리(인덱스·화살표·`+N`).

레퍼런스: `약속연결-확정-레퍼런스.dc.html` 의 "③ 상세(여권)" 섹션.

> 참고: 완성 도장이 영수증 정보(D-Day·DATE·4/4)를 과하게 덮지 않도록, 도장은 영수증 하단쪽에 배치하고 크기/투명도로 정보 가독성을 확보한다.

## 5. 추억 피드 (변경 없음)

- 폴라로이드/카드 그리드 **그대로 유지**.
- 카드(사진 또는 자세히) 클릭 → 기존 `openMemoryDetail(postId)` 호출 → §4 상세 오픈.
- 연결된 약속이 있으면 카드에 작은 D-Day 배지를 선택적으로 노출해도 좋음(선택).
