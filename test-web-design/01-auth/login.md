# 로그인 (Login) — 화면 명세서

> **위치**: `01-auth/login.html` (독립 페이지). 의존: `../02-main/css/global-theme.css`·`success-overlay.*`·`js/auth.js`.
> **최종 갱신**: 2026-07-10 · **실제 구현 기준**(팀원 개선본 이식 — Enter 네비·성공 오버레이·비번 보안 경고).

---

## 1. 화면 목적

이메일·비밀번호 또는 간편 로그인으로 Clov.에 입장하고, "로그인 유지"로 다음 접속 시 자동 진입.

---

## 2. 진입 · 이탈 경로

**진입**: 앱 최초 화면. **`accessToken`이 이미 있으면** 로그인 화면을 그리지 않고 바로 **방 선택(`03-rooms/makerooms.html`)** 으로 보낸다.
**이탈**: 로그인 성공 → 성공 오버레이 → **`03-rooms/makerooms.html`**. "회원가입" 링크 → `signup.html`.

---

## 3. 화면 레이아웃

```
┌───────────────────────────────┐
│          로그인                 │
│  이메일과 비밀번호로 다시 입장…   │
│  [ 이메일 ]                     │
│  [ 비밀번호        👁 ]          │
│  ☑ 로그인 유지        비밀번호 찾기│
│  [        로그인        ]        │
│  ──── 간편 로그인 ────           │
│  [카카오] [네이버] [구글]         │
│  아직 계정이 없으신가요? 회원가입   │
└───────────────────────────────┘
```

---

## 4. 컴포넌트별 상세

| 요소 | 표시 / 상태 | 비고 |
|---|---|---|
| 이메일 입력 | placeholder 안내 | Enter → 비밀번호로 포커스 이동 |
| 비밀번호 입력 | 표시/숨김 토글(👁) | **보이는 상태일 때 보안 경고 문구** 표시. Enter → 로그인 실행 |
| 로그인 유지 | 체크박스 | 켜면 자동 로그인 토큰 저장 |
| 비밀번호 찾기 | 링크 | OAuth2 연동 단계 예정(안내) |
| 간편 로그인 | 카카오/네이버/구글 | OAuth2 placeholder |
| 회원가입 링크 | `signup.html` | |

---

## 5. 사용자 액션 & 상태 전이

| 액션 | 결과 |
|---|---|
| 이메일 입력 후 Enter | 비밀번호 칸으로 이동 |
| 비밀번호 입력 후 Enter / 로그인 클릭 | 로그인 실행 → **성공 오버레이** → 방 선택 화면 |
| 로그인 유지 체크 | `accessToken` 지속 저장(다음 접속 자동 진입) |
| 👁 토글 | 비밀번호 보임/숨김 + 보임 시 경고 문구 |

---

## 6. 데이터 / 저장

- `accessToken`(localStorage/sessionStorage) — 로그인 유지 여부에 따라 저장소 선택.
- 로그아웃(다른 화면) 시 토큰 정리 → 이 화면으로 복귀.

---

## 7. 예외 / 경계 케이스

- **비밀번호 보임 상태**: "조심하세요! 비밀번호가 보여요!" 경고.
- **비밀번호 찾기 / 소셜 로그인**: 실제 연동 전 안내 메시지.
- **자동 로그인 토큰 존재**: 로그인 화면 건너뛰고 방 선택으로.

---
