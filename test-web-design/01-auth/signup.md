# 회원가입 (Sign up) — 화면 명세서

> **위치**: `01-auth/signup.html` (독립 페이지). 의존: `../02-main/css/global-theme.css`·`success-overlay.*`.
> **최종 갱신**: 2026-07-10 · **실제 구현 기준**(팀원 개선본 이식 — 5단계 위저드·단계 진행바·약관 키보드 접근성·성공 오버레이).

---

## 1. 화면 목적

신규 계정을 **단계별 위저드**로 생성한다. 한 화면에 몰아넣지 않고 계정 → 약관 → 확인 → 프로필 순으로 나눠 부담을 줄인다.

---

## 2. 진입 · 이탈 경로

**진입**: 로그인 화면의 "회원가입" 링크.
**이탈**: 가입 완료 → 성공 오버레이 → **로그인(`login.html`)**. 각 단계에서 "← 이전으로" 이동.

---

## 3. 화면 레이아웃

```
┌───────────────────────────────┐
│  ●───●───○───○───○   (단계 진행바) │
│                                │
│        [ 현재 단계 뷰 ]           │
│                                │
│   [← 이전으로]      [다음 단계 →] │
└───────────────────────────────┘
```
- 상단 **step-bar**(5개 점)로 진행 상태 표시(active/done).

---

## 4. 단계(뷰)별 상세

| 단계 | 내용 |
|---|---|
| **① 계정** | 이메일 + 비밀번호(표시토글 + 보임 시 보안 경고) |
| **② 약관 동의** | [필수]/[선택] 약관. 각 항목 **펼쳐보기 토글**(키보드 접근성: `aria-expanded`) |
| **③ 확인** | 추가 확인 단계 |
| **④ 프로필** | 닉네임 + 생년월일(선택) — "친구들에게 보여질 이름" |
| **⑤ 완료** | 가입 완료 → 성공 오버레이 → 로그인 |

---

## 5. 사용자 액션 & 상태 전이

| 액션 | 결과 |
|---|---|
| 다음 단계 → | 유효성 통과 시 다음 뷰로, 진행바 갱신 |
| ← 이전으로 | 이전 뷰로(입력 유지) |
| Enter | 다음 입력/단계로 이동 |
| 약관 펼쳐보기 | 약관 본문 토글(키보드 지원) |
| 가입 완료 | 성공 오버레이 → 로그인 이동 |

- **상태**: 현재 단계 인덱스(0~4), 각 단계 입력값, 약관 동의 여부.

---

## 6. 데이터 / 저장

- 가입 입력값(이메일·비번·닉네임·생일·약관 동의)을 단계 진행 동안 보관, 완료 시 계정 생성 흐름으로.

---

## 7. 예외 / 경계 케이스

- **필수 미입력 / 필수 약관 미동의**: 다음 단계 진행 차단(안내).
- **비밀번호 보임 상태**: 보안 경고 문구.
- **이전 이동 시 입력 유지**: 되돌아와도 값 보존.

---

## 8. 반응형 · 테마

- `global-theme.css` 라이트/다크. 모바일 폭 대응. 단계 진행바는 반응형.

---
