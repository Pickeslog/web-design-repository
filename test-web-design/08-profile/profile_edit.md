# 사용자설정 (Settings) — 화면 명세서

> **위치**: `02-main` 헤더 → **사용자설정 모달**(`#dt-profile-modal`, 렌더 `components/clov-profile-modal.js`). 단독 파일 `08-profile/profile_edit.html`.
> **최종 갱신**: 2026-07-10 · **실제 구현 기준**
> **핵심 서비스 원칙**: 모든 멤버 동등(방장/관리자 권한 없음) · **탈퇴해도 기록은 보존**(작성자만 '언노운' 익명화).

---

## 1. 화면 목적

내 **개인정보(이름·연락처·비밀번호)** 를 수정하고, 앱의 **테마·배경·커스터마이즈**(라이트/다크, 바탕화면, 커스텀 색상, 대표 사진/커버, 우정편지·증거카드 테마, 마스코트)를 한곳에서 설정하는 모달.

---

## 2. 진입 · 이탈 경로

**진입**: 상단 헤더의 프로필/설정 진입 → 모달 오버레이.
**이탈**: 우상단 ×, 하단 "취소", 오버레이 바깥 클릭. (테마 변경은 즉시 적용·저장되므로 닫아도 유지.)

---

## 3. 화면 레이아웃

```
┌──────────────────────────────────────────────────────────┐
│ SETTINGS                                              [×] │
│ 사용자설정                                                │
├───────────────┬──────────────────────────────────────────┤
│ (김) 김예린   │  [개인정보 수정 pane]  또는  [테마 설정 pane]│
│               │                                          │
│ 계정          │   기본 정보 / 연락처 / 비밀번호 …          │
│ · 개인정보수정│   또는                                    │
│ 화면          │   테마 / 사용자 설정(물감) / 바탕화면 …    │
│ · 테마 설정   │                                          │
├───────────────┴──────────────────────────────────────────┤
│ [계정 탈퇴]                        [취소]  [저장하기]      │  ← 하단 액션(pane별로 다름)
└──────────────────────────────────────────────────────────┘
```
- 좌측 **레일**(아이덴티티 + 네비) + 우측 **pane**(선택된 설정) + 하단 **액션 바**.

---

## 4. 컴포넌트별 상세

### 4-1. 좌측 레일
| 요소 | 표시 | 동작 |
|---|---|---|
| 아이덴티티 | 아바타(이니셜/사진) + 이름 | 이름 입력 시 실시간 반영 |
| 네비: 개인정보 수정 / 테마 설정 | 활성 항목 강조 | 클릭 → pane + 하단 액션 전환 |

### 4-2. 개인정보 수정 pane (account)
| 섹션 | 요소 | 비고 |
|---|---|---|
| **기본 정보** | 프로필 아바타(클릭 업로드) + 이름/닉네임 입력(≤16자) | 힌트 "프로필 사진을 클릭하면 변경할 수 있어요" |
| **연락처** | 이메일, 생년월일 | 생년월일은 입력칸 어디를 눌러도 달력 |
| **비밀번호 변경** | 현재 / 새(8자↑) / 확인 | 각 칸 눈아이콘 표시토글, 확인 불일치 시 힌트 |

### 4-3. 테마 설정 pane (theme)
| 섹션 | UI | 비고 |
|---|---|---|
| **테마** | 라이트/다크 **색 스와치** | 클릭 즉시 전환, 활성 링 |
| **사용자 설정(물감)** | 물감 방울 카드 + **커스텀 색상 피커** | 탭 → SV 박스+Hue 슬라이더, 드래그로 단색 지정. "↺ 기본값으로" 복귀 |
| **바탕화면** | 아이콘 **이미지 스와치** | 아이콘 없는 항목은 이모지 스와치 폴백 |
| 대시보드 배경 | 계절 벽지 목록 | |
| 대표 사진 | 기본/업로드 사진 | 업로드 사진이 "기본 사진"으로 반영 |
| 대표 커버 장식 | 준비중 | |
| 우정편지 테마 | 선물상자 / 우체통 | |
| 증거카드 테마 | 빨랫줄 / 겹침 카드 / 일기장 | 기본값 겹침 카드 |
| 마스코트 | 크로비 / 롭 | 대사 톤 분기 |

### 4-4. 하단 액션 바
- **개인정보 pane**: `계정 탈퇴`(빨강 danger) · `취소` · `저장하기`
- **테마 pane**: 변경이 즉시 적용되므로 별도 저장 없음(닫기 계열).

---

## 5. 사용자 액션 & 상태 전이

| 액션 | 결과 |
|---|---|
| 네비 전환(개인정보/테마) | 해당 pane + 하단 액션 세트 전환 |
| 아바타 클릭 | 파일 선택 → 미리보기·저장 |
| **저장하기** | 새 비밀번호 일치 검사 통과 시 저장, 실패 시 차단·힌트 |
| 테마/바탕화면/대표사진 등 스와치 클릭 | **즉시 적용**(+토스트) · active 이동 |
| **물감 커스텀 색상** | 물감 탭 → 피커 드래그 → 실시간 단색 배경 + **밝기에 따라 자동 라이트/다크**(가독성). 벗어나면 원래 라이트/다크 설정 복원 |
| ↺ 기본값으로 | 커스텀 벗어나 기본 배경(우드 & 클로버)으로 |
| **계정 탈퇴** | 확인 → 기록은 보존한 채 작성자 '언노운' 익명화 저장 + 로그아웃 → 로그인 화면 이동 |

---

## 6. 데이터 / 저장 (localStorage)

| 키 | 내용 |
|---|---|
| 프로필(이름·이메일·생년월일·아바타) | 개인정보 |
| `clov_darkMode` | 라이트/다크 |
| `clov_appBackground` | 바탕화면 id(`default`/이미지/`custom`) |
| `clov_appBgCustomColor` | 커스텀 배경 HEX |
| `clov_withdrawn` | 탈퇴(익명화) 플래그 |
| 그 외 | 대시보드 배경·대표사진·커버·편지·증거카드·마스코트 테마 |

- 테마·배경 변경은 **즉시 저장·적용**, 개인정보는 저장하기 눌러야 반영.

---

## 7. 예외 / 경계 케이스

- **새 비밀번호 불일치**: 힌트 표시 + 저장 차단.
- **커스텀 배경색 밝기**: 어두운 색 → 자동 다크 글자, 밝은 색 → 라이트. (가독성 보장)
- **아이콘 PNG 없는 배경**: 이모지 스와치로 폴백.
- **커스텀 색이 텍스처에 가려지던 문제**: 배경 이미지를 `none`으로 지워 단색이 실제로 보이게 처리.
- **계정 탈퇴**: 삭제가 아니라 **익명화**(추억·편지·폴라로이드 보존).

---

## 8. 반응형 · 테마

- 좁은 화면: 레일/pane 세로 배치.
- 라이트/다크 모두에서 색 스와치·물감 카드·아이콘 스와치가 정상 표시(다크에서 대비 확보).
