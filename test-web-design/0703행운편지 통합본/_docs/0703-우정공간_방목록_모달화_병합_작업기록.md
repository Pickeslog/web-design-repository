사용자가 새로 전달한 `makerooms.html`, `makerooms.md`, `invite.html`, `invite.md`, `join_room.html`,
`join_room.md` 여섯 파일을 `test-web-design/03-rooms/`의 기존 버전과 비교해, 실제로 달라진 부분만 골라
병합했다.

## 2. makerooms.html — 패널 전환 → 모달 전면 개편

### 기존 구조 (병합 전)

- `showPanel('list' | 'create' | 'success')`로 페이지 내 3개 패널을 전환
- 방 카드 클릭 → `enterRoom()` 즉시 이동 (미리보기 없음)
- 방 코드 미입력 시 브라우저 기본 `alert()`
- 삭제 시 `confirm()`, 복사 시 `alert('복사됐어요!')` — Modal-First 미적용 (관련 코드 0건)

### 병합 후 구조

- **`panel-create`/`panel-success` 패널을 완전히 제거**하고 `room-header-modal-backdrop` 공통 모달 셸로 통일
- **우정공간 미리보기 모달 신규 추가** (`#room-preview-modal`) — 방 카드 클릭 시 먼저 열림
  - 기본 정보(이름·소개·레벨·최근 활동), 주요 알람(+N), 참여 멤버 4인 칩, 초대 코드+복사 버튼 표시
  - 하단 **[🚀 우정공간 입장하기]** 버튼을 눌러야 실제 `enterRoom(id)` 호출
- **방 만들기 모달** (`#room-create-modal`), **생성 완료 모달** (`#room-success-modal`) — 기존 패널 내용을 모달로 이전
- **방 코드 미입력 경고 모달** (`#room-alert-modal`) 신규 — 기존 `alert()` 대체
- 삭제 → `clovConfirm()`, 복사 완료 → `clovToast()`로 전환해 Modal-First 정책 완성
- 방 카드에 **초대 코드 칩**(🔑 CLOV-XXXX) 표시 추가, 아이콘을 이모지 → Tabler 아이콘 폰트(`ti ti-*`)로 통일
- 데이터 모델에 `code` 필드 명시 추가 (방마다 고유 초대 코드 보유)

### 관련 함수 (신규/변경)

`openRoomCreateModal`, `closeRoomCreateModal`, `closeRoomSuccessModal`, `showRoomPreviewModal`,
`copyPreviewRoomCode`, `deleteRoom`(clovConfirm 적용), `enterRoom`(roomCode 파라미터 추가)

## 3. invite.html — Modal-First 업그레이드

기존 코드가 이미 구조적으로는 동일했고, 초대 코드 유효성 검증 실패 시 처리만 아래처럼 바뀌었다.

```diff
- alert("유효한 초대 코드를 입력해주세요.");
+ clovAlert("유효한 초대 코드를 입력해주세요.", { icon: "⚠️", type: "warn" });
```

`<script src="../02-main/components/clov-modal.js"></script>`를 새로 추가해 `clovAlert`를 사용할 수 있게 했다.

## 5. 검증 내용

- 방 목록 렌더링: 초대 코드 칩 포함 정상 표시 확인
- 방 코드 미입력 → 경고 모달 정상 표시 확인 (스크린샷 픽셀 단위 비교)
- "방 만들기" 클릭 → 모달 오픈, 이름/소개글 입력 → 생성 → 완료 모달 → 목록 반영까지 확인
- 콘솔 에러 없음

## 팀 공유 시 주의할 점

- `makerooms.html`은 이제 방 카드 클릭 시 **바로 입장하지 않고 미리보기 모달을 먼저 거친다** — 다른 화면에서
  이 페이지로 딥링크를 걸 때 이 흐름을 감안할 것
- `room-header-modal-backdrop`는 편지함/알림/경고/미리보기/생성/완료 모달이 전부 공유하는 셸이다.
  새 모달을 추가할 땐 `id`만 다르게 주고 이 패턴을 재사용하면 된다
