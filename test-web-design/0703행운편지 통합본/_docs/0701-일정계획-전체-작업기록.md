# 일정계획 탭 — 전체 작업 기록 (2026-07-01)

## 작업 1 & 2 — 4컷 사진 스트립 카드

### 기획 배경

10~20대에서 인기 있는 인생네컷(4컷 사진 부스)의 세로 필름 스트립 형태로 약속 성장 과정을 시각화.

### 카드 구조

```
┌──────────────────────┐
│ 제목         D-8 pill │  ← strip-header
├───┬──────────────┬───┤
│ ░ │  frame 1    │ ░ │  ← 약속 씨앗
│ ░ ├─────────────┤ ░ │
│ ░ │  frame 2    │ ░ │  ← D-day 새싹
│ ░ ├─────────────┤ ░ │
│ ░ │  frame 3    │ ░ │  ← 만남 클로버
│ ░ ├─────────────┤ ░ │
│ ░ │  frame 4    │ ░ │  ← 추억 꽃 (인증 프레임)
└───┴─────────────┴───┘
│  약속을 향해 가는 중  │  ← strip-footer
└──────────────────────┘
```

좌우 `strip-perf` = 필름 천공(8개 span).

### 프레임 상태 CSS 클래스

| 클래스 | 조건 | 표시 |
|--------|------|------|
| `strip-frame--past` | 단계 날짜 경과 (프레임 1~3) | ✓ 녹색 아이콘 |
| `strip-frame--growing` | 현재 진행 중 단계 | 이모지 + pulse 애니메이션 |
| `strip-frame--locked` | 날짜 미도래 | 이모지 32% dim |
| `strip-frame--open` | 약속 당일 이후 (프레임 4만) | 📷 인증하기 버튼 |
| `strip-frame--done` | 사진 업로드 완료 (프레임 4) | 사진으로 프레임 채움 |

### 인증 로직

- 프레임 1~3: 날짜 경과 → `past`, 현재 단계 → `growing`, 미래 → `locked`
- 프레임 4 (추억 꽃): `sch.date <= today` 조건 충족 시에만 📷 업로드 버튼 표시

```js
function uploadStagePhoto(viewType, scheduleId, stageKey, inputEl) {
    const file = inputEl.files[0];
    if (!file) return;
    const reader = new FileReader();
    reader.onload = function(e) {
        const sch = groupsData[activeGroup].schedules.find(s => s.id == scheduleId);
        if (!sch) return;
        if (!sch.stagePhotos) sch.stagePhotos = {};
        sch.stagePhotos[stageKey] = e.target.result;
        renderScheduleList('dt');
        renderScheduleList('mb');
    };
    reader.readAsDataURL(file);
}
```

### Footer 상태 문구

| 상태 | 문구 |
|------|------|
| 인증 전, 당일 미도래 | 약속을 향해 가는 중 |
| 당일 이후, 미인증 | 📷 인증하면 완성이에요 |
| 인증 완료 | 🌸 추억이 완성됐어요 |

## 작업 3 & 4 — 캐러셀 → 보드형 그리드 전환

### 변경 전

- `.growth-card-list` : `display: flex; overflow-x: auto` (가로 스크롤)
- 좌우 화살표 버튼 + 페이드 오버레이 있음

### 변경 후 (데스크톱)

```css
.growth-card-list {
    display: grid;
    grid-template-columns: repeat(auto-fill, minmax(148px, 148px));
    justify-content: start;
    gap: 14px;
    overflow: visible;
}
```

- 카드 폭 148px 고정, 화면 폭에 따라 열 수 자동 조정
- 11개 이상도 줄바꿈으로 자연 처리
- 캐러셀 화살표 버튼 DOM 제거
- 양쪽 페이드 그라데이션 오버레이 (`.growth-card-rail::before/::after`) 제거

### 모바일 유지

```css
.mobile-window .growth-card-list {
    display: flex;
    flex-direction: row;
    flex-wrap: nowrap;
    overflow-x: auto;
    scroll-snap-type: x mandatory;
}
```

모바일은 손가락 스와이프 UX 유지.

### 확인된 배치

| 화면 폭 | 카드 열 수 |
|---------|-----------|
| 1024px  | 4열       |
| 1366px  | 6열       |
| 1600px  | 7열       |
