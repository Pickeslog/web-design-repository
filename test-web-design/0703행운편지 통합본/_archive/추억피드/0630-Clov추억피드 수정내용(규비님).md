# 2026년 6월 30일 오후 수정 사항 정리
(16:20 ~ 현재까지 요청 및 반영된 전체 작업 내역)

## 1. 🏷️ 해시태그 다중 입력 및 UI 개선
- 새 추억 게시글 작성 시 불필요한 '부제목' 항목을 삭제했습니다.
- 해시태그 입력 항목을 추가했으며, 띄어쓰기로 여러 개를 입력할 수 있도록 구현했습니다.
- 여러 해시태그를 입력했을 때 뷰 화면에서 각각의 태그 앞에 `#` 기호가 누락되지 않고 정상적으로 표시되도록 수정했습니다.

## 2. 📝 추억피드 제목 글자 수 제한
- 제목이 길어질 경우 우측의 수정/삭제 버튼 레이아웃을 침범하는 문제를 방지하기 위해 **제목 글자 수를 25자로 제한**했습니다. (`maxlength="25"` 속성 적용)

## 3. 🔍 더보기 버튼 모달창 도입 및 내용 짤림 문제 해결
- 코멘트 카드가 너무 세로로 길어지는 것을 막기 위해 텍스트가 길 경우 `더보기` 버튼을 추가했습니다. (기존 `···더보기`에서 `더보기`로 텍스트 변경)
- 기존에 텍스트를 저장할 때 말줄임표 처리된 잘려진 텍스트만 저장되던 치명적인 버그를 찾아내어, **글을 작성할 때 전체 내용이 온전히 저장**되도록 로직을 전면 수정했습니다.
- 더보기 버튼 클릭 시 카드가 아래로 늘어나는 대신, 화면 중앙에 **'전체 보기 모달창'**이 예쁘게 뜨도록 개선했습니다.

## 4. ⚙️ 수정 시 리다이렉트 버그 수정 (인라인 모달 도입)
- 추억피드에서 게시글 수정 버튼을 누르면 다른 페이지(`write_post.html`)로 이동했다가 다시 돌아오면서, 앞서 적용했던 더보기 모달 등의 스크립트 기능이 먹통이 되는 버그가 있었습니다.
- 이를 막기 위해 **페이지를 아예 떠나지 않고 현재 추억피드 화면 안에서 바로 수정할 수 있는 인라인 수정 모달**을 새로 도입했습니다.

## 5. 👥 다른 사람의 기록 전체보기 제목 동적 변경
- 친구(예: 솔)의 기록을 '더보기' 했는데도 모달 제목이 "📝 내 기록 전체 보기"로 고정되어 나오는 문제를 수정했습니다.
- 이제 기록을 남긴 **작성자의 이름에 맞춰 "📝 솔의 기록 전체 보기" 처럼 동적으로 제목이 변경**됩니다.

## 6. 🖼️ 이미지 카드 텍스트 제거
- 사진(이미지)이 있는 코멘트 카드 위에 겹쳐서 나타나던 **"✨ 우리의 추억 스냅샷" 문구를 아예 삭제**하여, 사진이 더 돋보이고 깔끔하게 보이도록 조치했습니다.

## 7. 🎨 필터 탭 그림자(셰이드) 제거
- 화면 상단의 피드 컨트롤 영역("전체", "월별 달력", "내 기록", "친구 기록" 탭)에 있던 **그림자(Box Shadow/셰이드) 효과를 제거**하여 더욱 플랫하고 모던한 느낌으로 만들었습니다.
