2026년 6월 30일 오후 기준으로 7개 항목의 수정 작업이 완료되었다.

## 6/30 주요 수정 내용

### 1. 해시태그 다중 입력 및 UI 개선

- 새 추억 게시글 작성 시 `부제목` 항목 삭제
- 해시태그 항목 추가: 띄어쓰기로 여러 개 입력 가능
- 뷰 화면에서 각 태그 앞 `#` 기호 정상 표시

### 2. 추억피드 제목 글자 수 제한

- 제목 최대 25자 제한 (`maxlength="25"`)
- 수정/삭제 버튼 레이아웃 침범 방지

### 3. 더보기 버튼 전체 보기 모달 도입

- 기존 `···더보기` → `더보기` 텍스트 변경
- 말줄임 잘린 텍스트만 저장되던 치명적 버그 수정
  - 전체 내용이 온전히 저장되도록 로직 전면 수정
- 카드 늘어남 대신 화면 중앙 모달창 팝업 방식으로 변경

### 4. 수정 시 리다이렉트 버그 수정 (인라인 모달)

- 기존: 수정 버튼 → `write_post.html` 이동 → 돌아오면 스크립트 먹통
- 변경: 현재 페이지 내 인라인 수정 모달 도입

### 5. 다른 사람의 기록 전체보기 제목 동적 변경

- 기존: `📝 내 기록 전체 보기`로 고정
- 변경: 작성자 이름에 따라 `📝 솔의 기록 전체 보기` 등 동적 표시

### 6. 이미지 카드 텍스트 제거

- 사진 카드 위 `✨ 우리의 추억 스냅샷` 문구 완전 삭제
- 사진이 더 돋보이고 깔끔하게 보이도록 개선

### 7. 필터 탭 그림자(셰이드) 제거

- 피드 컨트롤 영역 (전체 · 월별 달력 · 내 기록 · 친구 기록 탭)의 Box Shadow 제거
- 더욱 플랫하고 모던한 느낌

## 추억피드 화면 구성 (main/index.html 기준)

- 월별 아카이브 레일 (월 선택)
- 필터 탭: 전체 / 내 기록 / 친구 기록
- 피드 카드 그리드 (폴라로이드 스타일)
- 글쓰기 버튼
- 더보기 → 전체 보기 모달 (`backdrop` + 모달창)
