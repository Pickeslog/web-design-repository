# profile_edit.html — 개인정보 수정

## 개요

프로필 아바타, 닉네임, 이메일, 비밀번호, 상태 메시지 등을 수정하는 독립 페이지다.  
`index.html` 프로필 드롭다운에서 `개인정보 수정`을 클릭하면 진입한다.

> **참고**: 현재 `index.html`에서는 별도 페이지 이동 대신 **내 프로필 모달** (`openProfileSettingsModal()`)을 우선 사용한다. 이 파일은 별도 페이지 이동이 필요한 경우나 레거시 경로에서 사용된다.

---

## 화면 구성

| 섹션 | 내용 |
|---|---|
| 아바타 섹션 | 88px 원형 아바타 (그라디언트 배경), 하단 편집 배지 (📷) |
| 기본 정보 카드 | 닉네임, 이메일, 상태 메시지 입력 폼 |
| 비밀번호 변경 카드 | 현재 비밀번호 / 새 비밀번호 / 확인 입력 |
| 계정 관리 카드 | 로그아웃 / 계정 탈퇴 (danger 색상) |

---

## 폼 동작

- 읽기 전용 필드(`readonly`)는 시각적으로 구분되어 직접 편집 불가
- 저장 버튼 클릭 시 유효성 검사 후 처리
- 저장 데이터: `localStorage` (`clov_profile_nickname`, `clov_temp_email` 등)

---

## 계정 관리

- **로그아웃**: `login.html`로 이동 (데모 계정 데이터 유지)
- **계정 탈퇴**: `localStorage`의 프로필 관련 키 삭제 (데모 기능)
  - `localStorage.clear()` 사용 금지 — 임시 로그인 계정까지 삭제될 수 있음
