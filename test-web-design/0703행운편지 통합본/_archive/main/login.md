# login.html — 로그인

## 개요

이메일/비밀번호 기반 로그인 화면이다. 회원가입 페이지와 레이아웃을 의도적으로 차별화했다.

---

## 화면 구성 (2열 그리드)

`grid-template-columns: minmax(310px, .92fr) / minmax(360px, 1fr)`

### 왼쪽 패널 (memory-panel)

- 배경: 진한 초록색 (`--primary-green`)
- `🍀 Clov.` 브랜드 로고
- `오늘도 추억 보관 중` 배지
- 서비스 소개 문구
- 더미 추억 카드 2개 (그리드 패턴 마스크 효과)

### 오른쪽 패널 (form-panel)

- 이메일 입력
- 비밀번호 입력 (보기/숨기기 토글)
- 로그인 유지 체크박스 (체크 시 초록 텍스트로 전환)
- 비밀번호 찾기 버튼 (현재: 추후 API 연동 예정 안내 메시지)
- 로그인 버튼
- 소셜 로그인 (카카오 · 네이버 · 구글) — 아이콘 원형 버튼, hover 시 라벨 표시

---

## 입력 검증

- 이메일 형식 오류 시 해당 input 흔들림 애니메이션
- 비밀번호 공란 시 해당 input 흔들림 애니메이션
- 정상 입력 시 예시 완료 메시지 표시 (실제 API 미연동)

---

## 비밀번호 보기/숨기기

- 눈 아이콘 클릭 시 `input[type]` 전환 (`password` ↔ `text`)
- 보임 상태에서 경고 문구 표시: `조심하세요! 비밀번호가 보여요!`

---

## 폰트 및 애니메이션

- 폰트: `Outfit` (Google Fonts, 300–900 웨이트)
- 진입 애니메이션: `rise` (`translateY + scale 0.98 → 1, 650ms`)

- 하단 `회원가입` 링크 → `signup.html`
- 로그인 성공 → `index.html`로 이동 예정
